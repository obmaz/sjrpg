# 지형 레이어와 Tiled 저작 가이드

현재 Flutter 게임은 `.tmx`를 사용하지 않습니다. `AdventureWorld`가 길·물·충돌을 정의하고 `TerrainArt`가 같은 좌표를 그립니다. 지형 변화는 완성된 지형 타일 캐시에 기록하며 전투 이펙트는 그 위에 별도로 합성합니다.

## 현재 지면 구성

- 기본 잔디 위에 일반 잔디·잡초·야생화·작은 돌의 네 변형을 섞습니다. 월드 seed와 셀 좌표로 선택하므로 이동·저장·재접속 중 무늬가 바뀌지 않고 전투 난수도 소비하지 않습니다.
- 변형의 가장자리는 알파로 블렌딩합니다. 길 중앙은 불투명하게 유지하고 양옆과 끝부분은 잔디로 부드럽게 이어집니다. 수면·마을·주요 구조물은 공통 지형 마스크로 제외합니다.
- 작은 풀과 꽃, 바닥에 박힌 돌은 장식입니다. 큰 바위·나무 줄기·건물의 발밑은 기존 공통 충돌 모델을 사용합니다.

변형 원본은 `docs/art/meadow-variants-original.png`, 측정한 경계와 출처는 `docs/art/meadow-variants-provenance.json`에 보존합니다. `python tools/prepare-meadow-variants.py`로 런타임 아틀라스를 다시 만들 수 있습니다(Pillow·NumPy·SciPy 필요). `npm run prepare:new`가 아틀라스를 Flutter 자산에 복사합니다.

## Tiled로 저작할 경우

레이어 순서는 다음과 같이 구성합니다. 현재 앱에 TMX 임포터가 연결된 것은 아니므로, 파일을 추가하는 것만으로 게임에 반영되지는 않습니다.

| 레이어                   | 내용                       | 저작 방법                                                                                                                                     |
| ------------------------ | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Ground                   | 흙, 잔디, 길, 수면         | 잔디 변형 4종의 출현 가중치를 지정하고 Terrain/Wang Set과 Automapping으로 인접 경계 타일을 선택합니다. 길 모서리와 끝 타일도 따로 준비합니다. |
| Decoration               | 잡초, 꽃, 작은 돌, 낙엽    | 대부분의 셀을 비워 두고 군집을 불규칙하게 배치합니다. 길 중앙과 NPC 접근 지점은 비웁니다.                                                     |
| Shadow                   | 건물·나무의 접지 그림자    | 낮은 불투명도의 별도 그림을 사용하고 왼쪽 위 광원 방향을 통일합니다. 동적 조명과 겹쳐 검게 뭉치지 않게 조절합니다.                            |
| Collision (Object Layer) | 줄기·기둥·바위의 실제 발밑 | 이미지 전체 사각형 대신 발밑 다각형을 정의합니다. 이동·길찾기·발사체가 같은 데이터를 읽게 합니다.                                             |
| Objects / Actors         | 건물·캐릭터·큰 식생        | 발밑 Y 좌표로 깊이를 정렬합니다. 위를 가리는 나뭇잎과 캐릭터의 관계를 별도로 처리합니다.                                                      |

기존 월드 좌표는 직교 좌표입니다. Tiled를 도입해도 이 좌표에 맞춰 쿼터뷰 원화를 배치하면 현재 이동 모델을 유지할 수 있습니다. 진짜 Isometric 맵으로 전환한다면 화면 투영과 입력·충돌 좌표 변환도 함께 구현해야 합니다. 그림만 기울여 충돌과 어긋나게 만들지 않습니다.

검증은 길 교차점·강 가장자리·구조물 앞에서 수행합니다. 가로·세로 화면 모두에서 타일 이음새, 오브젝트의 발밑, 조명 아래 색상, 이동 가능 범위와 미니맵의 지형을 함께 확인합니다.
