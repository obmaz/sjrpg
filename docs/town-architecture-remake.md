# 마을 건축 재제작

사용자 원본은 [보관된 게임 화면](../assets/source/style/approved-game-reference.jpg)입니다.
분리 원화는 이를 최상위 참조로, [비교 수정한 장면 후보 3](../assets/source/remake/town-master-scene.png)을
재질 참조로 사용했습니다. 이전 집 그림은 구조 참조이며 스타일 기준이 아닙니다.
실제 전체 프롬프트·첨부 파일·원본 해시는 [생성 기록](../tools/extract/town_remake_generation.json)에 있습니다.
장면 후보는 사용자의 승인이나 원화 투영 합격을 뜻하지 않습니다.

## 원본과 실제 비례

새 PNG 다섯 개는 `assets/source/remake/house-nw.png`, `house-ne.png`, `house-sw.png`,
`house-se.png`, `chapel-v2.png`입니다. 전면 포장대와 난간이 있던 `chapel.png`는 이전 후보로 보존합니다.
새 예배당은 같은 본체·재질을 참조해 생성하고 문 앞 3단만 남겼습니다. 원본 픽셀을 임계값으로 자르거나 다시 그리지 않았습니다.
NE·SW 미리보기의 갈색 영역은 투명 픽셀의 RGB이며, 실제 흰색·검정색 배경 합성에서는
넓은 배경 잔여물 없이 투명합니다. 문턱과 구조물 전체를 함께 확인했습니다.

배우의 `ActorSprite.body_height=84` 기준값과 출입문 비례를 함께 기록합니다. 실제 가시 실루엣 높이는 애니메이션 프레임과 atlas.ref_height에 따라 달라지므로 화면 점유율은 브라우저에서 별도로 비교합니다. 아래 값은 새 측정과 저작 투영으로
도출한 값이며 카메라 확대와 무관합니다. 패킹·런타임 수치의 최종 감사는 추출 후 진행합니다.

| 건물 | 배치 모델 월드 폭 | 문 높이 약값 | 기준값 84 대비 |
| --- | ---: | ---: | ---: |
| 상점 NW | 406.09 | 98.0 | 1.17 |
| 대장간 NE | 680 | 100.7 | 1.20 |
| 탈것 상인 SW | 450 | 110.3 | 1.31 |
| 촌장 SE | 455.35 | 102.4 | 1.22 |
| 예배당 v2 | 232.77 | 128.0 | 1.52 |

NE·SW의 기존 폭을 고정하면 문이 영웅보다 낮아지므로 중심은 유지하고 폭을 조정합니다.
주민 접근은 새 그림의 실제 문턱에서 전면 외측 법선으로 계산하며, 포장 기단 밖까지 나온 뒤
35월드 픽셀의 여유를 둡니다. 이전 주민 절대 좌표를 새 건물 안에 그대로 남기지 않습니다.

예배당 v2의 배치 모델은 주 본체 바닥을 기준으로 하며 돌출 입구까지 포함한 전체 가시 폭은 약362.44입니다.
모델 폭을 전체 실루엣 폭으로 혼동하지 않습니다. 문은 새 나무 개구부의 실제 위·아래 점을 투영해 `Iso.S` 적용 전 원본 월드 단위 128로 맞추고,
본체 중심은 마을 안쪽의 월드좌표 `(780, -110)`으로 옮깁니다. 카메라 확대 때문에 이 비례를 바꾸지 않습니다.

`chapel_measure.json`의 `measured_yard`는 이름을 유지하되 현재는 넓은 마당이 아닌 `door_steps`입니다.
실제 세 단의 문앞 영역과 진입·보행 경로, 낮은 좌우 측면, 닫힌 문을 포함한 오목한 본체 차단선을 별도로 기록합니다.
주 본체의 정규화된 바닥 사각형은 배치·배율 모델이고, 돌출 입구의 실제 이동 차단은 별도 복합 다각형이 담당합니다.
가려진 뒤쪽 점의 기하적 완성이나 배치 사각형을 실제 원화 각도 증거로 사용하지 않습니다.
문앞 단차만 높은 깊이 층을 사용하고 그 주위는 일반 지면으로 걸을 수 있어야 합니다.

## 실제 선분과 투영

발치만으로 각도를 판정하지 않습니다. 새 처마·능선/기와 수평줄·중간 띠장·양쪽 기단·창틀과
수직 모서리를 여러 높이에서 다시 측정합니다. 지붕 경사와 계단 진행 방향은 수평축에서 제외하고
계단 단의 수평 모서리는 포함합니다. 오목한 문턱을 가로질러 존재하지 않는 기단 직선을 만들지 않습니다.

분리 저작 조각은 [새 축 실측](../tools/extract/remake_architecture_axis_measure.json)과
[새 메시 제약](../tools/extract/remake_architecture_warp_measure.json)입니다. 중앙 카탈로그와 메시가
최종 런타임의 기준이며, 이 조각의 저작 검토만으로 브라우저 검수를 통과했다고 선언하지 않습니다.

| 대상 | gvs | gvk | 새 메시 |
| --- | ---: | ---: | --- |
| NW | 1.02 | 0 | `nw` |
| NE | 1.04 | 0 | 없음 |
| SW | 1.10 | 0 | `sw` |
| SE | 1.02 | 0 | `se` |
| 예배당 v2 | 1.25 | 0.06 | `chapel` |

메시 제약의 목표 각도는 전역 보정의 역각도입니다. `ArtWarp` 후 `gvs`/`gvk`가 적용된 실제
그리기 좌표에서 ±30°가 되도록 계산합니다. 같은 변환으로 발치·충돌·계단·주민 접근점을 옮깁니다.
PNG 자체와 알파는 보존하고, 국소 보정은 수직 방향의 작은 변위로 제한합니다.
중앙 데이터 통합 전에 삼각형 뒤집힘, 선 내부, 실제 알파가 있는 구조선 구간을 함께 확인합니다.
예배당은 종탑 양면·상단 처마·본체 지붕·입구/쌍창 전면·반대쪽 석재 줄·기단·문틀·세 단을 새 원화에서 각각 측정합니다.
지붕이 올라가는 경사는 지면 축과 구별합니다. 문턱의 서로 가까운 실측 끝점이 하나로 합쳐지지 않도록
해당 메시의 점 병합 거리를 지정하고 실제 선분을 메시 변으로 복원합니다. 선분 삭제나 허용 오차 완화로 해결하지 않습니다.

## 통합과 남은 검수

`town_art.py`와 `chapel.py` 엔트리포인트를 유지합니다. 기존 `town.webp` 시트를 새 소스로 다시
패킹하므로 다른 패밀리의 별도 아틀라스를 덮어쓰지 않습니다. 추출 JSON은 직접 수정하지 않습니다.
`tools/prepare_town_remake.py /path/to/sjrpg`가 중앙 축/메시 조각 통합, 패킹, 원본에서 village 추출,
실제 원화·런타임 해시의 명시적 고정을 직렬로 수행합니다. 패킹 중 엔진 임포트·export를 겹치지 않습니다.

필수 런타임 검수는 확대된 NE/SW의 성벽·길 간격, 네 주민의 실제 접근, 예배당의 세 단 진입·닫힌 문과 본체 차단,
양쪽 벽 주위의 지면 보행, 새 문 비례와 앞뒤 가림입니다. `chapel` 검사는 현재 단차 종류·실제 문 높이·작은 계단 영역을
기준으로 하며 이전 넓은 마당의 크기를 고정하지 않습니다. `art_projection`은 `chapel`을 포함한 현재 매니페스트의
모든 기록에 상·중·하단, 양축·수직, 평행·선 내부·원본 해시·메시 뒤집힘 검사를 적용합니다.
세로·가로 브라우저에서 배우·포장석·주변 숲과 함께 최종 재질·구도·움직임을 검수하기 전까지
장면 분위기 판정은 미검증입니다.
