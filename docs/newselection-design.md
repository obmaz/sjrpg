# 수호자 선택 화면

사용자가 새로 첨부한 직업 선택 화면의 계층과 720×1280 세로 비율을 따릅니다.
첨부 원본은 대화 이미지로만 제공되었으며, 저장된 사용자 파일이나 그 해시가 있는 것으로 기록하지 않습니다.

## 구성

- 흐릿한 짙은 숲 배경, 상단 중앙의 금빛 나무 문장과 게임명, 왼쪽의 모서리를 자른 뒤로 버튼
- 중앙의 ‘수호자 선택’ 제목·설명, 금속 면이 선택되는 넓은 전사/마법사 탭과 작은 아래 삼각형
- 하나의 큰 둥근 카드. 선명한 실제 직업 원화 위로 짙은 녹색 정보 면이 올라오며, 직업 문장·이름·역할·설명·실제 시작 수치·시작 무기를 표시. 문장 옆의 세로 구분선 뒤에 이름·역할을 묶고, 하트/불꽃 기호·작은 이름·굵은 수치가 있는 두 개의 둥근 테두리 상자로 체력과 자원을 구분
- 카드 아래의 금빛 ‘전사/마법사로 모험 시작’, 별도의 어두운 ‘이어하기’ 행동

세로 기준으로 탭은 y245/h66, 카드는 y335/h630, 새 모험은 y1017/h90,
이어하기는 y1128/h74입니다. 긴 화면의 여유 높이는 주로 원화와 카드에 배분합니다.
정보 면은 카드 안으로 들어간 둥근 녹색 패널이며 긴 화면에서도 카드 중간부터 시작합니다.
가로에서는 같은 순서를 유지하며 카드의 원화·정보를 나란히 놓고 하단 두 행동을 나눠 표시합니다.
작게 보이는 뒤로 판도 실제 터치 높이는 64 단위를 유지합니다.

## 실제 데이터와 저장

직업 탭은 미리보기만 바꿉니다. `GameState.CLASSES`에서 시작 체력·자원,
`Gear`에서 무기 이름을 읽으며, 선택만으로 진행 상태나 저장을 바꾸지 않습니다.
시작 버튼에서만 `chosen`을 내보내고 기존 `Main`의 새 모험 확인을 거칩니다.
이어하기는 실제 저장의 직업·레벨과 백업 복원 여부를 표시합니다. 저장이 없거나 읽을 수 없으면 이유를 표시하고 비활성화합니다.

## 원화·금속 패킹과 출처

- 인물은 기존 `assets/source/hero-selection.png`의 전사·마법사를 그대로 사용합니다.
  `tools/prepare_entry_art.py`가 두 WebP를 만들며, 화면 비율이 바뀌어도 원화의 위쪽부터 잘라 얼굴을 유지합니다.
- 새 선택 화면의 금속 원본은 `assets/source/selection-trim.png`입니다.
  사용자의 **실제 최신 대화 첨부 이미지 1장**을 참조해 생성했습니다.
  원문 프롬프트·참조 방식·원본 경로는 [생성 기록](../tools/extract/selection_ui_generation.json)에 있습니다.
- `tools/prepare_selection_ui.py`는 네 셀의 실제 알파 경계를 측정해 자르고 패킹합니다.
  알파 2 이하인 제작 잔여만 제거하며 금속을 새로 그리지 않습니다.
  `assets/data/selection_ui.json`에 셀·원본 좌표·PNG/런타임 SHA-256을 고정합니다.
  버튼은 이 그림을 아홉 조각으로 늘려 모서리와 얇은 금속 띠를 유지합니다.
- 뒤의 빈 숲은 `assets/source/selection-forest.png`입니다. 사용자 최상위 게임 기준 이미지와 기존 전사 원화를 실제 참조 파일로 함께 첨부해 생성했습니다.
  사람·문자·UI가 없는 정적 원화여서 화면 전체를 매 프레임 흐리는 셰이더나 인물 잔상이 필요하지 않습니다.
  [배경 생성 기록](../tools/extract/selection_background_generation.json)에 원문 프롬프트·참조 파일·해시를 남깁니다.
  `tools/prepare_selection_background.py`는 WebP 형식과 크기만 패킹합니다.
- 나무 문장과 전사 방패는 선택 화면 금속 시트의 원화입니다. 마법사 문장은 기존 실제 번개 기술 아이콘을 사용합니다.
  UI에 들어가는 한글과 숫자는 모두 실제 텍스트이며 그림에 굽지 않습니다.

이 금빛 선택 화면은 해당 사용자의 새 선택 화면 기준에 한정합니다. 게임 안의 승인된 얇은 청동·은빛 HUD에 밝은 버튼 면을 옮기지 않습니다.

## 검증

`entry_layout`은 세로·가로·작은 화면·회전에서 행동 버튼과 카드의 범위, 얼굴 보존,
설명과 수치 상자 사이의 여유·두 상자의 분리와 수치 포함, 실제 시작 수치, 미리보기의 저장 불변, 실제 이어하기·손상/중단 저장 확인 절차를 검사합니다.
루트의 전체 검사 후 `tools/screenshot.mjs --scene select --class warrior|mage --device phone|phone-landscape`
및 같은 화면의 `--rotate 1`로 실제 UI 비율과 그림·글자의 겹침을 확인합니다.

```sh
python3 tools/prepare_selection_background.py
python3 tools/prepare_selection_ui.py
tools/check.sh --only=entry_layout --export
```
