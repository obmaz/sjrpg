# 숲 레퍼런스와 화면 구성

사용자가 제공한 예배당·숲길·남색 마법사 화면을 제1장의 전체 재료·색·가독성 기준으로 사용합니다.
새 원화는 [레퍼런스 분위기 제작 가이드](reference-look-guide.md)의 작은 완성 장면 → 분리 원화 → 실제 플레이 검수 순서를 따릅니다. 아래는 현재 구현이며, 원본 분위기 달성의 완료 판정이 아닙니다.
최근 승인한 작은 헤더와 레벨 배지는 유지하며, 미습득 스킬이나 체력 수치를 레퍼런스처럼 보이도록 조작하지 않습니다.

## 지면과 식생

`assets/source/lighting/ground-materials.png` 왼쪽 패널은 밝고 평평하게 닳은 석회암 포장입니다. 원본 사용자 화면을 실제 생성 참조로 사용했으며 프롬프트·참조 해시·채택 영역은 `tools/extract/ground_light_generation.json`에 기록합니다. 오른쪽 잔디 후보는 가는 실 모양의 밀도가 여전히 높아 탈락시켰습니다. 기존 `remake/ground.png`의 흙 패널과 `grass-v2.png`의 짧은 풀·클로버는 유지합니다. 모두 고정 조명·나무 그림자가 없는 위에서 본 원화이며 실제 120° 투영은 런타임이 맡습니다. 포장 512px 한 반복의 지면 크기는 180으로 두어 기본 세로 화면에서 돌의 긴 대각선이 약 50–60px로 읽히게 합니다. 280 후보는 실제 비교에서 판석이 지나치게 커서 축소했습니다.
`assets/source/remake/flora.png`는 높은 쿼터뷰의 흰꽃·주황/노랑 꽃·고사리·낮은 풀입니다. 주변의 숨은 RGB와 실제 알파를 구별해 단색 배경에서 검수합니다.
`tools/extract/forest_art_measure.json`에 영역과 줄기·지면 접점을 측정하고 `tools/prepare_forest_art.py`로 패킹합니다.
`assets/data/forest_art.json`이 원본·실제 배포 텍스처의 해시를 보관합니다.

`ForestArt`가 예배당 주변 지면과 나무 아래 군락에 먼저 예산을 배정하고, 실제 길·건물 발치에는 불규칙한 꽃·고사리·풀 군집을 배치합니다. 총 420개를 넘기지 않으며 도로 내부·주민·상자·문·워프·계단 경로·물가·시작 지점을 비웁니다. 얕은 문턱 위를 꽃으로 덮지 않습니다.
별도 난수 생성기를 사용하므로 장식이 전투·전리품·나무의 기존 난수 상태나 이동 충돌을 바꾸지 않습니다.
길과 지도·충돌은 기존 다각형을 유지하며, 잔디와 석재를 균일하게 투영합니다. 반복 검은 그림자나 고정 햇빛 얼룩은 추가하지 않습니다.

`ForestLighting`과 `WorldLighting`이 [장면 가독성 기준](world-readability.md)에 따라 지면·건물·나무·배우에 공통의 따뜻한 낮빛과 차가운 그늘을 적용합니다. `GroundEdges`는 실제 도로 경계를 불규칙하게 섞고 나무 발치에 기존 흙 원화를 낮은 채도로 배합합니다. 나무 그림자는 실제 수관 실루엣을 따르며 UI와 동굴의 등불은 분리합니다. 이는 2D 재질·평지 그림자 개선이며 높이와 수관 부피를 복원한 3D 조명은 아닙니다. 동일 구도의 `--lighting off`와 기본 화면을 비교하고 원본 레퍼런스도 함께 확인합니다.

```sh
python3 tools/prepare_forest_art.py
tools/check.sh --only=forest_art,forest_lighting,canopy_shade,juice,hud_layout,ui_input --export
```

## 캐릭터와 효과

기본 카메라 배율은 `Game.CAMERA_WORLD_SCALE=1.60`, 두 직업의 원화 기준 높이는 84입니다. 이 값은 현재 구현값이며 레퍼런스의 화면 점유율 목표를 대신하지 않습니다. 가까운 카메라 비교와 조명·식생 검수는 분위기 가이드에 따라 별도로 진행합니다. 시각 작업에서 충돌 반경·공격 거리·현재 1.5배 액션 템포를 임의로 바꾸지 않습니다.
성공한 원소 마법 준비에 기존 생성형 이펙트 시트의 작은 손끝 빛과 6개의 짧은 섬광을 사용합니다.
실제 투사체 위치에 같은 시트의 핵과 가는 꼬리를 표시합니다. 표시 효과는 장식 64개 한도·일시정지·동작 줄이기를 따르며 피해 판정과 분리합니다.

## 조작 표시와 검수

조이스틱의 바탕·노브를 낮은 불투명도로 표시하고, 빈 슬롯 표시만 줄여 투명한 각인으로 만듭니다.
점유 슬롯은 실제 그림·얇은 베젤·쿨타임을 유지하고, 일반 근접 행동은 높이 42px의 작은 명판을 사용합니다. 워프 이동은 후속 요청으로 확대했으며 [UI 기준](ui-reference.md)의 별도 크기를 따릅니다.
표시 크기와 터치 영역을 구별해 빈 슬롯 바깥의 터치와 64px 이상 터치 높이를 유지합니다.

일반 나무는 `assets/source/remake/trees-v2.png`의 높은 수관 4종을 사용합니다. 1536² 아틀라스의 모든 원화는 축소 없이 패킹되며 실제 뿌리 접점으로 배치합니다. `CanopyShade`는 최대 6그루의 실제 알파·발치·변환을 공통 광원 방향으로 평지에 투영하는 제한된 그림자 근사입니다. 나무의 3D 부피를 복원한 조명은 아니며, 타일에는 반복 그림자를 넣지 않습니다.

`forest_art`는 원화 해시·실제 발치·예배당 주변 지면 꽃·나무 아래 군락·문과 계단 여유·반복 배치·게임 난수와 충돌 보존을 검사합니다. `tree_art`·`canopy_shade`는 원본/아틀라스와 실제 투영 접점·일시정지·화질 설정도 확인합니다.
`juice`는 성공·실패 시전, 손끝 추적·취소·일시정지·동작 줄이기와 효과 한도를 검사합니다.
`hud_layout`·`ui_input`은 작은 명판과 빈 슬롯의 보이지 않는 터치 여유도 확인합니다.
브라우저의 `town`·`chapel`·`juice`·`field`를 가로·세로로 확인하고, 절약 화질에서도 시야와 UI가 유지되는지 검수합니다.
