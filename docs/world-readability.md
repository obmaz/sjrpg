# 숲 1장 공간·조명·주민 기준

최상위 분위기는 [사용자 게임 원본](../assets/source/style/approved-game-reference.jpg)과 [레퍼런스 제작 가이드](reference-look-guide.md)입니다. 아래 기능은 1장의 가독성과 실제 플레이를 개선하며 후속 지역을 추가하지 않습니다.

## 조명과 지면

`WorldLighting`과 `world_daylight.gdshaderinc`가 예배당 앞·분수 광장의 실제 월드 좌표를 공유합니다. 차가운 주변광 `(0.58,0.66,0.72)`와 따뜻한 낮빛을 섞고, 두 영역의 겹침은 합집합으로 처리해 과도한 흰 빛을 막습니다. 지면·건물·성벽·나무·다리·지형·배우·주민·시체가 같은 기준을 사용합니다. 원본의 재질과 면 음영은 보존하며, 배우의 색은 실제 발치에서 구합니다. 타격 섬광·원소 효과·수면의 발광·이름·HUD는 독립적으로 읽힙니다.

이 재질은 `forest_daylight` 부모 아래의 월드에만 적용합니다. 동굴은 기존 등불과 기본 라이트 수신 재질을 유지합니다. 숲의 표시 전환 즉시 조명을 복원하며, 절약 화질이나 화면 확대는 광원의 월드 좌표를 바꾸지 않습니다. 광원 노드·추가 화면 렌더 패스는 늘리지 않습니다. 카메라 전체 색 필터나 3D 높이·법선·간접광 복원은 아닙니다. 나무의 투영 그림자는 기존 실제 수관 알파·발치 기반의 평지 근사를 사용합니다.

`GroundEdges`는 실제 포장·흙 다각형에서 최대128²의 거리 마스크를 한 번 만들고 가장자리에만 기존 흙·잔디를 섞습니다. 불규칙성은 전이 마스크에만 사용하며 원화 대신 새 재료를 그리지 않습니다. 중심의 재질과 원래 UV·도로·충돌·지도는 유지합니다. 실제 마을·필드 나무의 발치에는 최대512²의 공유 마스크로 기존 흙 원화의 낮은 채도 색을 섞어 초록 수관과 바닥을 구분합니다. 고정 나무 그림자를 타일에 넣지 않습니다.

## 성벽 내부 여백과 주민

`tools/extract/town_clearance.json`의 마을 둘레3200과 원화의 실제 성벽 높이를 기준으로 내부 여백을 확보합니다. `town_art.merge()`는 건물·예배당의 월드 중심과 크기를 유지한 채 UV를 다시 구하고, 성벽·성문·도로·안전 구역을 같은 둘레로 만듭니다. 건물이나 주민을 성벽보다 앞에 강제로 그리는 방식으로 가림을 숨기지 않습니다. `npc_clearance`는 실제 건물의 알파 외곽·주민 몸·성벽 그리기 사각형과 깊이 정렬을 검사합니다. 수관 배치도 새 주민의 몸·이름·표식 여유를 함께 비웁니다.

`assets/source/npcs/identities.png`의 상인·대장장이·탈것 상인·촌장·미라·엘린·노아·로웬은 서로 다른 얼굴·옷·소품을 사용합니다. 실제 알파 몸 높이112는 주인공 정지 프레임의 그려진 실루엣117–118에 맞춘 값입니다. 명목상 `Player.body_height=84`나 아틀라스 전체 셀 높이를 사람의 실제 키로 간주하지 않습니다. 발바닥 접점과 옷·이름·표식은 분리합니다.

원본·참조·프롬프트·실측은 `npc_generation.json`·`npc_measure.json`, 배포 픽셀은 `assets/data/npc_art.json`에 고정합니다. 새 주민을 만들 때 사용자 원본과 이 패밀리를 함께 실제 참조로 사용합니다.

## 성문과 몬스터

`TownGateRuntime`은 살아 있는 숲 몬스터와 실제 성벽·성문 지면 영역을0.15초 간격으로 비교합니다. 200 이내의 접근은 네 철문을 닫고, 모두280 밖으로 물러난 상태가1.2초 이어져야 다시 엽니다. 생성형 철제 격자는 기존 열린 나무 문 뒤의 실제 아치 영역 안에서 내려옵니다. 쇠막대 상·중·하단과 양쪽 모서리를 실제 픽셀에서 측정하고 각 성문 평면에 투영합니다.

몬스터의 몸 반경을 포함한 마을 진입 금지는 철문 상태와 별개입니다. 주인공이110 이내로 접근하면 그 통로를 열어 귀환·출입을 허용하고150 밖으로 벗어날 때까지 유지하되 몬스터는 따라 들어오지 못합니다. 메뉴에서 시간과 움직임이 멈추고 동작 줄이기에서는 문 위치를 즉시 표시합니다. 동굴에는 이 성문 규칙을 적용하지 않습니다.

철문 원본·생성 기록·실측과 배포 해시는 `gate_closure_art.json`과 `tools/extract/gate_closure_*`에 보관합니다. 기존 석재·나무 문과 별개 재질을 임의로 그리지 않습니다.

## 높이가 다른 근접 전투

`TerrainLevels`는 실제 지형의 윗면·절벽 면과 계단 진입 선을 사용합니다. 높이는 측정한 수직 또는 대응하는 윗변/아랫변의 변위에서 구하며, 배우의 그리기 `z_index`와 구별합니다. 높이 없는 장식 윗면은 새 층을 만들지 않습니다. 계단에서 인접한 높이 차이25 이내는 연결되지만 절벽이나 다리 난간을 가로지르는 공격은 막습니다. 마을 성벽을 통과하는 근접 공격도 막고 열린 성문 틈은 유지합니다.

주인공의 근접·회전·착지·그림자 연격과 몬스터의 공격 시작·적중 시점에 같은 검사를 사용합니다. 높은 곳과 낮은 곳 양 방향 모두 적용하며, 원거리·마법 광역의 기존 규칙은 유지합니다. 동굴은 자체 평지로 처리합니다. 높이를 저장 데이터에 새로 기록하지 않습니다.

## 재생성과 검수

```sh
python3 tools/prepare_npc_art.py
python3 tools/extract/extract_data.py /path/to/sjrpg --only=village
python3 tools/prepare_gate_closure.py
tools/check.sh --export
```

원화 패킹과 엔진 임포트를 겹치지 않습니다. 네 성문·네 내부 건물·여덟 주민을 가로/세로와 기본/절약 화질로 비교하고, 조명 적용 전후는 동일한 위치의 `--lighting off`와 기본 화면으로 확인합니다. 실제 출입·계단·전투 경로·동굴 전환과 프레임 비용도 검수하며 정지 화면만으로 완료 판정하지 않습니다.
