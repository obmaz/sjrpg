# 예배당 원화 재생성 규격

## 문제

원본 저장소(obmaz/sjrpg)의 `docs/art/stage1-isometric-120/chapel-original.png`는
120° 쿼터뷰(지면 축 ±30°) 기준에서 벗어납니다. 실측 바닥 사각형(`assets/data/village.json`의
`frames.chapel.ground`)의 변 각도는 다음과 같습니다.

| 건물 | 변 각도 (°) |
| --- | --- |
| 집·대장간·마구간 | 약 ±31~32, 마주보는 변이 서로 같음 |
| 예배당 | -30.0 / +39.3 / -19.3 / +27.1 (마주보는 변이 11~12° 어긋남) |

원본 문서(`docs/art/stage1-isometric-120/README.md`)도 "기준에서 크게 벗어난 원화는 다시 생성"하라고
정해 두었습니다. 작은 잔차는 `groundVerticalScale`/`groundVerticalSkew`로 보정할 수 있지만, 이 정도 차이는
그림을 비틀어야 해서 쓰지 않습니다.

## 새 원화 규격

- 투명 배경 PNG, 약 1254×1254 이상, 조명은 왼쪽 위 낮 햇빛.
- 직교(원근 없음) 2.5D 쿼터뷰. 바닥의 직사각형은 60°/120° 마름모이며 지면 축이 화면에서 정확히 ±30°.
  마주보는 변은 서로 평행해야 함(원근으로 모이면 안 됨). 수직 기둥·벽 모서리는 화면에서 수직.
- 구성: 자갈 포장 높은 마당(기단) 위에 고딕 예배당, 마당 가장자리 난간, 왼쪽 앞 모서리에서 내려오는 넓은 계단,
  기단 옆면은 담쟁이 덮인 석벽과 바위. 문은 마당 쪽(왼쪽 아래)을 향함.
- 크기 기준: 마을 포장 한 칸(변 24)을 기준으로 마당 윗면 약 24×16칸, 문 높이는 주인공 키의 1.25배 이상.
- 이미지에 글자·UI·그림자 바닥판을 넣지 않음. 그림자는 기단 바깥으로 길게 늘이지 않음.

## 교체 절차

1. 새 PNG를 `assets/source/chapel-new.png`로 둡니다.
2. 마당 윗면 윤곽 8점, 계단 경로 6점, 절벽면 2개, 바닥 접점 4점을 원본 좌표로 측정해
   `assets/data/village.json`의 `chapel`, `frames.chapel`, `sprites.chapel`을 갱신합니다.
3. 바닥 접점 변 각도가 ±30°에서 2° 이내인지 위 표와 같은 방식으로 확인합니다.
4. `town.webp` 시트에 패킹하고 `godot --headless res://tests/skill_smoke.tscn`(계단 오르기·절벽 차단 포함)을 통과시킵니다.
