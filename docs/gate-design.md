# 성문·성벽 패밀리

사용자가 지정한 [게임 화면 원본](../assets/source/style/approved-game-reference.jpg)이 최상위 기준입니다.
[아트 기준](art-direction.md)·[생성 공통 문구](art-prompts.md)를 함께 따릅니다.
아래 통합 컨셉은 연결 부품의 재료와 형태를 맞추기 위한 생성형 보조 자료이며 별도 사용자 승인을 뜻하지 않습니다.

## 고정 디자인과 원본

- [통합 컨셉](../assets/source/style/gate-wall-design.png): 둥근 쌍탑 성문, 두 방향의 흉벽, 실제 코너 연결.
- `assets/source/gate-cohesive-a.png`, `gate-cohesive-b.png`: 같은 회색 석회암·거친 입자·좁은 줄눈·아케이드 받침띠·경사진 흉벽 캡을 사용하는 성문 두 방향.
- `assets/source/wall-cohesive.png`: 성문에 이어지는 **단일 생성형 성벽 모듈**. 반대 방향은 이 원화를 투영한 뒤 수평 반사합니다.
  독립적으로 다른 벽을 생성하지 않으므로 두 벽의 돌 크기·줄눈·받침띠·캡·높이·두께가 같습니다.
- `assets/source/style/wall-base-design.png`: 최종 성벽의 줄눈 크기를 조절할 때 실제로 첨부한 초기 모듈. 배포에는 최종 모듈만 사용합니다.

정규 성벽에는 중성에 가까운 따뜻한 회색의 작은 거친 석재와 얕은 풍화를 사용합니다.
노란 대형 블록, 다른 형태의 브래킷 띠, 과장된 몰딩, 굵은 외곽선, 바닥에 붙인 그림자를 섞지 않습니다.
원본의 자체 음영과 어두운 참나무 벽걸음길은 유지합니다. 원통형 탑의 곡면 조적과 정규 성벽의 줄눈 크기는 실제 화면에서 비교하며,
생성 문구만으로 모든 방향의 돌 크기가 완전히 같다고 주장하지 않습니다.

실제로 사용한 생성 문구와 이미지 첨부 순서는 [gate_generation.json](../tools/extract/gate_generation.json)에 있습니다.
최종 원본·패킹 결과·사용자 기준·컨셉·프롬프트 파일의 SHA-256은 `assets/data/gate_family.json`에 고정합니다.
사용하지 않은 생성 시안은 작업 원본 보관소에 남기고 런타임 기준으로 삼지 않습니다.

## 실제 픽셀의 투영

생성 원화는 흔한 디메트릭 각도와 서로 다른 높이의 원근이 섞일 수 있습니다.
새 성문의 왼쪽·오른쪽 날개벽, 위·중간·기단, 반대 방향 끝면과 수직선 및 성벽 앞뒤 캡·모르타르·기단을 실제 픽셀에서 다시 측정합니다.
`art_axis_measure.json`에는 선분 양끝·측정 방식·기대 축을 기록합니다. 옛 원화의 좌표를 단순 확대해 재사용하지 않습니다.

`art_warp_measure.json`의 `gate-0`, `gate-2`, `wall-a`는 그 실제 선분을 제약하는 작은 투영입니다.
성문은 기존 지면 보정과 함께 사용하고, 성벽은 보정된 단일 모듈을 두 방향으로 배치합니다.
수직 이동만 허용하는 삼각형 투영이므로 원본의 가로 폭과 수직 모서리를 유지합니다.
이미지 경계까지 성벽이 차 있는 경우 경계 정점을 충분히 넣고 출력에 투명 여백을 두어 픽셀 누락과 접힌 삼각형을 방지합니다.
메시 뒤집힘은 제작 단계와 `art_projection` 검사에서 모두 거부합니다.

코드는 돌·줄눈을 새로 그리지 않습니다. 보존한 PNG 픽셀을 같은 `ArtWarp` 삼각형으로 재표본화하여 아틀라스에 패킹합니다.
`IsoSprite.native_point()`는 `baked_warp`가 있을 때만 같은 원본→투영 좌표를 적용하며,
실제 그리기·발치·문루 깊이 조각·충돌 데이터는 투영 후 아틀라스 좌표를 사용합니다.
성벽의 반사는 원본 투영 후 동일한 순서로 검증하여 이중 보정하지 않습니다.

## 크기·통로·연결

성벽 높이 200, 두께 64와 네 성문의 기존 중심·날개벽 끝점·탑 충돌·통로를 유지합니다.
`gate_measure.json`의 `model_reference`는 이전 정상 배치의 월드 좌표를 보존합니다.
새 원화에 맞춰 충돌 좌표를 다시 해석해 통로가 좁아지거나 길이 이동하지 않도록 새 아틀라스로 옮깁니다.
벽은 같은 가로·세로 배율로 반복하고 마지막 부분만 자릅니다. 문과 만나는 지점과 네 코너는 실제 브라우저에서 확인합니다.
성문 아래는 높은 지형이 아닌 지면입니다. 캐릭터의 일반 깊이 정렬을 유지하고 몸 주변의 국소 가림 완화로 통로 안에서도 읽히게 합니다. 성문 진입만으로 주변 집 지붕보다 앞으로 올리지 않습니다.

`gates` 검사는 네 통로 이동·탑 차단·여덟 날개벽 연결·기존 끝점 보존·동일 벽 모듈과 크기·리뷰 해시를 확인합니다.
`art_projection`은 실제 원화의 상·중·하·반대쪽 선분과 반사까지 그리기와 같은 좌표로 검사합니다.
축 오차와 같은 축의 평행선 편차는 모두 2.5° 이내여야 합니다. 검사 통과와 별도로 네 성문·네 코너를 가로·세로에서 검수합니다.

## 재생성

원본·실측·프롬프트를 먼저 검토한 뒤 다음 순서로 실행합니다. 패킹 중에는 Godot 임포트·테스트·export를 실행하지 않습니다.

```sh
python3 tools/extract/gate_projection.py
python3 tools/extract/gate.py
python3 tools/extract/extract_data.py /path/to/sjrpg --only=village
# 실제 투영·패킹 결과를 리뷰한 뒤 명시적으로 해시 고정
python3 tools/extract/art_audit_catalog.py
tools/check.sh --only=art_projection,axis,gates --export
```

새 원화를 생성할 때는 사용자 기준 화면과 이 패밀리의 원본을 실제 참조 이미지로 첨부합니다.
실측·알파·재료 크기·연결이 맞지 않으면 문구가 같거나 분위기가 비슷하다는 이유로 이전 측정값과 해시를 재사용하지 않습니다.
