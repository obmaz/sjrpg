# 월드 아트 기준

[대표 플레이 화면](art/village-reference.webp)은 생성 이미지로 만든 구도·색·그림체 기준입니다.
실행 화면의 캡처가 아니며, 화면 전체를 배경으로 깔지 않습니다. 월드는 기존 타일 맵과 실제 엔티티로 구성합니다.

## 그림체와 가독성

- 높은 시점의 2D 그림, 부드러운 붓 질감, 청록·숲 초록·따뜻한 돌·황동색을 공유합니다.
- 청록 망토의 모험가는 네 방향을 사용하고 이동 시 기존 걸음 타이머에 맞춰 움직입니다.
- 글자·체력바·재사용 게이지·상호작용·일지는 코드로 표시합니다. 이미지에 버튼 글자를 넣지 않습니다.
- 기본 초상은 월드의 모험가를 사용합니다. 외관을 고른 경우와 저체력 표정은 기존 선택·상태 표시를 유지합니다.

## 런타임 이미지 규격

두 월드 시트는 각각 정사각형 4×4, 투명 배경입니다. `data/art.js`가 셀 위치를 정의하고
`render/world-art.js`가 로딩 상태를 확인해 셀을 그립니다. 각 셀의 가로 중앙·높이 88%를 발밑 기준점으로 사용합니다.
원본 PNG는 생성 이미지 보관소에 보존하며 런타임은 알파를 보존한 WebP를 사용합니다.

| 시트                | 첫째 줄                    | 둘째 줄                     | 셋째 줄                   | 넷째 줄               |
| ------------------- | -------------------------- | --------------------------- | ------------------------- | --------------------- |
| `world-forest.webp` | 모험가 아래·왼쪽·위·오른쪽 | 상인·주민·여행자·미용사     | 나무·덤불·바위·상자       | 분수·상점·고블린·늑대 |
| `world-desert.webp` | 야자·선인장·사암·사막 상점 | 전갈·미라·스켈레톤·컬티스트 | 트롤·골렘·점액괴물·파라오 | 말·자전거·오토바이·배 |

## 대표 화면 UI

`assets/ui-reference.webp`는 대표 이미지의 초상·청록색 에나멜·황동 테두리를 기준으로 생성한 투명 4×4 시트입니다.
첫 줄은 모험가 초상·빈 원형 버튼·빈 사각 버튼·조이스틱, 둘째 줄은 가방·도감·일지·설정 메뉴,
셋째 줄은 검·소용돌이·부츠·대화, 넷째 줄은 조이스틱 손잡이·잎 문장·동전·투명 미니맵 테두리입니다.

HP 숫자·골드·시간·단계·남은 횟수·대기시간·접근성 이름은 코드로 표시합니다.
일반 공격은 검 문양 하나만 보여주고 원형 공격 게이지를 유지합니다. 장착 무기는 가방과 접근성 이름으로 확인하며 별도 아이콘 배지는 겹치지 않습니다.
모험가 초상 옆의 각진 체력바, 초상 아래의 단계 원, 원형 미니맵 프레임,
반투명 큰 조이스틱과 개별 하단 메뉴 버튼을 대표 화면의 배치에 맞춥니다.
모바일 가로·좁은 세로 화면에서는 크기를 줄여 버튼의 44px 이상 터치 영역을 유지합니다.

빈 소비 아이템 바는 숨기고 아이템이 생기면 다시 표시합니다. 가까운 상호작용 대상이 없을 때에는 대화 조작을 숨깁니다.
데스크톱도 같은 그림 메뉴를 사용하며 키보드 조작은 유지합니다.
`ui/art.js`는 UI 이미지가 준비된 뒤 `reference-skin-ready` 클래스를 붙입니다.
이미지가 지연되거나 실패하면 CSS·SVG 버튼을 계속 사용할 수 있습니다.
팝업도 같은 청록 바탕·황동 프레임을 사용하고 글자와 스크롤·버튼은 DOM으로 유지합니다.

## 조작 이미지 정렬

`assets/controls.webp`는 대표 화면을 기준으로 다시 생성한 3×3 투명 시트입니다.
첫 줄은 조이스틱 바닥·손잡이·검 공격, 둘째 줄은 가방·펼친 지도·나침반,
셋째 줄은 설정·소용돌이·빈 원형 버튼입니다. 하단 메뉴는 둥근 사각 프레임을 사용합니다.

`data/ui-art.js`는 각 그림의 실제 불투명 영역 좌표를 보관합니다. 같은 셀 안에서도 여백이 다를 수 있으므로
`ui/sprite-layout.js`가 실제 그림 중심에 맞춘 배경 크기·위치를 계산합니다.
시트를 교체하면 불투명 영역 좌표를 다시 측정합니다. 조이스틱 바닥과 손잡이는 같은 중심에 맞추고, 포인터를 떼거나 취소하면 손잡이가 돌아옵니다.
하단 메뉴의 그림은 정사각형 표시 레이어에 놓아 버튼 높이 변화로 찌그러지지 않습니다.
새 조작 시트의 로딩이 끝나면 `controls-skin-ready`를 붙입니다. 로드 실패 시 CSS·SVG 조작을 사용합니다.

## 팝업 시안과 구현

[팝업 대표 시안](art/popup-reference.webp)을 먼저 생성한 뒤 공통 프레임·카드·일지·스위치를 코드로 구현합니다.
시안은 디자인 자료이며 실제 게임의 아이템·수치·설정 항목을 정의하지 않습니다.

`assets/popup-frame.webp`는 같은 시안으로 별도 생성한 빈 황동 테두리입니다.
`popup-skin-ready`에서 9분할 테두리로 표시하며 창 크기가 바뀌어도 모서리 장식을 유지합니다.
가방·상점·일지·설정·대화·도감·외관·슬롯머신·결과 창이 공유합니다.
제목·닫기·하단 복귀는 고정하고 본문만 스크롤합니다. 일지는 팝업 영역 기준 절대 배치를 유지하고, 본문·하단 버튼은 장식 테두리 안쪽에 여백을 둡니다. 상점의 잔액은 제목 아래에 고정합니다.
일지는 양피지 카드에 실제 설명·진행 막대·보상을 표시하고, 설정은 청록색 행과 황동 스위치를 사용합니다.
텍스트·아이템 카드·진행 값·구매·닫기는 DOM으로 처리하며 그림에 내용을 구워 넣지 않습니다.
월드 획득 말풍선은 모달보다 아래에 두어 내용을 가리지 않습니다.

## 지역별 적용

숲 마을은 돌 광장·분수·상점·주민을 기준으로 구성합니다. 상점과 첫 퀘스트 주민은 좁은 세로 화면에서도 분수 옆에 보이도록 배치하고 전체 몸체의 유효성을 검사합니다.
숲 전투에 동일한 모험가·몬스터·상자를 사용합니다.
사막에서는 바닥·야자·선인장·사암·천막·미라·파라오를 같은 그림체의 사막 시트로 전환합니다.
도감도 해당 몬스터 그림을 공유합니다. 전용 그림이 없는 적·대형 보스는 기존 그림을 사용합니다.

그림의 발밑을 기존 몸체에 맞추며 HP·공격 범위·충돌·탑승 조건을 변경하지 않습니다.
NPC·상자·탈것·플레이어·적은 표시용 복사본의 발밑 순서로 그립니다. 원본 배열 순서와 게임 난수는 바꾸지 않습니다.
이미지가 로드되지 않았으면 기존 절차형 그림으로 표시하며, 그림 로딩 때문에 게임 시작을 기다리지 않습니다.

## 확인 범위

지역별 화면, 네 방향, 이동·공격, 직접 상점 진입·구매, 탈것의 수동 탑승과 내리기,
패널 일시정지·복귀를 확인합니다. 모바일 세로·가로와 데스크톱 배치를 함께 점검합니다.
실제 화면 캡처와 대표 생성 이미지는 구분합니다.
