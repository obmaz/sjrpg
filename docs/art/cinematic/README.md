# 전투 화면 원본

사용자가 첨부한 어두운 판타지 모바일 RPG 화면을 기준으로 제작한 몬스터 21종, 흑철·청동 원형 버튼 12종, 붉은 금빛 회전 공격·얼음·번개·피격 효과 원본입니다. 모든 원본은 `image_gen`으로 새로 생성했으며, `provenance.json`에 SHA256과 측정 경계를 기록합니다.

몬스터 시트는 동쪽부터 시계 방향 8방향·방향당 두 접촉 자세입니다. 패킹 도구가 연결된 알파 실루엣을 분리하고 실제 그림 경계를 측정한 뒤 게임의 남쪽 시작 순서로 재배열합니다. 칸을 넘어간 무기와 꼬리도 다른 자세와 섞이거나 잘리지 않습니다. 모든 몬스터는 위쪽에서 약 45도 내려다보는 동일한 쿼터뷰를 사용합니다. 몬스터 픽셀은 확대·축소하지 않습니다. 기준 높이는 측정한 원본 몸체 높이의 1/1.5로 기록하며 충돌 크기와 이동·공격 판정은 유지합니다. 버튼은 측정한 그림만 256px 타일에 여백과 함께 축소 패킹합니다. 이전 이펙트 원본은 출처 기록으로 보존하며, 현재 효과는 각각 분리해 생성한 검격·냉기·번개·화염 네 원본으로 교체했습니다. [생성 이펙트 출처](../cinematic-combat-vfx-provenance.json)의 실제 알파 경계를 측정해 512px 셀 네 개에 투명 여백과 함께 패킹합니다. 공통 도구의 VFX 분기는 새 패커에 위임하므로 이전 시트로 덮어쓰지 않습니다.

원본 패킹에는 Python의 Pillow·NumPy·SciPy가 필요합니다.

```sh
python tools/prepare-cinematic-art.py
npm run prepare:new
```

캐릭터의 새 384px 방향별 렌더링과 재현 방법은 [캐릭터 동작](../character-motion.md)에 있습니다.
