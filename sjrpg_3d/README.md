# 자연의 수호자 3D

[3D 모험 실행](https://obmaz.github.io/sjrpg/3d/) · [버전 선택](https://obmaz.github.io/sjrpg/)

Godot4.7.2에서 120° 직교 쿼터뷰를 유지하는 독립3D 프로젝트입니다. `project.godot`를 직접 열어 실행할 수 있습니다. 이전2D판은 저장소의 `../sjrpg_2d/`에 보존합니다.

성문 네 곳은 기본적으로 마을 바깥쪽으로 열립니다. 적이 성벽에 접근하면 닫히고, 주인공이 문에 접근하면 통행을 위해 열리는 기존 규칙을 유지합니다. 게임 화면과 모험 설정에는 표시 방식 배지를 띄우지 않으며, 웹 설정의 저장 후 선택 화면 복귀 기능은 유지합니다.

설정 맨 위에서 전체화면을 켜고 끌 수 있습니다. 설치한 웹 앱은 지원되는 기기에서 전체화면으로 시작하며, 브라우저가 입력을 요구하면 첫 터치/키 입력에서 전환합니다. iOS 등 별도 전체화면 API가 없는 환경은 홈 화면 앱의 기본 화면을 사용합니다. 설치 앱 자체의 전체화면을 임의로 끌 수 없는 플랫폼에서는 현재 상태를 안내합니다.

- `NativeAdventure`:3D 모험 진입점과 기존 UI·진행 어댑터
- `SpatialWorld3D`:실제3D 정적 충돌·지형 높이·CharacterBody3D 배우·성문·마을 안전 경계
- `SpatialCombat3D`:높이·벽·3D 몸체를 반영한 공격과 투사체
- 공간 표시기:입체 건물·나무·배우·시체·지형 장식과 기존 위치/수명을 따르는 마법 효과
- [네 주택 패밀리](docs/native-house-family.md): 같은 재질을 공유하는 여관·대장간·마구간·상점의 실제 문/창 홈·처마·굴뚝·지붕창
- [소환 비석·보물상자](docs/native-encounter-props.md): 공유 입체 모델·종류별 재질과 실제 충전·피격·내구력·개봉 상태
- 기존 숲1장·선택형 동굴·직업·스킬·의뢰·UI·저장 규칙 재사용, 후속 스테이지 추가 없음

전체 화면을 평면 배경으로 붙이지 않으며 공간 표시도 숲·동굴에서 계속 유지합니다. 3D 모델 제작과 게임 규칙 전환은 별개이므로2D 이미지가 보인다는 이유만으로2D 물리를 쓰는 것은 아닙니다. 저장은 `sjrpg_3d` 사용자 경로로 분리합니다.

```sh
tools/check.sh
tools/check.sh --export
```

위 명령은 이 프로젝트 안의 도구입니다. 저장소 루트의 도구는 두 앱을 검사하고 선택 화면을 포함한 로컬 검수 빌드를 만듭니다. 배포의 기본은 Dropbox APK 전달이며, 공개 웹 배포는 별도 요청 시에만 수행합니다. 통합 구조는 [루트 개발 안내](../docs/development.md), 모델·재질·현재 스타일은 [3D 에셋 제작 기준](../docs/3d-asset-guide.md)을 따릅니다. 기존2D 레퍼런스와 비교 모델 문서는 원화·자산의 제작 출처로 유지하며, 현재의 공간 시뮬레이션 구조는 루트 개발 안내가 기준입니다.

마을 분수와 마을·수호자·동굴 내부의 워프문은 입체 석재 모델입니다. 마을 밖 두 이동 지점은 약10cm 두께의 돌 기단을 가진 원형 웨이포인트입니다. 기단 위에 실제로 올라설 수 있습니다. 미발견 상태는 어두운 회색입니다. 문양 안을 밟아야 발견 상태가 저장되고 석재가 차분하게 밝아지며 네 모퉁이에 작은 호박색 불이 켜집니다. 첫 발견 때만 주변에 금빛 고리와 빛 입자가 퍼지고, 화면에는 레벨업과 같은 형식으로 장소 이름과 워프 활성화 안내가 나타납니다. 이미 발견한 지점에서는 반복하지 않습니다. 주변을 지나가는 것만으로 활성화되지 않으며, 동굴과 높은 지형에서 떨어진 빈 공간에 배치합니다. 동굴 웨이포인트에서는 흙길을 따라 바위 골짜기를 내려가면 입구를 찾을 수 있습니다. 빛은 발견 상태를 따르며 일시정지 중에도 유지됩니다.

높은 지형은 지층이 드러난 암반 선반과 뿌리·잔디가 섞인 흙 언덕으로 구분합니다. 가장자리는 넓게 내려오는 사면으로 이어지며 보이는 돌출부와 실제 충돌이 맞습니다. 기존 보행 상면과 진입 경사의 높이는 유지합니다. 필드는 기존 북서 경계를 유지하고 가로·세로를 각각2배(면적4배) 확장했습니다. 강은 확장한 동쪽 경계까지 길게 흐르고, 다리는 강 끝에 가까운 동쪽 지점으로 옮겼습니다. 수면에는 이동하는 물결·반사와 포말이 있습니다. 강 수면은 주변 땅보다1.2m 낮고, 생성형 젖은 암석·흙·자갈·풀 재질을 섞은 약2.8m 폭의 강둑으로 이어집니다. 다리는 두 하부 석조 아치로 강을 건너며, 양 끝의 흙 교대가 원래 길 높이에 연결됩니다. 막다른 포장길은 흙길로 서서히 끝납니다.

동굴 입구는 잘게 파쇄된 비대칭 지층과 기울어진 암괴가 이어지는 넓은 구릉입니다. 포장길에서 떨어진 남동쪽 암반 골짜기를 약20m 내려가면 약4m 폭의 입구에 도달합니다. 바깥 진입로에서3.2m 내려가고, 입구 안쪽으로1.2m를 더 내려갑니다. 표시와 보행 충돌이 같은 하강로를 사용하며, 입구 접근과 동굴 전환은 기존 규칙을 유지합니다. 다리에는 생성형 석재·덮개돌·포장 표면을 구분해 적용합니다. 동굴 안쪽은 바닥6종·벽6종의 흙/자갈/암반·균열/습기/광물 재질을 구역별로 혼합합니다.

남쪽 필드 길에서 바람 동굴까지 풀과 대비되는 넓은 흙·자갈 접근로와 네 곳의 길 표지가 이어집니다. 웨이포인트를 지난 뒤 바위 골짜기로 내려가 실제 입구에 도달합니다.

상자는 이전 입체 모델보다 세 축이2배입니다. 동굴 방 구석의 쇠 상자는4번 타격에 열리며 돈·물약 위주로 나오고, 황금 상자는 적 매복 없이 희귀 이상 장비를 보장합니다. 동굴 상자는 입장마다 새로 생기며 숲 상자 저장 기록과 분리됩니다. 상자는 짙은 고목재·무쇠·고풍스러운 금장에 앞/옆/뚜껑 전용 이미지를 사용합니다.

마을 건물은 저마다 재질이 다릅니다. 대장간은 기존 2D 원본의 밝은 회색 석재와 슬레이트를 기준으로 벽·지붕 표면을 재구성하고, 앞·옆 작업 홈에 선반·목재 작업대·도구·모루를 둡니다. 분수의 아치 조각은 실제 입체로 보강하고 석재에 마모·이끼 질감을 더합니다. 물은 기존 2D 분수의 물 픽셀을 재사용하여 움직이는 잔물결과 두 낙수점의 파문을 표시합니다.  성벽·성문에는 두 종류의 석회암 벽돌·거친 기단석·다듬은 장식석을 섞습니다. 성벽과 성문은 2D 원본의 넓은 석조 벽면·아치형 음각 받침·양쪽 흉벽과 목재 통로를 따릅니다. 네 모서리와 성문 쌍탑은 지붕이 열린 원형 망루이며, 실제 목재 전망 바닥·두꺼운 돌 난간·성가퀴와 깊은 화살창을 갖춥니다. 상점은 차분한 상아색 회반죽, 마구간 집은 결이 보이는 참나무 판재를 사용합니다. 예배당은 원본 화면의 낮은 돌출 입구·높고 가파른 본당 지붕·굵은 종탑을 따른 혼합 모델이며, 확대된 L자 몸체와 왼쪽 입구의3단 계단이 실제 충돌과 맞습니다. 광장 우물은 가로·세로·높이가 각각 두 배이고, 확대된 구조물과 지형에는 실제 이동 충돌을 함께 맞췄습니다.

마을 포장과 바깥 돌길은 서로 어울리는 생성형 바닥6종을 섞습니다. 크고 작은 판석·보수 흔적·마모·이끼·빠진 돌이 구역별로 달라지고, 미세 표면 요철은 실제 광원에 반응합니다. 바깥길은 넓은 흙 경계와 길 안까지 들어온 풀로 이어집니다.

동시에 적 여럿을 맞히면 피해·처치 판정은 즉시 적용하고 데미지 숫자만 기본40ms 간격으로 나눠 띄웁니다. 적이 많으면 대기 중 간격을 줄여 마지막 숫자도 순서를 유지합니다. 표시 대기는 최대200ms이며 팝/상승/수명은 표시 시점부터 시작하고 일시정지 시 대기도 멈춥니다. 초상화/체력 헤더의 왼쪽 여백은 미니맵 오른쪽의 실제 테두리 여백과 같습니다.

주택 외벽은 창·문 그림 없이 실제3D 창틀과 맞물리고, 따뜻한 회벽·참나무·석재와 전용 계단/포장 재료를 사용합니다. 성벽 안쪽에는 발판·난간·받침을 갖춘 상부 통로가 있고 다리 교각에는 강바닥 기초와 물살 가름돌이 있습니다.

명중 순간에는 검이 닿은 자세가 잠깐 유지되고, 적의 상체·머리·무기가 맞은 방향으로 젖혀집니다. 짧은 접촉 불꽃과 단계별 피해 숫자·살/뼈/암석 타격음이 함께 반응하며, 강타와 처치는 순간적인 화면 집중 효과를 더합니다. 동작 줄이기 설정에서는 추가 움직임과 화면 효과를 끕니다. 명중 시 카메라 이동은 최대0.65px, 확대는 최대0.2%이며 연타에도 흔들림이 누적되지 않습니다. 타격감은 몸의 반동·접촉 정지·효과음과 명중 효과로 전달합니다. [타격감 구조와 검수](docs/juice.md)를 참고하세요.

주인공의 걷기·달리기 속도는 기존보다20% 빠르며 키보드·마우스·조이스틱에 동일하게 적용됩니다. 이동 거리에 맞춰 발걸음 동작도 빨라집니다.

플레이어를 가리는 정적 오브젝트는 지붕·벽·장식 등 전체 부품이 같은 투명도로 서서히 옅어지고, 벗어나면 함께 복원됩니다. 나무는 한 그루씩 처리합니다. 몬스터·플레이어·NPC와 움직이는 성문은 대상이 아니며, 연속된 바닥·물·길도 투명하게 만들지 않습니다. 첫 가림 때 끊기지 않도록 판정 메시·투명 재질을 로딩 중에 준비하고, 최근 오브젝트의 재질과 표시 노드를 재사용합니다. 이동 충돌과 공격 차폐는 그대로 적용됩니다. 동굴 벽은 가리는 벽 구간 전체만 함께 옅어지며 떨어진 벽과 묶지 않습니다.

모바일 체력·자원 표시와 미니맵은 안전 영역 위쪽에 가깝게 놓고, 조이스틱과 공격·스킬 부채꼴은 아래쪽으로 내려 중앙 시야를 넓힙니다. 하단 메뉴와 버튼 크기는 유지하며 가로로 돌려도 같은 터치 영역을 사용합니다.

가방과 상점의 장비 목록은 현재 착용 장비와의 능력치 비교를 기본으로 표시합니다. 장비를 누르면 착용·구매 등의 행동 버튼이 펼쳐집니다.

## 외곽 나무

숲 1장의 외곽 나무는 마을과 같은 실제 입체 나무 패밀리를 사용합니다. 원래 위치·크기·충돌을 유지하고, 수관 전체를 포함하는 공간별 묶음으로 표시합니다. 현재 참나무 두 변형을 공유하므로 기존 전나무·버드나무의 종별 모양은 차이가 있습니다. 제작 출처와 검증 계약은 [외곽 숲 나무](docs/native-forest-trees.md)를 참조하세요.

시작 화면에서 모험을 열면 네 개의 저장 슬롯을 선택할 수 있습니다. 빈 슬롯에서는 전사나 마법사를 골라 새로 시작하며, 저장된 모험은 해당 슬롯의 이어 하기로 엽니다. 새 모험은 다른 슬롯을 덮어쓰지 않습니다. 삭제는 슬롯별 확인 후 적용됩니다. 자세한 저장·복구 정책은 [저장 슬롯 안내](docs/save-slots.md)를 참고하세요.

이어 하기나 새 모험 시작을 누르면 로딩 표시가 먼저 나타납니다. 저장 읽기·새 모험 저장·월드 준비 상태를 안내하며, 실제 진행률을 알 수 없는 작업은 회전 아이콘으로 표시합니다. 준비 중에는 중복 시작을 막고, 저장 실패 시에는 선택 화면으로 돌아가 오류를 안내합니다.

마법사의 기본 화염탄과 화염구는 실제 비행 위치에 본체와 짧은 꼬리를 표시하며, 일시정지와 동작 줄이기를 반영합니다.

저장 선택은 번호·수호자 정보·지역/저장 시각을 분리한 네 카드로 표시합니다. 빈 슬롯에는 삭제 버튼을 표시하지 않으며, 선택한 빈 슬롯의 주 버튼은 저장을 만들기 전에 수호자 선택으로 이어집니다. 작은 화면에서는 목록만 스크롤되고 주 행동은 고정됩니다. 삭제 확인 중에는 배경 조작을 막고 취소에 먼저 포커스를 둡니다.

## 입체 배우와 UI 패밀리

고블린·늑대·멧돼지·스켈레톤·골렘·동굴 잠복자는 모두 외부 원본을 변환한 GLB와 종별 `.tscn`을 사용합니다. 각 모델과 시체는 실제 발·공격·피격·사망 수명을 기존 게임에서 읽습니다. [주민](docs/native-residents.md), [전사](docs/native-warrior.md), [몬스터와 시체](docs/native-enemy-models.md), [숲 장식과 랜드마크](docs/native-forest-props.md)에 제작 범위와 공유 재질을 기록합니다. 카메라는 기존 120° 직교 쿼터뷰를 유지합니다. 주인공과 기존 주민의 천·가죽·철·피부·털·바위에는 [생성형 공유 표면](docs/native-actor-surfaces.md)을 적용하며, 몬스터는 종별 원본 UV와 표면을 사용합니다.

물약·하단 메뉴·직업별 아바타는 [회화형 숲 UI 패밀리](docs/woodland-ui-family.md)를 공유합니다. 스킬트리는 같은 청동·아이보리·숯색으로 상태를 구분하고, 모바일 물약과 하단 메뉴 입력 영역은 실제 CSS 크기 44px 이상으로 배치합니다.

검수의 `remaining_sources`는 숲·동굴에 남은 물리 오브젝트 원화만 기록합니다. 바닥·물·마법 입자·이름표·UI의 평면 표시는 별도이며, 이를 입체 모델로 완료 처리하지 않습니다. 주민·전사·다섯 몬스터의 실제 네 방향과 모바일 가로·세로 화면은 `native-style-review.yml`의 비교 캡처로 확인합니다.

설정의 화면 확대는 `0.5× / 0.75× / 1× / 1.25× / 1.5×`이며, 기본 `1×`는 이전 실제 배율 `0.75`의 넓은 시야를 사용합니다. 각 선택의 실제 배율은 `0.375 / 0.5625 / 0.75 / 0.9375 / 1.125`입니다. 기존 확대 선택은 그대로 유지되며 HUD·글자·입력 영역은 바뀌지 않습니다.

화면 방향은 설정에서 `자동 / 가로 / 세로`를 선택하며 이 기기에 저장합니다. Android는 시작할 때와 변경 즉시 적용합니다. 웹은 브라우저가 지원하는 화면 방향 API를 사용하며, 고정할 때 전체화면 허용이 필요할 수 있습니다. 거절되거나 지원하지 않으면 설정에 안내하고, 자동을 선택하면 방향 고정을 해제합니다. 브라우저 실행 시 저장한 고정을 적용하려면 해당 버튼을 다시 눌러야 할 수 있습니다.

설정의 `FPS 표시`를 켜면 게임 화면 왼쪽 아래에 현재 프레임 수를 표시합니다. 기본은 꺼짐이며, 선택은 이 기기에 저장됩니다.

상자의 현재 크기·충돌 기준은 [상자 규격](docs/native-chest-scale.md), 독립 모델 제작과 교체 방법은 [에셋 협업](docs/asset-workflow.md)을 따릅니다. 무료 에셋 출처·라이선스는 [재사용 기준](../docs/free-asset-sources.md)에서 확인합니다.

마을 상인과 보급원 미라는 상업적 이용·수정이 허용된 Quaternius CC0 모델을 사용합니다. 상인의 남성 평민 복장과 미라의 여성 레인저 복장은 체형·후드·장구가 다르며 실제 골격 대기 동작을 따릅니다. 다른 여섯 주민은 역할별 기존 모델을 유지합니다. 원본 라이선스·체형에 맞춘 동작 변환·모바일 예산은 [주민 제작 안내](docs/native-residents.md)에 기록합니다.

## Xbox 게임패드

Xbox 표준 버튼 배치를 사용하는 패드를 연결한 뒤 버튼을 눌러 활성화합니다. 왼쪽 스틱은 기울기에 따라 이동 속도가 달라지고, 오른쪽 스틱은 조준 방향을 정합니다. 오른쪽 스틱을 놓으면 기존 자동 조준을 사용합니다.

| 입력 | 모험 중 동작 |
| --- | --- |
| 왼쪽 스틱 | 이동 |
| 오른쪽 스틱 | 조준 |
| A | 주 스킬 |
| X / Y / RB / RT | 보조 스킬 1 / 2 / 3 / 4 |
| B | 구르기 |
| LT | 가까운 NPC·워프문·동굴과 상호작용 |
| LB | 체력 물약 |
| 십자키 ↑ | 자원 물약 |
| 십자키 ← / → / ↓ | 장비·가방 / 퀘스트 / 스킬 |
| 보기 버튼 | 전체 지도 |
| 메뉴 버튼 | 설정 |

메뉴에서는 왼쪽 스틱·십자키로 항목을 선택하고 A로 실행하며 B로 한 단계 뒤로 갑니다. 긴 내용은 오른쪽 스틱으로 스크롤합니다. 삭제 확인은 취소에 먼저 포커스를 둡니다. 패드를 사용할 때 HUD에 Xbox 버튼 안내가 표시되며 키보드·마우스·터치를 사용하면 기본 표시로 돌아갑니다.

연결 직후나 메뉴·로딩·일시정지에서 돌아온 뒤에는 버튼과 스틱을 잠시 놓으면 입력이 다시 활성화됩니다. 연결이 끊기면 남은 이동·공격 입력을 해제합니다. 브라우저에서는 패드가 인식되도록 먼저 버튼을 눌러야 하며, 최초 소리·전체화면 활성화에는 화면 터치나 클릭이 필요할 수 있습니다.

캐릭터 선택·이어하기는 [생성형 선택 화면 시안](docs/selection-screen-design.md)을 바탕으로 한 회화형 숲 UI를 사용합니다. 선택한 직업의 일러스트와 실제 능력치를 표시하며, 저장 카드에는 직업 초상화·슬롯 번호·레벨·지역·저장 시각을 구분해 표시합니다. 가로 화면에서는 일러스트와 조작 영역을 나란히 놓고, 저장 목록은 영역 안에서 스크롤하며 시작·이어하기 버튼은 별도로 유지합니다.

웹 렌더링은 실제3D 버퍼의 픽셀 상한과 일시정지 중 화면 유지를 적용합니다. 이전2D 배우 시트는 실제 원화 표시가 필요할 때만 읽고, 반복 몬스터 생성은 메시를 재사용합니다. 에셋 용량·실제 텍스처 메모리·검증 범위는 [웹 성능과 에셋 예산](docs/web-performance.md)을 참고하세요.

미니맵 또는 M 키로 여는 지도는 실제 건물·성문·NPC·동굴 위치를 공유합니다. 지도 번호나 장소 목록을 누르면 해당 위치를 확대하며 캐릭터는 이동하지 않습니다. 발견 전·후 웨이포인트도 같은 목록에서 유형별 색상과 이름으로 구분합니다. 목록은 행 위에서 손가락으로 드래그하며, 긴 이름·안내는 줄바꿈해 읽고, `전체`·`내 위치`·확대/축소·드래그로 시야를 조절합니다. [지도와 안식처 안내](docs/world-map.md)를 참고하세요.

일시정지 중 화면을 회전해도 미니맵·상태창·조작 버튼·알림이 새 화면에 맞춰 재배치됩니다. 표시 갱신으로 모험이나 알림 시간이 흐르지는 않습니다.

모바일에서는 최종 합성 화면도 최대 약200만 픽셀·기기 배율2배로 제한합니다. 폴드·고밀도 화면에서 UI 논리 크기와 터치 좌표를 유지하며, 3D 월드의 별도 해상도 상한과 함께 적용합니다. 3D로 교체된 배경의 원래 원화는 실제 대체 표시가 필요할 때만 불러옵니다. 미니맵 지형도 정지 상태에서는 같은 메시를 재사용하며, 이동으로 표시 영역이 바뀌거나 실제 지형·건축이 변경될 때 갱신합니다.

배경음악은 긴 곡 전체를 반복 복사하지 않는 스트리밍 재생을 사용합니다. 마을·숲·동굴의 교차 재생과 배경 전환 시 일시정지·재개를 유지하며, 재생 상태는 실제로 바뀔 때만 갱신합니다.

웹·Android 내보내기는 [플랫폼별 설정](docs/platform-exports.md)을 따릅니다. 불투명 월드 표면10장에는 S3TC/ETC2 GPU 압축을 적용하고 UI·투명 경계·현재 배우 표면은 기존 품질을 보존합니다. 검수 방법과 측정 범위는 같은 문서에 기록합니다.

개발·제작 문서는 [문서 목록](docs/README.md)에서 찾습니다.

마을의 네 주택과 예배당은 기존 건물 원화를 바탕으로 만든 외벽 전체 이미지를 사용합니다. 앞뒤 박공과 양 측면마다 다른 석재 배치·회반죽 보수·목조 이음새·마모를 표현하며, 문·창·기둥과 처마는 실제3D 형태를 유지합니다.

게임 중 Android 시스템 뒤로가기와 웹 브라우저 뒤로가기는 모험을 종료하지 않고 설정을 엽니다. 설정이 이미 열려 있으면 유지하고, 다른 팝업은 설정으로 바꿉니다. 웹 전체화면 해제도 게임 중에는 설정으로 연결됩니다. 키보드 Esc와 게임패드 B의 기존 메뉴 조작은 유지합니다.

## 동굴 입구의 잠복자 무리

동굴 입구 옆 비석을 공격하면 **동굴 잠복자20마리**가 한 번에 나타납니다. 살아 있는 무리가 있으면 추가 소환하지 않으며, 모두 처치한 뒤 비석을 다시 공격하면20마리를 재소환합니다. 기존 여섯 비석의 충전 규칙은 유지합니다.

이 무리는 갈고리 발톱과 등뼈, 움직이는 턱을 가진 실제3D 잠복자로 표시합니다. 검을 든 적은 무기를 휘두르고 짐승은 도약하거나 물어뜯습니다. 해골의 도끼 공격·피격은 발이 지면에 붙은 원본 동작을 유지합니다. 준비·타격·복귀 모션은 실제 공격 상태와 피해 시점을 따르며, 시체도 같은 입체 모델을 사용하다 기존 수명이 끝나면 사라집니다.

피해받은 몬스터 위에는 체력과 최근 피해 구간을 표시합니다. 일반 몬스터는 공격을 준비할 때 머리 위의 작은 황금색 게이지가 차오르고 타격·중단 때 사라집니다. 숲의 파수꾼의 내려치기 예고는 실제 타격 범위와 같은 지면 영역에 표시하고, 운석 예고·잔불과 화염벽·눈보라의 지속 범위도3D 공간에서 표시합니다. 이 표시는 실제 효과 수명과 일시정지·동작 줄이기를 따릅니다.

동굴 횃불은 이전보다1.7배 크게 표시하며, 실제 안쪽 벽면의 철제 고정판·받침대에 매달립니다. 바닥에 세우지 않고 불꽃과 기존 열 개의 광원을 같은 횃불 머리 위치로 옮깁니다. 불꽃은 기존 동굴 조명 시계와 일시정지·동작 줄이기 설정을 따릅니다.

설정과 승리 화면에서 타이틀·슬롯 선택으로 이동할 때는 저장 성공을 먼저 확인합니다. 저장에 실패하면 같은 팝업과 일시정지를 유지하고 오류를 안내하며, 현재 진행을 유지한 채 재시도할 수 있습니다.

집은 건물마다 생성한 네 면의 전용 벽면 이미지를 사용합니다. 예배당은 사용자 실제 화면에 맞춘 돌출 입구·두 지붕·종탑에 전용 면 그림을 붙입니다. 상점은 상아색 회반죽과 석재 기단, 대장간은 밝은 중성 석재, 마구간은 참나무 판재, 주택은 허브 문양이 있는 크림색 회벽, 예배당은 옅은 석재 부조로 구분됩니다. 바위에는 지의류·철 광맥 표면이 위치별로 고정되며, 고지대는 헤더 들판과 이끼 지면을 구별합니다. 몬스터의 피부·털·뼈는 연속 곡면 법선과 종별 표면을 사용하고 늑대의 송곳니·해골의 눈구멍·돌 골렘의 균열을 실제 입체 형태로 표시합니다.

숲과 마을에는 기존 활엽수 2종과 함께 어두운 전나무·소나무·측백 계열 3종이 섞여 나타납니다. 침엽수는 가지와 고정된 곡면 바늘잎으로 뾰족한 수관을 만들며, 줄기 주변에는 주니퍼·가시 관목이 추가됩니다. 같은 나무의 종류와 방향은 다시 접속해도 바뀌지 않습니다. 기존 줄기 충돌과 통행 경계는 유지합니다.

다리는 연속된 석재 기단 위에 기둥·줄눈 있는 덮개돌·얕은 아치 장식과 철물을 갖춥니다. 아치 뒤의 석재를 유지한 장식 난간으로, 다리의 통행 폭·높이·투사체 차폐는 기존 규칙을 따릅니다.

낮은 지면은 생성형 포장6종과 잔디10종을 혼합합니다. 실제 길의 코너·교차로 모양에 맞춰 빠진 돌·흙·클로버·잔풀로 경계를 다듬으며 포장은 얕은 실제 요철을 공유합니다.

모든 몬스터는 이전보다 높이와 폭이 30% 커졌습니다. 표시뿐 아니라 실제 충돌·체력 표시·피격 위치·시체도 같은 크기를 따릅니다. 몸 가장자리에서 닿는 근접 사거리를 유지하도록 중심 기준 사거리만 보정하며 체력·피해량·보상은 바꾸지 않습니다.

3D판의 잔디와 강물은 각각 독립 생성형 이미지10종을 월드 좌표에서 혼합합니다. 풀 밀도·마른 잎·흙·자갈·들꽃과 물결·흐름·소용돌이·포말의 질감 차이를 주며 작은 군락과 넓은 구역이 자연스럽게 이어집니다. 낮은 들판과 높은 지형은 같은 풀 패밀리를 공유하고 강물은 기존 흐름·강둑 경계·일시정지 시계를 따릅니다. 자세한 구조는 [야외 표면](docs/native-outdoor-surfaces.md)을 따릅니다.

몬스터 보행은 각 GLB의 발 접지 구간에서 측정한 보폭과 실제 지면 이동 거리로 재생합니다. 이동 속도와 공격 판정은 유지하며 느린 이동·벽 정지·몸체 확대에도 보행 주기를 맞춥니다. 잔디는 네 방향으로 겹친 표면의 가중치를 정규화해 사각 이음선과 교차점 누출을 줄입니다.

마을 주택 네 채·예배당·성곽/성문·다리도 [GLB + 개별 씬](docs/native-architecture-models.md)으로 불러옵니다. 기존 생성형 벽면·기와·석재는 씬에서 연결하고, 문짝의 회전축과 실제 보행·충돌 규칙을 유지합니다. 생성기는 오프라인 제작 도구로 분리했습니다.

몬스터 여섯 종의 GLB 보행은 실제 이동 거리와 지지발의 누적 변위 표를 연결해 접지 중 발의 앞뒤 미끄러짐을 줄입니다. 벽 정지·일시정지·밀침은 원래 이동 규칙을 유지합니다.

워프는 약0.7초의 푸른 빛과 함께 사라진 뒤 도착지에서 다시 나타납니다. 프레임이 지연돼도 연출 단계를 보존하며 이동/공격만 잠그고 쿨다운·버프·회복 시간은 계속 흐릅니다. 메뉴 일시정지는 연출과 모험 시간을 함께 멈춥니다. 멧돼지와 잠복자의 시체는 실제 골격이 옆으로 쓰러진 자세로 바닥에 놓입니다. 시체는 모험 시간15초 뒤 제거하며 마지막3초 동안 서서히 사라집니다. 동굴 방문 중에도 숨겨진 필드 시체의 수명이 흐릅니다. 스킬 대상과 실제3D 몸체가 함께 정리됩니다.

바람 동굴은 방마다 오르내리는 경사와 높은/낮은 분기로 이어집니다. 가시판과 벽 화염은 바닥 예고와 남은 시간을 보고 피할 수 있으며 몬스터를 유인해 맞힐 수도 있습니다. 멀리 있는 방의 적이 순찰만 하다 함정으로 소모되지 않도록 주변 전투 범위에서 피해를 처리합니다. 지도에는 장치 위치와 종류, 바닥의 높낮이를 표시합니다. 쇠 상자는 타격에 뚜껑이 살짝 반응하고, 개봉하면 뚜껑이 짧고 부드럽게 열립니다. 동작 줄이기에서는 즉시 열린 모습으로 표시합니다. 아직 열지 않은 황금 상자는 금색, 쇠 상자는 청회색으로 두 지도와 장소 목록에 표시하며, 선택하면 실제 위치로 확대합니다. 쇠 상자의 남은 내구도도 확인할 수 있고 개봉하면 표식이 사라집니다. [동굴 구조와 트랩](docs/native-cave.md)을 참고하세요.

동굴에서는 방별 남은 적과 정리한 방 수를 안내합니다. 방 밖으로 쫓아온 적도 출신 방에 반영하며, 지도에서 각 방의 남은 적을 확인할 수 있습니다. 모든 적을 정리하면 마지막 귀환문에서 추가 보상을 받도록 안내합니다.
