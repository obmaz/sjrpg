# 자연의 수호자 3D

[3D 모험 실행](https://obmaz.github.io/sjrpg/3d/) · [버전 선택](https://obmaz.github.io/sjrpg/)

Godot4.7.2에서 120° 직교 쿼터뷰를 유지하는 독립3D 프로젝트입니다. `project.godot`를 직접 열어 실행할 수 있습니다. 이전2D판은 저장소의 `../sjrpg_2d/`에 보존합니다.

성문 네 곳은 기본적으로 마을 바깥쪽으로 열립니다. 적이 성벽에 접근하면 닫히고, 주인공이 문에 접근하면 통행을 위해 열리는 기존 규칙을 유지합니다. 게임 화면과 모험 설정에는 표시 방식 배지를 띄우지 않으며, 웹 설정의 저장 후 선택 화면 복귀 기능은 유지합니다.

설정 맨 위에서 전체화면을 켜고 끌 수 있습니다. 설치한 웹 앱은 지원되는 기기에서 전체화면으로 시작하며, 브라우저가 입력을 요구하면 첫 터치/키 입력에서 전환합니다. iOS 등 별도 전체화면 API가 없는 환경은 홈 화면 앱의 기본 화면을 사용합니다. 설치 앱 자체의 전체화면을 임의로 끌 수 없는 플랫폼에서는 현재 상태를 안내합니다.

- `NativeAdventure`:3D 모험 진입점과 기존 UI·진행 어댑터
- `SpatialWorld3D`:실제3D 정적 충돌·지형 높이·CharacterBody3D 배우·성문·마을 안전 경계
- `SpatialCombat3D`:높이·벽·3D 몸체를 반영한 공격과 투사체
- 공간 표시기:입체 건물·나무·마법사와,3D 에셋이 없는 대상의 개별2.5D 원화 메시
- [네 주택 패밀리](docs/native-house-family.md): 같은 재질을 공유하는 여관·대장간·마구간·상점의 실제 문/창 홈·처마·굴뚝·지붕창
- [소환 비석·보물상자](docs/native-encounter-props.md): 기존 재질·위치·충돌을 유지하는 입체 모델과 실제 충전·피격·소모 상태
- 기존 숲1장·선택형 동굴·직업·스킬·의뢰·UI·저장 규칙 재사용, 후속 스테이지 추가 없음

전체 화면을 평면 배경으로 붙이지 않으며 공간 표시도 숲·동굴에서 계속 유지합니다. 3D 모델 제작과 게임 규칙 전환은 별개이므로2D 이미지가 보인다는 이유만으로2D 물리를 쓰는 것은 아닙니다. 저장은 `sjrpg_3d` 사용자 경로로 분리합니다.

```sh
tools/check.sh
tools/check.sh --export
```

위 명령은 이 프로젝트 안의 도구입니다. 저장소 루트의 도구는 두 앱을 검사하고 선택 화면과 함께 배포합니다. 통합 구조는 [루트 개발 안내](../docs/development.md), 모델·재질·현재 스타일은 [3D 에셋 제작 기준](../docs/3d-asset-guide.md)을 따릅니다. 기존2D 레퍼런스와 비교 모델 문서는 원화·자산의 제작 출처로 유지하며, 현재의 공간 시뮬레이션 구조는 루트 개발 안내가 기준입니다.

3D판 분수와 모든 워프문은 기존 측정 바닥 범위 안에 놓인 입체 석재 모델입니다. 분수의 두 수면·물줄기와 워프문의 소용돌이·작은 입자는 원래 상호작용의 시계를 따르며, 일시정지와 동작 줄이기를 반영합니다. 이동 충돌과 목적지·진행 규칙은 기존 공간 데이터를 유지합니다.

## 외곽 나무

숲 1장의 외곽 나무는 마을과 같은 실제 입체 나무 패밀리를 사용합니다. 원래 위치·크기·충돌을 유지하고, 수관 전체를 포함하는 공간별 묶음으로 표시합니다. 현재 참나무 두 변형을 공유하므로 기존 전나무·버드나무의 종별 모양은 차이가 있습니다. 제작 출처와 검증 계약은 [외곽 숲 나무](docs/native-forest-trees.md)를 참조하세요.

시작 화면에서 모험을 열면 네 개의 저장 슬롯을 선택할 수 있습니다. 빈 슬롯에서는 전사나 마법사를 골라 새로 시작하며, 저장된 모험은 해당 슬롯의 이어 하기로 엽니다. 새 모험은 다른 슬롯을 덮어쓰지 않습니다. 삭제는 슬롯별 확인 후 적용됩니다. 자세한 저장·복구 정책은 [저장 슬롯 안내](docs/save-slots.md)를 참고하세요.

마법사의 기본 화염탄과 화염구는 실제 비행 위치에 본체와 짧은 꼬리를 표시하며, 일시정지와 동작 줄이기를 반영합니다.

저장 선택은 번호·수호자 정보·지역/저장 시각을 분리한 네 카드로 표시합니다. 빈 슬롯에는 삭제 버튼을 표시하지 않으며, 선택한 빈 슬롯의 주 버튼은 저장을 만들기 전에 수호자 선택으로 이어집니다. 작은 화면에서는 목록만 스크롤되고 주 행동은 고정됩니다. 삭제 확인 중에는 배경 조작을 막고 취소에 먼저 포커스를 둡니다.
