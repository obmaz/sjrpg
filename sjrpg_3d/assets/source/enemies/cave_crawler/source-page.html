Preview: 

Usually we release city building game art, but we're working on a new kit right now and are giving away the game monster we've made. This is a 3D model we're releasing into the public domain for use in your Unity games. Comes from the Horror Game Maker set. Includes multiple poses, various skins, an a few animations. Integrate in your own Unity game projects.

Includes:

  • 3D character models
  • Run animation
  • Attack animation
  • Jump animation
  • Walk animation
  • Various poses
  • 3 color schemes

Let me know if you have any questions or requests!
