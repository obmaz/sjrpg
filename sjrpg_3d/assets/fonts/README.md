# 글꼴

기존 HUD와 공용 패널은 NanumGothic을 유지합니다. 수호자 선택·모험 이어가기는
사용자가 지정한 `selection-and-continue-concept.png`의 명조형 글자를 따라
NanumMyeongjo Regular/Bold를 사용합니다. `SelectionUi` 안에서만 적용합니다.

두 글꼴은 NHN Corporation의 원본이며 SIL Open Font License 1.1로 배포합니다.
원본을 수정하지 않았습니다. NanumMyeongjo의 원문 라이선스는
[NanumMyeongjo-OFL.txt](NanumMyeongjo-OFL.txt)에 보존합니다.

출처: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo

| 파일 | SHA-256 |
| --- | --- |
| `NanumMyeongjo-Regular.ttf` | `7ed9e8653a8ed04285d51dc343ffea6eb3d9c73afc27383ea8929ee4ffd03205` |
| `NanumMyeongjo-Bold.ttf` | `bc9ed8e60d93fe6db054b8fb988481b625f2eef8cb2317ad0e9834681b8fe3f3` |

다운로드 원본 URL은 위 출처의 동일 파일명이며 실제 배포 글꼴의 해시를 기록합니다.
폰에서 본문 글자는 최소12 CSS px, 주요 조작 영역은 최소44 CSS px를 유지합니다.
