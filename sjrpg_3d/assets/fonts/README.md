# 글꼴

HUD와 공용 패널·작은 설명·수치·저장 메타는 NanumGothic을 사용합니다.
수호자 선택의 큰 제목·직업명·주 버튼은 NanumMyeongjo Bold를 사용합니다.
작은 본문은 획이 잘 읽히는 고딕으로 통일하고 명도와 실제 표시 크기를 확보합니다.
사용하지 않는 NanumMyeongjo Regular 배포 파일은 제거했습니다.

NanumMyeongjo는 NHN Corporation의 원본이며 SIL Open Font License 1.1로 배포합니다.
원본을 수정하지 않았으며 원문 라이선스는
[NanumMyeongjo-OFL.txt](NanumMyeongjo-OFL.txt)에 보존합니다.

출처: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo

| 파일 | SHA-256 |
| --- | --- |
| `NanumMyeongjo-Bold.ttf` | `bc9ed8e60d93fe6db054b8fb988481b625f2eef8cb2317ad0e9834681b8fe3f3` |

다운로드 원본 URL은 위 출처의 동일 파일명이며 실제 배포 글꼴의 해시를 기록합니다.
폰에서 본문 글자는 최소14 CSS px/Android dp, 주요 조작 영역은 최소44 CSS px/Android dp를 유지합니다.
