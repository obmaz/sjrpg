# 타격감 개선 계획과 현재 상태

현재 구현 계약은 [전투 피드백과 타격감](juice.md)입니다. 이 문서는 최근 병합된 제안을
현행 코드와 대조해 다음 작업의 범위를 정합니다. 이전 리포트의40/55ms 정지,
단일 명중음, 시체 없음이라는 진단은 현재 구현을 설명하지 않습니다.

## 적용 순서와 판단

| 순서 | 채널 | 현재 구현과 다음 판단 |
| --- | --- | --- |
| 1 | 화면 | 작은 왕복 반동을 적용했습니다. 사용자의 작은 흔들림 요청을 우선하며 큰 진폭 제안은 적용하지 않습니다. |
| 2 | 소리 | 기존 접촉 박자와8보이스를 유지합니다. 실제 명중음이 재생될 때 음악을 잠깐 낮추는 분리 단계를 적용했습니다. |
| 3 | 시간 | 일반50ms·강타90ms·처치120ms의 배우 로컬 정지를 적용했습니다. 접촉 묶음의 정지는 더하지 않고 가장 강한 단계까지만 승격합니다. |
| 4 | 명중 표시 | 실제3D 접촉점의 카드·몸통 플래시·공유 파편을 사용합니다. 낮 숲과 동굴의 실제 화면을 비교한 뒤 추가 면적을 판단합니다. |
| 5 | 적 반응 | 실제 피격 자세·방향 반동·쓰러진3D 시체와 만료 처리를 사용합니다. 진동 길이는 실제 기기에서 청음·촉감과 함께 조정할 대상입니다. |
| 6 | 큰 체력 대상 | 현재 최대 체력의10%/30%로 MEDIUM/HEAVY를 나눕니다. 보스의 강타 구분은 피해량·공격 종류·기존 피격 모션을 함께 플레이 검증한 뒤 조정할 후보입니다. |

기존 입력 반응 속도와 빠른 공격을 유지합니다. 준비 동작을 늘리기 위해 기본 공격 전체를
일괄 느리게 하거나, 처치·약점·스킬 타격을 모두 강타로 승격하는 변경은 현재 계획에 포함하지 않습니다.

## 소리 분리 단계

실제 명중음이 출력될 때 음악에 최대3dB 감쇄를 줍니다.80ms 동안 유지하고120ms에 걸쳐
복귀하며, 연타는 감쇄량을 더하지 않습니다. 기존 명중/재질 악센트의 음량과 PCM 원본은 유지해
동시 재생의 헤드룸을 보존합니다. 더 큰 명중음 이득은 실제 휴대폰의 연속 전투 청음 후 판단합니다.

음소거·보이스 제한·게이트로 타격음이 재생되지 않은 경우 음악도 낮추지 않습니다.
음악 설정, 동작 줄이기, 메뉴 일시정지, 앱 포커스, 지역 전환과 종료에서 효과의 수명을 정리합니다.
음악은 기존 한 곡 재생·페이드 정책을 유지하고 새 재생기나 전역 오디오 버스를 추가하지 않습니다.

## 유지할 경계

- 피해·보상·재사용 시간·충돌 판정은 연출 때문에 지연하거나 변경하지 않습니다.
- `ContactRhythm`은 최대3개의 대기 박자를 관리하며 동시 타격을 짧은 후속 악센트로 나눕니다.
- `GameTempo.ContactStop`은 적과 근접 공격자만 정지합니다. 월드 전체의 시간을 멈추지 않습니다.
- `Prefs.reduce_motion`, 소리·음악 설정, 일시정지와 지역 전환을 따릅니다.
- 파편·음성·효과 풀의 상한을 보존합니다. 상한을 늘린다는 이유만으로 체감 개선을 주장하지 않습니다.

## 검증

기능별 구현과 독립 검증은 최대3회로 제한하며, 일회성 하네스 결과는 `build/reports/`에 둡니다.
관련 회귀 검사와 로컬 전체 검사 후 실제 브라우저 가로·세로에서 명중과 메뉴 동작을 확인합니다.

```sh
sjrpg_3d/tools/check.sh --only=music,combat_audio,contact_rhythm,native_hit_feel,juice_tier
tools/ci.sh
```

카메라와 진동의 촉감, 폰 스피커에서 음악과 타격음의 분리는 정적 캡처로 판정하지 않습니다.
Android 실기에서30초 이상 연속 전투의 청음·촉감·피로도를 확인해야 하며,
로컬 자동 검사 통과를 실기 체감 검증으로 표시하지 않습니다.

- 진동: `scripts/state/prefs.gd`
