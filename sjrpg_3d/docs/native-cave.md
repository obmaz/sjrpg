# 기존 바람 동굴의 입체 암벽

숲1장의 기존 동굴만 다룹니다. 방5개·양쪽 분기·출구·전투·보상·충돌 정책은 변경하지 않습니다. 최상위 미감은 `assets/source/style/approved-game-reference.jpg`, 지하 공간의 기존 제작 자료는 `assets/data/cave_art.json`의 회색 층상 암반·풍화된 석판·호박색 등불 패밀리입니다. 이 문서는 제작 계약이며 실제 모바일 화면 검수의 완료 기록이 아닙니다.

## 기하와 소유권

`Ortho3DCaveRock`은 `DungeonArt.boundary_segments`에 기록된 실제 방/통로 합집합의 경계를 사용합니다. 이 값은 귀환문 같은 독립 소품 충돌이 추가되기 전의 경계이며, 소품을 새 방이나 절벽으로 바꾸지 않습니다. 물리는 기존 `SpatialWorld3D`의 경계 박스와 바닥을 그대로 사용합니다.

- 좌표는 `+Y` 위·지면`XZ`,65지면 단위/m입니다. 카메라45°/35.2643897°와 화면 축±30°는 유지합니다.
- 안쪽 바닥 접점은 물리 경계 박스의 반두께와 같은4cm 안쪽이며, 실제 암벽은 걸을 수 없는 바깥쪽으로 약1.05m 부피를 가집니다.
- 바닥·안쪽 경사 면·깎인 능선·뒤쪽 면·하부까지 닫힌 단면입니다. 같은 끝점은 공통 마이터와 높이를 사용해 양 방향과 모서리가 연결됩니다.
- 뒤쪽 방 경계는 최대3.5m, 뒤쪽 통로는1.45m, 앞쪽은0.45m를 기준으로 고정된 자연 실루엣을 만듭니다. 앞쪽과 일부 통로는 전투 시야를 위한 **시각적 컷어웨이**이며 실제3.5m 충돌벽이 낮아졌다는 뜻이 아닙니다.
- 12m 단위의 공간 청크로 나누어 재질 한 개를 공유합니다. 모델 예산은2만 삼각형·8개 청크 이내이며 실제 반환값과 브라우저 비용을 별도로 확인합니다.

기존 원화 중 `cave_role == "wall"`인 벽 조각과 끝 바위만 네이티브 표시 목록에서 제외합니다. 등불과 벽이 같은 아틀라스를 사용하므로 아틀라스 전체를 제거하지 않습니다. 아직 입체 자산이 없는 아치·등불·귀환문은 개별 원화 메시로 남습니다. 소스 어댑터 노드·로컬`visible`·게임 시계는 유지하며 소스 캔버스를 다시 표시하지 않습니다.

## 재질과 조명

`assets/art/cave/dark.webp`의 기존 생성형 평면 암반을2.6m 세계 좌표 타일로 사용합니다.512px 기준 약197px/m이며 법선은 실제 암벽 면의 기하에서 구합니다. 별도의 법선·거칠기 스캔은 만들지 않았습니다. 기존 알베도의 미세 자체 음영은 남으며 PBR 스캔이라고 주장하지 않습니다. 바닥도 같은2.6m 배율을 유지하고 넓은 어둠을 알베도에 덧그리지 않습니다.

동굴에 들어갈 때만 차가운 주변광과 약한 방향성 산란광, 입구의 고정 반사광을 사용합니다. 등불이 없는 입장 방에서도 남색 옷과 발밑 석판이 읽히도록 설계합니다. 실제 등불10개의 따뜻한 위치·범위·게임 시간 기반 미세 변화는 유지합니다. 방향광 그림자는 기존1024 아틀라스의 한 패스를 사용하고, 등불·입구 반사광에는 별도 그림자 패스를 추가하지 않습니다.

숲의 태양·반사광 설정은 변경하지 않습니다. 동굴 진입 직전의 주변광 색/세기·배경색을 기록해 복귀 때 정확히 복원합니다. 전체 화면 블룸·GI·색 필터·추가 후처리 패스는 사용하지 않습니다. 구체적인 후보 수치는 `assets/data/native_cave_geometry.json`에 기록합니다.

## 검수

`native_cave_geometry`는 실제 메시 삼각형의 닫힘·유한한 법선/UV·앞면 감기·모서리 공유·물리 경계 접점을 검사하고 실제3D 캡슐 이동으로 같은 경계가 막히는지 확인합니다. 교체/유지 원화의 인스턴스 ID를 비교해 등불·아치가 잘못 제거되지 않았는지도 확인합니다. 조명은 동굴 진입/정지/복귀의 수명과 숲 설정의 복원을 검사합니다.

최종 채택 전에는 같은 위치의 세로/가로 변경 전·후 화면을 나란히 보고 남색 배우·바닥·등불의 명암, 모든 암벽 방향과 코너, 통로/귀환문 접근, 실제 명중광을 확인해야 합니다. 라이브 회전·양 화질에서 WebGL 오류와 공간 그리기/삼각형/그림자 수를 함께 기록합니다. 헤드리스 기하 검사는 이 시각 검수를 대신하지 않습니다.

2026-11-06 Godot4.7.2 헤드리스 검증에서 `native_cave_geometry`, `native_environment` 두 케이스가 모두 통과했습니다(실패0,2.504초). 실제 메시와3D 벽 레이/캡슐 이동 검증을 포함합니다. GPU 비교 화면과 라이브 회전 검수는 대기 중입니다.
