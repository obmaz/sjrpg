# 바람 동굴의 입체 공간

숲1장의 기존 바람 동굴만 다룹니다. 방5개·분기·출구·전투를 유지하고 실제 오르내리는 바닥과 주기형 트랩을 사용합니다. 카메라는120° 직교 투영이며 [3D 제작 기준](../../docs/3d-asset-guide.md)을 따릅니다. 바닥과 벽의 생성형6종 재질·원본·혼합 방식은 [동굴 재질](native-cave-surfaces.md)이 기준입니다.

## 기하와 소유권

`CaveWallGeometry3D`은 `DungeonArt.boundary_segments`의 원래 방/통로 합집합 경계를 사용합니다. 귀환문 같은 독립 소품 충돌을 새 절벽으로 바꾸지 않습니다. `DungeonRelief`의 합집합 바닥과 경사·벽 부피를 렌더링과 `SpatialWorld3D`가 공유하며 배우 캡슐로 보행합니다.

좌표는`+Y` 위·지면`XZ`,65지면 단위/m입니다. 안쪽 발치는 실제 경계 충돌의 반두께와 같은4cm 안쪽이고, 바깥 암반은 약1.6m 부피를 갖습니다. 바닥·안쪽 경사·능선·뒤쪽·하부 삼각형이 닫힌 부피를 구성합니다. 전경은0.32m 절단면으로 낮게 유지하고 바깥 하부는 보행면 아래1.35m의 실제 암반으로 이어집니다. 뒤쪽 벽은 큰 층리와 돌출·후퇴하는 단면으로 높이를 유지하며 낮은 모서리로2m에 걸쳐 연결합니다.

뒤쪽/옆쪽 벽의 하부 chamfer와 중간 크기 파쇄 암반은 같은 닫힌 벽 메시입니다. 실제 보행 합집합 바깥에만 놓고 전경/트랩 진입에는 흩뿌리지 않습니다.

원래 연결된 직선 벽 구간마다 하나의 가림 오브젝트를 만듭니다. 그 벽의 안쪽과 바깥쪽 재질은 같은 투명도로 전환하고 떨어진 반대쪽 벽을 함께 묶지 않습니다. 바닥·몬스터는 정적 벽 소유권에 포함하지 않습니다. 원래2D 소스는 숨겨진 진행/배치 어댑터이며 표시기의 실제3D 소유권을 따릅니다.

외부 입구는 같은 하강 바닥과 암반 충돌을 유지하며 겹친 비대칭 사선 처마·좌우 지지 암반·위로 좁아지는 곡선 개구부·불규칙한 안쪽 벽을 가진 하나의 GLB입니다. 터널은 6.5m 깊이로 실제로 파고 같은 메시에서 SOLID 충돌을 만듭니다. 렌더는 작은 면까지 닫힌 표면을 보존하며, 충돌에는 모든 지형이 공유하는 면적 안정성 필터를 적용합니다. 필터를 통과한 원본 정점·감기와 실제 입구 충돌 변환은 그대로 유지합니다. 하강 바닥도 그 끝까지 같은 FLOOR를 사용합니다. 암반·바닥이 같은 깊이 감쇠 함수를 공유해 첫 1m의 천장·측벽은 중간톤으로 남기고 더 깊은 공간만 어둡게 합니다. 고정 카메라 방향의 실제 광선과 배우의 진입·후벽 정지·복귀를 검사합니다. 제작기의 사면체 보간 평면이 실제 절단점 정렬과 면 감기를 결정하며, 공유 끝점의 순서를 고정해 틈을 방지합니다. 내부의 얇은 석조 아치 대신 같은 암벽 재질의 두꺼운 암반 리브를 사용합니다. 첫 가시판을 가리던 입구 장식 아치는 제거하고5개방/분기 리브를 유지합니다.

입구의 물리 SOLID는 같은 GLB의 정점과 감기를 유지하며 다른 지형과 같은 면적 기준으로 극소 삼각형만 제외합니다. 렌더 메시의 밀폐는 별도로 보존해 작은 면을 생략하면서 생기는 틈을 막습니다.

## 조명과 수명

기존 차가운 주변광·한 방향성 그림자 패스·입구 반사광·등불10개의 source 소유권·범위·게임 시간 변화를 유지합니다. 실제 장착점은 같은 높이의 가까운 수직 암반에서 선택하며 원래 앵커에서1.5m를 넘지 않습니다. 숲의 태양·반사광을 변경하지 않으며 입출구에서 숲 주변광과 배경을 복원합니다. 추가 광원·블룸·GI·후처리 없이 실제 면과 재질이 기존 횃불 빛을 받습니다.

## 검수

`native_cave_geometry`는 실제 메시의 닫힌 모서리·삼각형 감기·유한한 법선/UV·경계 접점·캡슐 충돌·실제 바닥 정점과6종 이미지 바인딩을 검사합니다. `cave_treasure`는 전체 벽 전환·복원·몬스터 제외, `dungeon`은 주 통로와 갈림길·출구·지역 수명을 검사합니다.

실제 브라우저의 방과 갈림길을 가로/세로로 확인합니다. 횃불 아래 바닥·어두운 안쪽 벽·노출된 능선의 재질, 구역 사이의 혼합, 통로와 귀환문을 봅니다. 정지 fixture의 캡처를 실제 휴대폰 장시간 성능으로 간주하지 않습니다. 일회성 비교 자료는 `build/`에 둡니다.

## 고저차와 주기형 트랩

`DungeonLayout.relief`가 방·통로 합집합과 높이의 단일 출처입니다. 다섯 방은 입구 기준0/-1.2/-0.25/-1.8/-0.7m이고, 위쪽 분기는+1.1m, 아래쪽 분기는-0.6m를 더합니다. 방 사이와 분기 진입부는 실제 경사입니다. 정수 밀리미터 격자로 겹침·미세 틈을 없애며 같은 삼각형을 표시와 FLOOR 충돌에 사용합니다. 물리 레이가 삼각형 이음선을 놓치면 활성 FLOOR 몸체가 있는 합집합 내부에서만 같은 면의 평면으로 지지를 복구합니다. 빈 공간·비활성 바닥에 새 지지를 만들지 않습니다. 바위 발치·횃불·아치·상자·포털도 같은 높이를 읽습니다.

가시판5개와 벽 화염4개는 휴식→예고→발동→복귀를 반복합니다. 가시는2.4/1.1/0.65/0.35초, 화염은2.7/1.35/1.1/0.6초입니다. 느린 프레임에도 예고 전체를 건너뛰지 않으며 메뉴 일시정지는 주기·표시·피해를 함께 멈춥니다. 가까운 장치의 단계와 남은 시간을 HUD에 표시하고 바닥 범위·효과음으로 예고합니다. 지도에는 실제 장치 위치와 종류·현재 단계를 표시하고 바닥 밝기로 높낮이를 구분합니다.

함정의 주기는 멀리서도 계속 흐릅니다. 피해와 대상 검색은 영웅의 지면 위치에서 장치까지20m 이내에서 처리해 먼 방의 순찰 몬스터가 먼저 소모되는 것을 막습니다. 이 범위는 카메라 줌과 무관하며, 접근한 장치가 이미 발동 중이면 원래 발동/높이/피격 조건을 적용합니다.

한 번 발동하면 각 대상은 한 번만 피해를 받습니다. 플레이어는 최대 체력의18%를 기존 방어·보호막·회피 규칙으로 처리하고, 일반 적은22%, 우두머리는5%를 받습니다. 적을 유인하는 전술을 허용하면서 우두머리를 장치만으로 빠르게 처치하지 않도록 정한3D판 규칙입니다. 출구·시작 위치는 안전하며 사망·이탈 시 판정과 HUD를 함께 정리합니다.

장치별 GLB와 씬은 `assets/models/environment/traps/{spikes,flame_vent}/`에 있습니다. `tools/assets/dungeon/bake_traps.tscn`으로 오프라인 제작하며 `asset.json`에 생성기·모델 해시를 기록합니다. Y-up·미터·바닥 원점·+Z 분출 방향을 지키고 가시의 `Spikes` 노드만 수직 이동합니다. 모델은848/264삼각형이며 석재 이미지는 기존 동굴 재질을 공유합니다. 화염은 기존 생성형 효과 아틀라스와 분출구당8개 고정 MultiMesh 입자를 재사용합니다. 새 광원·전투별 입자 노드 생성을 추가하지 않습니다.

`dungeon_relief`는 실제 경사 보행·빈 공간·바닥 비활성화를, `dungeon_hazards`는 예고·중복 피해·회피·적 유인·죽음/귀환 수명을, `native_dungeon_traps`는 실제 GLB의 법선·UV·감기·해시·기하 예산을 검사합니다.

## 방별 진행과 알림

`DungeonRooms`는 생성 시 배정한 적의 ID와 방 번호를 추적합니다. 실제 사망에서만 카운터를 줄이고 중복/다른 지역의 통보를 무시합니다. 추격 위치로 출신 방을 바꾸지 않으며 HUD는 제한 시간을 먼저 표시하고 가까운 미완료 방·전체 정리 수를, 지도 목록은 각 방의 남은 적을 표시합니다. 방 정리와 전체 정리 후 귀환 안내는 기존 토스트를 재사용합니다. 재입장 때 새 추적기를 만들고 이탈 시 버립니다. 매 프레임 적 전체를 다시 검색하지 않습니다. `dungeon_rooms`가 실제 적 이동·처치·중복 통보·재입장을 검사합니다.

방 정리/입장 알림은 해당 동굴 루트를 약한 참조로 소유해 방문 종료 후 대기열에 남지 않습니다. 트랩 안내는 확인 알림과 레벨업 배너의 실제 영역을 피해 배치합니다. 일반 획득 보상 알림의 기존 수명은 유지합니다.

## 귀환문 접점

귀환문의 실제 위치는 `DungeonRuntime.return_portal()`이 현재 월드의 살아 있는 `CaveReturnPortal`에서 읽습니다. 지도·상호작용 버튼·완료 보상은 이 위치를 함께 사용하고 제거/삭제 대기 중인 문을 제외합니다. `DungeonLayout.EXIT`는 최초 배치 설계이며 실행 중 상호작용 좌표로 복제하지 않습니다. `cave_return_point`는 실제 충돌을 통과한 주변 접근 방향, 위치 변경·제거·재입장과 완료 보상의 단일 지급을 검사합니다.
