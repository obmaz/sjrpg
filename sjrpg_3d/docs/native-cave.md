# 기존 바람 동굴의 입체 암벽과 바닥

숲1장의 기존 동굴만 다룹니다. 방5개·분기·출구·전투·보상·충돌 정책은 변경하지 않습니다. [3D 제작 기준](../../docs/3d-asset-guide.md)의 성숙한 회화형 재질과120° 직교 투영을 따릅니다. 기존 회색 암반·풍화된 석판·호박색 등불 원본은 보존하며, 바닥과 암벽이 한 회색 덩어리로 읽히지 않도록 실제 면의 역할을 구분합니다.

## 기하와 소유권

\`Ortho3DCaveRock\`은 \`DungeonArt.boundary_segments\`의 실제 방/통로 합집합 경계를 사용합니다. 귀환문 같은 독립 소품 충돌을 새 방이나 절벽으로 바꾸지 않습니다. 기존 \`SpatialWorld3D\` 경계 박스·바닥·3D 배우의 이동이 기준입니다.

- 좌표는 \`+Y\` 위·지면\`XZ\`,65지면 단위/m입니다. 직교 카메라45°/35.2643897°와 화면 축±30°를 유지합니다.
- 안쪽 바닥 접점은 물리 경계 박스 반두께와 같은4cm 안쪽입니다. 암반은 바깥쪽으로 약1.05m 부피를 가집니다.
- 기존 바닥·안쪽 경사·능선·뒤쪽·하부의 모든 정점과 삼각형 감기를 유지합니다. 끝점의 마이터와 높이도 공유하므로 재질을 나눠도 모서리가 벌어지지 않습니다.
- 뒤쪽 방은 최대3.5m, 뒤쪽 통로는1.45m, 앞쪽은0.45m 기준입니다. 낮은 앞면은 시각적 컷어웨이이며 실제3.5m 충돌벽의 변경이 아닙니다.
- 기존12m 청크·2만 삼각형·8청크 이내를 유지합니다. 각 청크의 실제 안쪽/바깥쪽 면을 두 공유 서피스로 나누며 암벽 서피스는 최대16개입니다. 별도 능선 외곽선이나 면을 덧붙이지 않습니다.

원화의 \`cave_role == "wall"\` 조각만 암벽이 소유합니다. 등불·아치·귀환문도 각 네이티브 표시기가 원본 객체와 수명을 관찰합니다. 아틀라스 전체를 지우거나 규칙 어댑터를 삭제하지 않습니다. 지원되지 않는 개별 대상의 임시 원화와 현재 네이티브 자산의 완료 범위를 구별합니다.

## 걸을 수 있는 바닥·안쪽 벽·노출 암반

| 실제 면 | 원본과 표면 처리 | UV |
| --- | --- | --- |
| 바닥 | 기존 \`assets/art/cave/floor.webp\`의 평평한 풍화 석판. 한 공유 조명 셰이더가 색 대비를 줄이고 따뜻한 중성색을 섞어 보행 영역을 읽히게 함 | 기존 세계\`XZ\`/2.6m와0.004m 표시 편향 유지 |
| 안쪽 벽 | 기존 \`assets/art/cave/dark.webp\`, 더 짙고 차가운 암석. 바닥 텍스처를 벽으로 섞지 않음 | 벽의 수평\`X\` 또는\`Z\`와 수직\`Y\`/2.6m. 같은 스트립의 두 삼각형이 동일한 차트 사용 |
| 능선·바깥 암반 | 기존 \`assets/art/village/rock.webp\`의 거친 암석과 절제된 흙빛 회색. 실제 단면 능선에서 안쪽 재질과 만남 | 상단·바깥 어깨는 연속 세계\`XZ\`/3.2m, 바깥 수직 뒷면은 수평축·\`Y\`/3.2m |

이전 암벽 전체의 삼면 투영을 없앴습니다. 수직 면의 UV가 바닥처럼 눕거나 높이 방향으로 무너지는지 실제 UV 면적과 네 방향을 검사합니다. 상단 경계는 임의 높이의 페인트 띠가 아니라 원래 단면의 \`PROFILE[4]\` 능선입니다. 모든 재질은 실제 기하 법선·기존 동굴 조명을 사용하며 발광·가짜 그림자·새 법선/거칠기 이미지를 추가하지 않습니다.

\`native_cave_floor.gdshader\`의 낮은 대비는 알베도만 조정합니다. 기존 등불의 따뜻한 빛과 벽 그림자가 계속 바닥에 반응하며, 평면 전체를 무광원 이미지로 바꾸지 않습니다. 원본 이미지 바이트와 \`texture_policy.json\`의 S3TC/ETC2 압축·밉맵 설정은 유지합니다. 원본 미세 자체 음영은 남으므로 PBR 스캔이라고 부르지 않습니다.

## 조명과 수명

기존 차가운 주변광·방향성 산란광 한 패스·입구 반사광·실제 등불10개의 위치·범위·게임 시간 기반 변화를 유지합니다. 숲의 태양·반사광은 바꾸지 않으며, 동굴 입출구에서 기록한 숲 주변광·배경색을 복원합니다. 블룸·GI·추가 그림자 패스나 후처리를 넣지 않습니다.

## 검수

\`native_cave_geometry\`는 실제 닫힌 메시·감기·유한한 법선/UV·모서리·물리 경계 접점과3D 캡슐 이동을 검사합니다. 새 재질 분리는 원래 능선 양쪽의 실제 공유 정점, 각 서피스의 수직/상단 UV 면적, 네 방향 벽, 기존 바닥 폴리곤·평면 법선·미터 UV와 한 공유 조명 재질로 검증합니다. 기존 소유권·입출구·조명 시계와 숲 복원 검사는 유지합니다.

실제 브라우저의 입구·전투 방·분기에서 세로/가로 변경 전후를 비교합니다. 발밑의 따뜻한 석판, 어두운 안쪽 벽, 노출된 바깥 능선을 동시에 확인하고 모든 방향·모서리·통로·귀환문 동선을 검수합니다. 정지 동굴 fixture의 사진은 실제 플레이·장시간 성능을 대신하지 않습니다. 새 시각 처리의 최종 판정은 현재 후보의 실제 캡처와WebGL 검증 후에 기록합니다.
