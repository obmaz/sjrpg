# 바람 동굴의 입체 공간

숲1장의 기존 바람 동굴만 다룹니다. 방5개·분기·출구·전투와 실제 충돌 경계는 유지합니다. 카메라는120° 직교 투영이며 [3D 제작 기준](../../docs/3d-asset-guide.md)을 따릅니다. 바닥과 벽의 생성형6종 재질·원본·혼합 방식은 [동굴 재질](native-cave-surfaces.md)이 기준입니다.

## 기하와 소유권

`Ortho3DCaveRock`은 `DungeonArt.boundary_segments`의 원래 방/통로 합집합 경계를 사용합니다. 귀환문 같은 독립 소품 충돌을 새 절벽으로 바꾸지 않습니다. `SpatialWorld3D`의 경계 박스·바닥·배우 캡슐이 보행 기준입니다.

좌표는`+Y` 위·지면`XZ`,65지면 단위/m입니다. 안쪽 발치는 실제 경계 박스의 반두께와 같은4cm 안쪽이고, 바깥 암반은 약1.05m 부피를 갖습니다. 바닥·안쪽 경사·능선·뒤쪽·하부 삼각형이 닫힌 부피를 구성합니다. 앞쪽 절단면은 낮고 뒤쪽 벽은 실제 높이를 유지합니다.

원래 연결된 직선 벽 구간마다 하나의 가림 오브젝트를 만듭니다. 그 벽의 안쪽과 바깥쪽 재질은 같은 투명도로 전환하고 떨어진 반대쪽 벽을 함께 묶지 않습니다. 바닥·몬스터는 정적 벽 소유권에 포함하지 않습니다. 원래2D 소스는 숨겨진 진행/배치 어댑터이며 표시기의 실제3D 소유권을 따릅니다.

## 조명과 수명

기존 차가운 주변광·한 방향성 그림자 패스·입구 반사광·실제 등불10개의 위치·범위·게임 시간 변화를 유지합니다. 숲의 태양·반사광을 변경하지 않으며 입출구에서 숲 주변광과 배경을 복원합니다. 추가 광원·블룸·GI·후처리 없이 실제 면과 재질이 기존 횃불 빛을 받습니다.

## 검수

`native_cave_geometry`는 실제 메시의 닫힌 모서리·삼각형 감기·유한한 법선/UV·경계 접점·캡슐 충돌·실제 바닥 정점과6종 이미지 바인딩을 검사합니다. `cave_treasure`는 전체 벽 전환·복원·몬스터 제외, `dungeon`은 주 통로와 갈림길·출구·지역 수명을 검사합니다.

실제 브라우저의 방과 갈림길을 가로/세로로 확인합니다. 횃불 아래 바닥·어두운 안쪽 벽·노출된 능선의 재질, 구역 사이의 혼합, 통로와 귀환문을 봅니다. 정지 fixture의 캡처를 실제 휴대폰 장시간 성능으로 간주하지 않습니다. 일회성 비교 자료는 `build/`에 둡니다.
