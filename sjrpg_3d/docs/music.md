# 배경 음악

마을·들판·동굴 세 곡이 영웅의 위치에 따라 바뀌며 반복 재생됩니다. 곡은 `tools/prepare_music.py`가 코드로 작곡·합성하므로
외부 음원이 없고 같은 결과를 다시 만들 수 있습니다.

```sh
python3 tools/prepare_music.py --check    # assets/audio/music/*.ogg 재생성 + 이음새·음량 측정 (numpy, ffmpeg 필요)
tools/check.sh --project=3d --only=music  # 재생기 테스트
```

## 곡

| 곡 | 장소 | 조성·빠르기 | 길이 | 분위기·악기 |
| --- | --- | --- | --- | --- |
| `town` | 마을 안전 구역 | G 장조, 92 bpm, 16마디 | 41.7초 | 따뜻한 민요풍. 류트 아르페지오, 플루트 선율, 낮은 베이스, 부드러운 프레임 드럼과 셰이커 |
| `field` | 마을 밖 숲·들판 | A 단조, 78 bpm, 16마디 | 49.2초 | 탁 트이고 공기감 있는 곡. 하프 아르페지오, 스트링 패드, 긴 플루트 선율, 에코 |
| `dungeon` | 동굴 | D 단조, 54 bpm, 12마디 | 53.3초 | 어둡고 느린 곡. 낮은 드론, 심장박동 같은 북, 드문 종소리, 쓸쓸한 낮은 플루트, 긴 잔향 |

각 파일은 약 0.5~0.6MB(Ogg Vorbis, 32kHz 스테레오)이고 웹 번들은 약 1.8MB 커졌습니다.

## 반복이 끊기지 않는 이유

- 모든 음을 **정확히 한 번 반복 길이의 버퍼**에 쓰고, 끝을 넘어가는 음의 여운은 처음으로 되감아 더합니다.
  곡의 끝에서 울리던 소리가 곧바로 처음 마디 위로 이어지는 것과 같습니다.
- 리버브와 에코는 순환 방식(FFT 순환 컨볼루션, 순환 이동)이라 이음새를 만들지 않습니다. 드론과 바람 소리는 한 반복에 정수 주기가 들어가게 맞춥니다.
- 끝 마디는 처음으로 되돌아가는 화성(딸림화음)과 선율(이끎음)로 끝납니다.
- 인코딩 후에도 확인합니다: 디코딩한 길이가 원본과 샘플 단위로 같고(차이 0), 원본과 상관 0.999 이상이며, 이음새의 샘플 단차는 곡 전체 단차의 99.5% 지점 이하입니다.
  `.import`는 `loop=true`이고 재생기도 시작할 때 `loop`를 켭니다.

## 게임 안에서

- `MusicDirector`(`scripts/audio/music_director.gd`)가 `Game`의 자식으로 있고, 0.25초마다 위치를 봅니다.
  동굴 안이면 `dungeon`, 마을 안전 구역이면 `town`, 그 밖은 `field`입니다.
- 곡이 바뀌면 이전 곡을 약0.8초 동안 줄여 완전히 정지한 뒤 새 곡을 약0.8초 동안 키웁니다. 마을·필드 경계를 왕복하거나 동굴로 바로 이동해도 동시에 두 곡을 재생하지 않습니다. 메뉴로 게임이 일시정지돼도 페이드는 계속되고, 앱이 포커스를 잃으면 음악만 멈췄다가 돌아오면 이어집니다.
- 설정의 **배경 음악** 토글(`Prefs.music_enabled`, 기기에 저장)로 끄고 켭니다. 전투 효과음 설정과는 별개입니다.

## 조정하려면

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 코드 진행·선율·악기 편성 | `prepare_music.py`의 `town()`·`field()`·`dungeon()` (`progression`, `tune`, `bells`) |
| 곡 자체의 음량 | `TARGET_RMS` (현재 약 -21 dBFS) |
| 게임 안 음악 음량 | `music_director.gd` `BASE_DB` (현재 -6 dB) |
| 순차 페이드 전환 길이 | `music_director.gd` `FADE_SECONDS` (아웃/인에 절반씩 사용) |
| 음질·용량 | `--quality` (libvorbis, 기본 3.5) |

수정 후에는 `prepare_music.py --check`를 다시 실행해 이음새 측정값이 유지되는지 봅니다.

## 알려진 한계

- **귀로 들어 보지 못했습니다.** 화성·선율은 음악 이론에 맞춰 짰고 음량 흐름과 이음새는 측정했지만, 취향·어울림은 직접 들어 보고 판단해야 합니다.
  마음에 안 드는 곡은 위 함수의 코드 진행이나 `tune` 목록을 고치면 됩니다.
- 음악 음량이 효과음에 비해 크거나 작으면 `BASE_DB`를 조정합니다.
- 웹에서는 사용자의 첫 입력 이후에만 소리가 나는 브라우저 정책을 따릅니다(게임은 클릭 뒤에 시작하므로 보통 문제없습니다).
- 보스 전투·타이틀 화면용 곡은 없습니다.


## 장면 종료와 앱 포커스

장면에서 나갈 때 세 플레이어를 정지하고 각 스트림 참조를 해제합니다. 다시 들어오면 같은 플레이어를 재사용해 현재 지역의 페이드를 시작합니다. 포커스를 잃은 상태는 장면 재부착 후에도 유지하고, 음악을 끄면 일시정지된 루프도 정리합니다. 일시정지와 실제 재생 객체의 존재를 구분해 같은 루프가 매 프레임 다시 시작되지 않도록 합니다. 전투 효과음 설정은 음악과 별개입니다.
