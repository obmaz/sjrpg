# 상자 크기와 충돌

상자는 `NativeEncounterMesh3D`의 공유 입체 메시를 사용합니다. 닫힌 실제 크기는 약0.570×0.529×0.375m, 표시 배율은(1,1,1)입니다. 뚜껑은 실제 힌지를 중심으로 움직이며 소비·파괴 상태는 기존 상자의 상태를 읽습니다.

`Chest.COLLISION_RADIUS`는30투영 단위이며 네이티브 반경은 약0.3885m입니다. 실제 지형 위에 높이0.530m의 유한한 PROP 실린더를 둡니다. 상자 몸체를 지나는 투사체는 맞고 위로 지나가는 투사체는 통과합니다. 소비된 상자는 충돌과 표적에서 제외합니다. 상자 ID·저장·보상은 유지합니다.

동쪽 기억 상자는 기존 성벽과 뚜껑의 회전 공간을 피한 지점(1480,260)에 있습니다. 표시·충돌·보상 기준점이 같은 위치를 사용합니다. `native_encounter_props`는 모든 상자의 크기·뚜껑 회전·표면/삼각형 예산·실제 충돌·투사체 높이·주변 통행을 검사합니다.

공통 제작과 외부 모델 납품 기준은 [에셋 협업](asset-workflow.md)을 따릅니다. 비교 화면·특정 후보 커밋의 완료 리뷰는 저장소 문서에 보관하지 않고 `build/`와 CI 아티팩트에서 관리합니다.
