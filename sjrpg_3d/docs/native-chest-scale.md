# 상자 크기와 충돌

모든 상자는 이전 입체 모델보다 세 축이2배입니다. `EncounterGeometry3D`의 공유 메시를 사용하며 닫힌 실제 크기는 약1.140×1.058×0.750m, 표시 배율은(1,1,1)입니다. 뚜껑은 실제 힌지를 중심으로 열리고 내부·철띠·리벳도 입체입니다.

`Chest.COLLISION_RADIUS`는60투영 단위이며 네이티브 반경은 약0.777m입니다. 지형 위에 높이1.06m의 유한한 PROP 실린더를 둡니다. 상자를 지나는 투사체는 맞고 위로 지나가는 투사체는 통과합니다. 열린 상자는 충돌과 표적에서 제외합니다.

`ChestPlacement`는 건물·나무·다른 상자·낮은 기단 경계와 뚜껑 회전 공간이 겹치지 않는 같은 높이의 위치를 찾습니다. 숲의 저장 ID와 보상 종류는 유지합니다. 동굴의5개 상자는 방 구석에 두며 주 통로·갈림길을 비웁니다. 동굴 상자는 입장마다 새로 생기고 숲의 개봉 기록을 변경하지 않습니다.

쇠 상자는 확정된 타격4번에 열리며 돈 또는 돈과 물약을 줍니다. 황금 상자는 희귀 이상 장비를 보장하고 적 매복을 일으키지 않습니다. 앞면·옆면·곡면 뚜껑 전용 생성형 알베도 원본·프롬프트·참조 해시는 `assets/source/materials/chests/`에 보존합니다.

`native_encounter_props`와 `cave_treasure`는 실측 크기·뚜껑 회전·실제 충돌·투사체 높이·통행·지역 수명·보상1회·내구력을 검사합니다. [입체 소품 구조](native-encounter-props.md)와 [에셋 협업](asset-workflow.md)을 참고하세요.
