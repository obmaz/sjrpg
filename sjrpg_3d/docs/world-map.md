# 미니맵과 장소 지도

미니맵을 누르거나 M 키로 지도를 엽니다. 지도 위에는 번호, 별도 목록에는 같은 번호의 장소명·거리·안내를 표시합니다. 번호나 목록을 누르면 실제 위치를 중심으로 확대합니다. 선택으로 캐릭터가 이동하지 않습니다. 드래그로 지도를 옮기고 `전체`, `내 위치`, `-`, `+`로 시야를 조절합니다.

세로 화면은 지도 아래에, 가로 화면은 오른쪽에 목록을 둡니다. 목록만 스크롤하므로 지도와 확대 버튼이 사라지지 않습니다. 긴 이름·설명은 행 높이를 늘려 모두 표시합니다. 웨이포인트는 발견 전·후 모두 목록에 표시하고 미발견은 직접 밟아 활성화하도록 안내합니다. 의뢰는 금색, 웨이포인트는 보라색, 시설은 청록색, 동굴은 파란색, 비석은 갈색으로 구분하고 유형 이름도 표시합니다. 행은 버튼이 아닌 `PanelContainer`이며 터치 드래그를 부모 스크롤로 전달합니다. 짧은 탭을 떼었을 때만 선택하고 키보드·패드 확인도 같은 선택을 실행합니다. 안식처 이동은 별도 `안식처·워프` 탭에서 기존 발견·위험·동굴 제한을 적용합니다.

## 실제 공간이 기준

- `MapWorldState`가 두 지도에 같은 `Game.map_shapes` 스냅샷과 변경 번호를 제공합니다. 지면·강·길·동굴 유도 길·높은 지형은 실제 생성 설계를 읽습니다.
- 주택·예배당·성곽·다리는 현재 네이티브 루트의 발자국과 `global_transform`을 읽습니다. 예배당의 L자 몸체, 성벽 모서리 탑, 실제로 회전하는 문짝도 포함합니다. 위치·크기·회전 변경과 루트 제거·교체를 다음 갱신에 반영합니다.
- 시설·의뢰는 살아 있는 NPC, 재소환 비석은 실제 노드, 웨이포인트는 실제 접점, 동굴은 `DungeonRuntime.entry_point()`, 귀환문은 `DungeonRuntime.return_portal()`의 살아 있는 포털 노드에서 위치를 읽습니다. 완료 버튼과 보상 판정도 같은 접점을 사용하고, 문이 제거되거나 삭제 대기 중이면 표식과 상호작용을 함께 제외합니다. 별도의 표식 좌표표를 만들지 않습니다.
- 동굴 바닥은 실제 FLOOR 설계인 `DungeonLayout.relief.cells`를 사용하며 밝은 길은 높고 어두운 길은 낮습니다. 가시판·화염 장치는 현재 위치와 단계·남은 시간·바닥 높이를 표시합니다. 장치 표식은 각각 호박색·주홍색으로 구분합니다. 전투 구역은 실제 방 중심에 표시하며, 남은 적 수와 정리 여부를 보여 줍니다. 추격해 방 밖에 나온 적도 출신 방에 포함합니다. 동굴의 미개봉 상자는 실제 `Game.chests`의 위치·종류·내구도를 읽습니다. 황금 상자는 금색 장비 보물, 쇠 상자는 청회색 보급 보물로 구분하고 개봉·제거 때 표시를 없앱니다. 숲/동굴 전환 시 다른 지역의 도형과 표식을 버립니다.

지도 좌표는 `WorldSpace3D.world_to_projected()`와 `Iso.project()`의 지면 좌표입니다. 건물 높이를 다시 투영하지 않습니다. 번호판은 읽기 쉬운 빈 곳으로 옮길 수 있지만 원래 점은 고정하고 연결선으로 번호와 잇습니다. 번호가 밀집하면 일부 번호판만 생략하며 모든 장소는 목록에서 선택할 수 있습니다.

새 정적 건축을 연결할 때는 실제 제작 루트에 기존 `native_house`, `chapel_detail`, `fortification_detail`, `bridge_detail` 계약을 유지하거나 `MapWorldState`에 동등한 발자국 공급자를 추가합니다. 숲 나무·상자 전체를 지도 표식으로 노출하지는 않습니다. 실제 충돌·배치 변경은 공간/에셋 담당 코드에서 함께 처리해야 하며 지도는 공간을 수정하지 않습니다.

## 갱신과 검증

원본 내용과 네이티브 변환은 프레임당 한 번 확인합니다. 변경이 없으면 전체 지도 메시를 재사용하고, 미니맵도 기존 이동 허용 오차·클리핑·보관된 점을 유지합니다. 같은 개수의 꼭짓점·색상 변경도 캐시를 무효화합니다. `Game.refresh_map(true)`는 배치 검사에서 같은 프레임의 변경을 즉시 확인할 때 사용합니다.

`cave_treasure_map`은 실제 상자의 이동·내구도·개봉·제거·재입장과 두 지도의 공통 표식을 검사합니다. `map_world_sync`는 실제 GLB 루트 이동·확대·제거·교체와 성문·NPC·동굴 전환을, `map_panel_navigation`은 번호 선택·실제 좌표·이동 없음·회전·긴 글자·독립 스크롤을 확인합니다. `minimap_mesh_cache`, `minimap_retained`, `minimap_border`, `exploration`도 함께 유지합니다. 화면 검수는 실제 브라우저의 가로·세로에서 수행합니다. 자동화 브라우저의 `window.__sjrpgMapPanel`은 현재 UI 좌표를 읽는 검수용 값이며 게임 조작 API가 아닙니다.

실제 터치 회귀는 로컬 Web 빌드를 실행한 뒤 `node sjrpg_3d/tools/check_map_touch.mjs --url http://localhost:8878/index.html --out build/review/map-touch`로 수행합니다. 행 위에서 손가락을 드래그해 목록이 움직이는지, 스크롤 중 선택이 발생하지 않는지, 미발견 웨이포인트 선택과 가로 회전 후 위치를 확인합니다. `--scope cave`로 실제 동굴의 보물 목록·황금 상자 선택·화면 회전도 같은 터치 입력으로 검사합니다. 휠 입력으로 터치 검증을 대신하지 않습니다.

워프 수락 후에는 `WarpTravel`이 약0.7초 동안 사라짐→이동→나타남을 처리합니다. `Exploration.travel/warp()`의 `true`는 이동 수락이며, 완료가 필요한 호출자는 `transition.finished`를 기다립니다. 실제 이동 직전에 안전한 도착지를 다시 검사하고 실패하면 출발점에서 배우·조작을 복원합니다. 진행 중 이동·공격·구르기·피격은 잠그고 메뉴 일시정지는 전환 시계도 멈춥니다. `WarpEffects3D`는 전체 배우 재질의 전용 알파 사본, 세 개의 링과 한 묶음의 빛 입자를 재사용합니다. 원본 재질·그림자를 완료/취소 후 복원하고 투명 변형은 로딩 중 미리 그립니다.
