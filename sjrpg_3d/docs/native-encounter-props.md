# 소환 비석과 보물상자의 입체 자산

숲 1장의 기존 비석 6개와 기존 상자만 교체합니다. 카메라는 45°/35.2643897° 직교 투영이며 후속 지역·방·보상·전투·충돌 규칙을 추가하지 않습니다. 원본 2D 프로젝트는 동결합니다. [3D 제작 기준](../../docs/3d-asset-guide.md)의 성숙하고 절제된 회화형 숲 판타지와 실제 사용자 레퍼런스를 따릅니다.

## 제작과 재질

`NativeEncounterMesh3D`는 모든 면·후면·기단·실제 내부를 가진 미터 단위 메시를 재현합니다. 생성형 이미지를 새로 만들지 않았습니다. 기존 `assets/art/preview3d/materials.json`에 기록된 **정면 평면 재질** limestone/timber를 재사용하며 기존 원화의 실루엣을 평면에 붙인 신규 모델이라고 표시하지 않습니다.

비석은 기존 52×32 지면 단위, 즉 0.80×0.4923m 기단 안에 있습니다. 1.58m 높이의 깎인 석재 몸체·양쪽 홈 테두리와 작은 청록 인레이를 갖습니다. 공통 석재의 2.56m 세계 좌표 타일과 0.32m 단 높이를 유지하고 실제 기하 법선과 그림자를 사용합니다. 준비/비준비와 피격 색은 원본 `art.modulate_color`를 관찰합니다. 녹색 인레이는 약한 고정 발광만 사용하며 별도 광원·블룸·광역 발광을 추가하지 않습니다.

상자는 바닥·네 벽·빈 내부·둥근 목재 덮개·철띠·리벳·후면 힌지·열렸을 때 붙어 있는 작은 파편을 갖습니다. 닫힌 크기는 0.456×0.4232×0.300m이며 높이보다 폭이 넓습니다. 몸통 상단은 0.28m이고 정점과 철물을 실제로 재작성했으며 한 축 런타임 확대/축소를 사용하지 않습니다. 목재·철 구분은 실제 기하의 정점 마스크를 사용합니다. 기존 timber 알베도와 기존 공용 wood/iron의 색·거칠기·금속 값을 한 공유 셰이더로 읽어 움직이는 부품당 한 서피스에 합칩니다. 철물을 목재 알베도에 새로 칠하지 않았습니다. UV는 실제 미터에 공용 0.65 배율을 적용하고, 덮개를 열어도 나뭇결은 부품과 함께 움직입니다.

새 텍스처·GLB 다운로드는 0바이트입니다. 기존 두 공유 텍스처와 실제 코드 파일 해시·바이트, 메시별 삼각형/서피스와 닫힌 상자의 실측은 `assets/data/native_encounter_props.json`에 기록합니다. 미세한 자체 음영이 남은 기존 알베도를 PBR 스캔이라고 주장하지 않습니다. 존재하지 않는 법선/거칠기 이미지도 기록하지 않습니다.

## 비례·바닥·충돌

기존 상자 그림은 약 111.7 원래 월드 단위 높이로 설정되어, 실제 반경 24px(0.3108m) inset 원통보다 크게 그려졌습니다. 새 모델은 기존 충돌 범위에 맞춰 과대한 그림 높이 대신 사람 무릎 아래의 실제 상자 비례를 사용합니다. 원본 배치 기준점과 같은 실제 지면 높이·콜라이더 중심은 유지합니다. 덮개의 **연속적인** -65°~0° 회전에서 각 메시 정점의 수평 극값을 계산해 전체 부피가 원래 원통의 바닥 범위를 벗어나지 않게 합니다. 별도의 회전 샘플 검사가 이 계산을 교차 검증합니다.

모델에는 새 충돌체가 없습니다. 비석 `body()`와 상자의 원래 PROP 원통/소모 수명은 `SpatialWorld3D`가 계속 소유합니다. 상자는 기존2.2m 높이의 단순화된 원통을 유지하므로 새 모델의 뚜껑 높이와 일치하는 세밀한 충돌로 전환한 것은 아닙니다. 투사체 벽과 공격 가능한 소품의 구분, 실제 소환·보상·저장 규칙도 유지합니다.

## 상태와 지역 수명

`NativeEncounterProps3D`는 자기 모델이 있는 **개별 source instance ID**만 소유합니다. 비석의 이전 원화 카드는 해당 ID만 제외합니다. 상자 파괴는 실제 `body_sprite`를 새 객체로 바꾸므로 매 동기화에서 새 ID를 소유하고 이전 카드는 정리합니다. 재질 패밀리나 지원 모델이 없으면 소유하지 않아 기존 개별 원화를 유지합니다.

비석 피격은 실제 `EncounterStone._flash`/원화 tint, 소환/남은 충전/대기는 실제 `EncounterRuntime.states`, `living`, `can_summon`만 읽습니다. 남은 초는 `ceil(RECHARGE_SECONDS-recharge)`이며 별도 카운트다운을 만들지 않습니다. 상자는 실제 `Chest.dead`에서 닫힘/열림/빈 상태를 결정하고, 임의 열림 시계나 추가 보상을 만들지 않습니다. 원본의 순간적인 파괴 전환을 유지합니다.

숲/동굴은 명시적으로 구분하고 소스 자체의 `visible`을 따릅니다. 원래 Canvas 조상은 3D판에서 일부러 숨겨져 있으므로 `is_visible_in_tree()`로 원본을 판단하지 않습니다. 동굴에서는 숲 소품과 상자 fallback 모두 숨기고, 복귀 때 동일한 소모 상태를 복원합니다. 원본이 삭제/이동되면 모델·소유 ID를 정리합니다. 모델과 표식은 깊이 검사를 유지하며, 기존 상태 헤더의 UI 깊이 정책만 그대로 둡니다.

## 검수 도구

`native_encounter_props`는 실제 메시의 유한한 UV/법선·모든 삼각형의 감기·바닥/기단·예산·덮개 전체 범위를 검사합니다. 실제 소환 타격과 상자 파괴를 호출해 원래 충전/보상 1회/콜라이더 해제, 원본 tint·쿨다운, source 숨김·동굴 왕복·삭제를 확인합니다. 메트릭 로그는 다음 도구로 제작 기록에 반영합니다.

```sh
python3 tools/preview3d/record_encounter_props.py --log /path/to/native-encounter-test.log
# 실제 브라우저 검수 기록의 해시·화질·화면 크기를 함께 보존할 때
python3 tools/preview3d/record_encounter_props.py --log /path/to/native-encounter-test.log --browser-proof /path/to/evidence.json
```

`?loot_review=1`은 새 격리 브라우저 프로필에서 실제 source 위치·재질·상태 메서드로 검수하는 명시적 fixture입니다. 기본 플레이에서는 실행하지 않습니다. 정식 `create_slot`으로 고유한 테스트 저장 세션을 만들며 운영 세션 가드는 수정하지 않습니다. 모델을 180° 돌리는 것은 보이지 않는 후면의 자산 검사이며 카메라/게임 규칙 변경이 아닙니다. before 모드는 같은 공간에 이전 **개별 원화 카드**를 표시하는 비교입니다. 실제 원본 시계를 멈춰 GPU 캡처를 기다리는 장면과 실제 전투 성능 측정은 구별합니다. 기존 west 비석은 높은 성벽에 배우가 가려지는 배치 한계가 있어, 원본 배치를 바꾸지 않고 실제 south 비석도 추가로 검수합니다.

```sh
TMPDIR=/workspace/sjrpg-browser-tmp node tools/preview3d/capture_encounter_props.mjs http://127.0.0.1:8071/ /path/to/evidence
```

실제 세로/가로·양 화질·앞/뒤·실제 피격·소모·동굴 왕복에서 콘솔/GPU 오류와 같은 위치 before/after를 확인한 뒤 채택합니다. 헤드리스 통과나 제작 메트릭만으로 시각 검수 완료를 선언하지 않습니다.
