# 동굴 바닥과 암벽 재질

기존 바람 동굴의 바닥과 벽에 각각 독립 생성형 알베도6종을 적용합니다. 원본 배치·방 경계·입장·전투와 충돌 높이는 그대로 사용합니다. 재료는 중성 회색 셰일과 회갈색 광물성 흙을 공유합니다.

바닥은 다져진 흙, 갈라진 암반, 습한 자갈, 마모된 암반, 부서진 셰일, 이끼가 낀 가장자리로 구별합니다. 벽은 층리·수직 균열·습기 자국·방해석 맥·잘게 깨진 지층·올리브색 광물 흔적으로 구별합니다. 고정된 월드 좌표에서 넓은 구역으로 혼합해 작은 타일마다 다른 모양이 붙는 격자를 피합니다.

`assets/models/materials/cave/`는 공유 표면 코드와 `floor/`, `wall/`의6개 이미지 패키지를 담습니다. `surfaces.gd`가 종류별6개 밉맵/VRAM 압축 텍스처를 연결합니다. 안쪽 벽은 원래 수직 UV, 바깥 암반은 실제 법선의 트라이플래너 좌표로 같은 벽 패밀리를 사용합니다. 물리 기하와 원래 벽 구간별 가림 소유권은 유지하며, 투명화가 필요한 셰이더의 include 경로는 절대 리소스 경로를 사용합니다.

한 이미지의 물리 배율은2.6m입니다. 바닥의0.004m 표시 오프셋과 실제 보행면은 유지합니다. 텍스처를 위한 추가 보행 장애물이나 단차는 만들지 않습니다. 거칠기는 바닥0.97, 벽0.98이고 추가 광원·발광·법선 이미지 파일은 없습니다.

각 이미지의 원본·정확한 프롬프트·실제 첨부 참조·해시는 `assets/source/materials/cave/{floor,wall}/provenance.json`에 있습니다. 생성 원본을 편집·리사이즈하지 않으며 어울리지 않는 초안은 런타임 패키지에 넣지 않습니다.

`native_cave_geometry`는 실제 표시기에 연결된6종 이미지와 해시·배율·원래 바닥 정점·닫힌 암벽 부피·충돌 경계를 검사합니다. `cave_treasure`는 실제 시선의 전체 벽 투명화와 몬스터 제외를, `dungeon`은 주 통로와 갈림길을 검사합니다. 실제 가로/세로·방/갈림길 화면에서 표면 혼합과 횃불 조명도 확인합니다. 일회성 캡처는 `build/`에 둡니다.
