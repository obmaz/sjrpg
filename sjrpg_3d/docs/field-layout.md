# 확장 필드 배치

`ForestRegion`이 숲1장 범위·랜드마크 기준점·파수꾼 공터·소환 지점·구역 이름을 소유합니다. 필드는 지면(-3600,-3600)에서(10800,10800)까지이며,65지면 단위가1m입니다. 마을은 원래 위치와 성벽 범위를 유지합니다.

| 구역 | 지면 기준점 | 역할 |
| --- | --- | --- |
| 고목 쉼터 | (3600,1600) | 첫 배달 의뢰·약초사·야외 웨이포인트 |
| 석조 정원 | (7600,1800) | 동쪽 숲의 정화 의뢰 |
| 계곡 폭포 | (9400,900) | 동쪽 탐험·기억 상자 |
| 바람 언덕 | (1200,7800) | 강 건너 남쪽 탐험 |
| 동굴 구릉 | (7600,7600) | 하강 진입로·조사관·선택 던전 |
| 파수꾼 공터 | (3700,8600) | 의뢰 뒤 남쪽 숲 도전 |

표의 랜드마크 기준점은 배치용입니다. NPC·의뢰 표식은 실제 윗면 중심과 입구에서 계산하므로 표 좌표를 UI에 복사하지 않습니다. 난이도는 `ForestBalance.zone_at()`이 화면 좌표를 지면 거리로 변환해 나눕니다. 방향에 따른 쿼터뷰 배율 차이를 난이도에 섞지 않습니다.

강은 마을과 떨어져 서쪽·동쪽 맵 경계 밖까지 이어집니다. `Village._build_river()`가 실제 다리 양 끝에서 수면 폭을 정하고, 다리 교대(5200,5200)와 갑판·강안·물 차폐를 함께 생성합니다. 마을 남문 길은 북쪽 강둑에 연결되고 다리만 물을 건넙니다. 남쪽 교대 뒤에서 동굴의 흙길이 이어집니다. 낮은 강바닥·물결10종·부드러운 강둑은 기존 `GroundRelief3D`와 재질을 사용합니다.

마을의 직립 워프문과 필드의 바닥 웨이포인트 두 곳만 야외 이동 등록에 들어갑니다. 파수꾼 공터에 작동하지 않는 장식 포털을 두지 않습니다. `Village.warp_point()`가 실제 발판의 중심을 계산하고 `Exploration`과 지도 표식이 함께 읽습니다. 원화의 앞쪽 피벗을 작동 좌표로 사용하지 않습니다.

퀘스트·웨이포인트·소환 비석의 기존 저장 ID는 유지합니다. `EncounterRuntime._relocate_members()`는 이전 기준점과 새 비석의 차이만큼 생존 무리를 옮기고, 체력·레벨·충전·회복 시간을 보존합니다. 기준점이 없던 저장은 무리의 중심을 사용하며 다음 저장부터 기준점을 기록합니다. 저장 좌표 한도는 확장 맵의 투영 모서리와 배치 여유를 포함합니다.

도로와 강을 바꾸면 `tools/review/models/capture_road_geometry.tscn` → `bake_ground_field.py`로 실제 거리장을 다시 만듭니다. 건축 제작기는 배치 의존성과 `ForestRegion`의 해시도 기록합니다. 새로운 지형 배치를 기존 GLB에 맞추려고 충돌을 삭제하지 않습니다.

`field_layout`은 실제 워프 발판/작동점, 두 경계를 가로지르는 강, 마을과 강 사이 여유, 퀘스트 분산, 난이도 거리, 지도·저장 이관을 검사합니다. `bridge`, `native_bridge_sweep`, `expanded_forest`, `natural_ground`, `warp_gates`, `encounters`, `map_world_sync`는 실제 보행·지형·워프·지도 동기화를 함께 검사합니다. 실제 모바일 가로·세로 화면에서 마을·다리·전체 지도를 확인합니다.
