# 파괴 가능한 숲 나무

마을 밖 일반 나무만 공격에 반응합니다. 마을 나무와 퀘스트 고목은 보호합니다.
기존 다섯 GLB 패밀리의 실제 줄기·가지·잎·UV를 재사용합니다.

| 공격/상태 | 반응 |
| --- | --- |
| 일반 공격 | 구조 내구도3. 보통3회, 기준 피해60 이상 공격은2회. 건강한 나무는 최소2회 필요 |
| 화염 | 4초 연소 후 공격 가능한 재. 연소 중 얼음에 맞으면 빙결 |
| 얼음 | 8초 빙결. 새로운 공격이면 원소에 관계없이 한 번에 깨짐. 방치하면 해동 |
| 전기 | 잎이 사라진 검게 탄 줄기가 남음. 새로운 공격 한 번에 깨짐 |
| 재 | 통행을 막지 않으며 새로운 공격 한 번에 남은 잔해를 부숨 |
| 파괴 후 | 낮은 그루터기가 남고 통행 가능. 약4분 뒤 화면 밖·배우 비점유 때 재생 |

내구도는 적 체력과 별개이며 공격당 구조 피해는1~1.5로 제한합니다.
기준 피해는 난수 변동을 제외한 값이며 환경 판정이 적 피해의 난수열을 소비하지 않습니다.
나무는 경험치·처치 수·전리품·적 처치 히트스톱을 발생시키지 않습니다.
근접 접촉은 기존 일반 히트스톱을 사용하며 별도 화면 흔들림을 추가하지 않습니다.

공격ID는 플레이어 인스턴스와 시전 번호의 조합입니다. 자식 투사체·폭발·지속 영역에도
전달하여 한 주문이 같은 나무를 얼린 직후 깨뜨리거나 여러 번 벌목하지 않습니다.
나무마다 최근64개 공격ID만 보관하며 원소 재적용보다 기존 취약 상태 판정이 우선합니다.
재의 주문 피격 범위는 손 높이까지 유지해 조준을 돕지만 보행 충돌은 제거합니다.
근접·범위 공격은 실제 높이와 벽 차폐를 확인하고 피해 없는 함성은 제외합니다.

## 구조와 비용

- [ForestTreeRuntime](../scripts/gameplay/props/forest_tree_runtime.gd): 안정적인 소스 키,
  공간 격자, 내구도·원소·재생·공격 중복 방지. 변경 기록만 `GameState.forest_trees`에 저장합니다.
- [TreeDamageRenderer3D](../scripts/rendering/vegetation/tree_damage_renderer_3d.gd): 기존16m
  청크/인덱스를 유지하며 바뀐 상태만 청크별 MultiMesh로 옮깁니다. 숲 전체를 재구축하지 않습니다.
- [TreeDamageGeometry3D](../scripts/rendering/vegetation/tree_damage_geometry_3d.gd): 다섯 GLB의
  손상 메시/재질 캐시. 탄화는 잎을 제외하며 잔해를 원래 수관 높이로 다시 맞추지 않습니다.
  냉기는 기존 잎 구멍과 나뭇결을 보존한 불투명 서리 표면입니다. 공유 메시·가림 재질·BVH는
  로딩 중 미리 준비하여 첫 원소 타격에 생성 비용이 몰리지 않게 합니다.
- `NativePlayerOcclusion`: `occlusion_enabled_instances`가 일시적인 투명화 복원보다 우선합니다.
  사라진 슬롯과 임시 프록시를 숨기고 재생은 정본 `occlusion_transforms`를 사용합니다.
- `SpatialWorld3D`: 같은 나무 키의 트렁크 충돌 레이어만 바꿉니다. 긴 광선은 물리 엔진의
  safe/unsafe 구간에서 실제로 막은 충돌체를 확인하며 거리 허용치를 넓혀 벽을 무시하지 않습니다.

나무별 처리 노드/타이머를 추가하지 않습니다.0.1초마다 변경된 나무만 갱신합니다.
시계는 일시정지 중 멈추며 저장한 남은 시간을 앱 종료 중에는 앞당기지 않습니다.
숲↔동굴 전환에서 상태와 물리 캐시를 유지하며 동굴에서는 숲을 화면 밖으로 취급합니다.
지도에는 일반 나무 표식이 없으므로 개별 파괴가 지도 전체 재생성을 유발하지 않습니다.

파편은 타격2개·파괴6개, 전체48개를 한 불투명 MultiMesh로 재사용하고0.6초 안에 회수합니다.
물리 파편·그림자·동적 광원이 없으며 화면 근처의 연소 불씨는8그루×3개로 제한합니다.
연소 표시는 기존 생성형 화염 아틀라스와 공유 셰이더를 쓰는 작은 평면으로, 새 이미지는 없습니다.
화면 밖에서는 상태만 진행합니다. 동작 줄이기는 날리는 파편을 생략하고 불씨를 고정합니다.
표시 이벤트 큐는24개이며 상태 배치는 필요한 청크에 한 번 만들고 재사용합니다.
이 상한은 특정 기기의 FPS를 보장하는 측정값이 아닙니다.

## 검수

`forest_tree_damage`는 실제 공격, 원소 우선순위, 지속 공격 중복 방지, 충돌·가림 복원,
저장·재생 조건과 파편 예산을 검사합니다. 실제 브라우저에서는 `tools/screenshot.mjs`의
`tree_healthy`, `tree_frozen`, `tree_burning`, `tree_charred`, `tree_ash`, `tree_felled`를
세로·가로/일반·절약 화질에서 확인합니다. 명시적 `inspection=1`에서만 실제 슬롯을 시전합니다.
재 장면은 실제 화염 명중 뒤 연소 시계만 앞당겨 느린 소프트웨어 GPU의 대기를 줄입니다.
