# Native forest flora and landmarks

The forest presenter replaces supported `forest_border_flora` source IDs with four shared lit mesh recipes: curved closed grass blades, paired fern leaflets, and ivory/ochre flowers with closed stems and petals. These are native volumes with normals, not camera-facing quads or texture masks. Placements use the original source foot and uniformly convert the authored height to metres; source decorators still keep roads, NPCs, stairs and portals clear. MultiMeshes are grouped by species and 12m cells with complete transformed bounds. No animation clock or new collision is added.

`LandmarkRenderer3D` replaces the four old atlas cards with actual terrain tops, cliff sides, water slabs and solid volumes. Tops use `SpatialWorld3D.surface_faces` verbatim with the existing 0.008m visual depth bias. Boundary heights sample the native ramp floor. Solids retain their authored polygons and the existing native 3.5m obstacle height. Shared limestone, paving and timber materials preserve the current material family. The old raised-top renderer excludes these successful replacements to avoid duplicate coplanar floors.

The hill uses grass above textured natural-rock cliff volumes. The stone garden uses individually tapered, irregular broken stone crowns. The rest grove uses the existing fully native oak mesh with seven volumetric exposed roots, at a uniform 7.2m height. The waterfall uses natural stone outcrops, separate upper/lower native-height ponds and a six-segment falling-water channel. Water uses the existing generated village water albedo over native rock beds with inset wet surfaces and bounded shore stones. The cascade joins the nearest authored shores rather than both pond centres. Its shader observes the existing fountain PlazaWater.phase, freezes under pause/reduced motion, and uses no shader TIME or independent clock. SceneryRenderer3D also owns exact cave arch roles, the existing field cave mouth and generated field rock definitions. Six passage arches use actual measured opening endpoints and closed extruded arch wedges; they leave the central capsule-clear passage empty. The exterior transition mouth has a native circular rock foundation (0.50m, above the existing 0.38m step limit), stone masses on both sides and behind the open vault, and a dark volumetric tunnel back. All mesh vertices stay within the existing 120px circular blocker, so the old blocked transition area is visibly marked rather than replaced by an apparently passable freestanding arch. The existing interaction still changes scenes; this does not create a new walkable tunnel. Field boulders use three closed faceted lumps bounded by their existing circular obstacle radius. Explicit future crystal roles have closed prismatic geometry, but the current dungeon has no crystal spawner and no instantiated-crystal coverage is claimed. Untagged outer field flowers/ferns/grass match their exact ForestArt frame definitions and use the same native flora family. Ten cave lamps now use static closed iron cages and warm emissive glass; their existing OmniLight3D positions and phase remain authoritative. Source simulations and all current collision rules are retained.

Reproducible generators: `scripts/rendering/vegetation/forest_flora_renderer_3d.gd`, `scripts/rendering/environment/landmark_renderer_3d.gd`, `scripts/rendering/environment/cave_lantern_renderer_3d.gd` and `scripts/rendering/environment/scenery_renderer_3d.gd`; no new generated images or external model licence is involved. Native flora uses one shared rough vertex-color material, no alpha overdraw or texture maps. New geometry must pass `native_forest_props` and the actual portrait/landscape native-world review before adoption. CPU mesh and placement records remain in `native_flora_report` / `native_landmark_report`; reports record exact replaced source IDs. Screenshot evidence is supplied by the review harness rather than treating headless tests as visual approval.

## Zero physical sprite sources and legitimate surfaces

The native ownership inventory concerns physical actors, architectural props, vegetation and landmark objects. A zero remaining-source count means every enumerated physical source has a successful native renderer owner; it does not mean every triangle in the game has volume.

Grounds, walkable ramps, water sheets, projected rings, skill particles, elemental ribbons, labels, UI and screen overlays may intentionally use planar geometry. They must remain classified as surfaces or effects rather than counted as converted physical objects. A whole building, tree, resident, monster or corpse shown as a camera-facing image remains a physical-object fallback and must not be hidden from the inventory merely because it is rendered by a spatial material.

Source records retain realm, source ID, role, definition and foot. Native owner IDs and fallback IDs are disjoint; cave return must retire its object owners and effect instances. Exact source-to-owner accounting and actual all-face renders jointly establish conversion coverage. They do not establish final style quality without visual review.

The exterior cave's dark tunnel back is offset in front of its rear rock face; they must not be coplanar. The rear and side cliff roofs taper and vary in height instead of forming a flat capped cylinder. The raised foundation and whole XZ envelope continue to match the existing transition blocker; the interaction still changes scenes.
