# Native forest flora and landmarks

The forest presenter replaces supported `forest_border_flora` source IDs with four shared lit mesh recipes: curved closed grass blades, paired fern leaflets, and ivory/ochre flowers with closed stems and petals. These are native volumes with normals, not camera-facing quads or texture masks. Placements use the original source foot and uniformly convert the authored height to metres; source decorators still keep roads, NPCs, stairs and portals clear. MultiMeshes are grouped by species and 12m cells with complete transformed bounds. No animation clock or new collision is added.

`NativeLandmarks3D` replaces the four old atlas cards with actual terrain tops, cliff sides, water slabs and solid volumes. Tops use `SpatialWorld3D.surface_faces` verbatim with the existing 0.008m visual depth bias. Boundary heights sample the native ramp floor. Solids retain their authored polygons and the existing native 3.5m obstacle height. Shared limestone, paving and timber materials preserve the current material family. The old raised-top renderer excludes these successful replacements to avoid duplicate coplanar floors.

The hill uses grass above textured natural-rock cliff volumes. The stone garden uses individually tapered, irregular broken stone crowns. The rest grove uses the existing fully native oak mesh with seven volumetric exposed roots, at a uniform 7.2m height. The waterfall uses natural stone outcrops, separate upper/lower native-height ponds and a six-segment falling-water channel. This is a native geometry pass; the waterfall currently has no independent flow animation. Native cave arches, miscellaneous legacy props and full landmark-specific scenic detailing remain conversion gaps. Ten cave lamps now use static closed iron cages and warm emissive glass; their existing OmniLight3D positions and phase remain authoritative. Source simulations and all current collision rules are retained.

Reproducible generators: `scripts/native_forest_flora_3d.gd` and `scripts/native_landmarks_3d.gd`; no new generated images or external model licence is involved. Native flora uses one shared rough vertex-color material, no alpha overdraw or texture maps. New geometry must pass `native_forest_props` and the actual portrait/landscape native-world review before adoption. CPU mesh and placement records remain in `native_flora_report` / `native_landmark_report`; reports record exact replaced source IDs. Screenshot evidence is supplied by the review harness rather than treating headless tests as visual approval.
