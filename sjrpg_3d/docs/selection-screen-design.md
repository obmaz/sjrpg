# 캐릭터 선택·이어하기 화면 제작 기준

생성 시안은 `../assets/source/entry-redesign/selection-and-continue-concept.png`이며, 실제 프롬프트와 첨부한 패밀리 원화는 같은 폴더의 `selection-generation.json`에 보존합니다. 최초 시안은 사용자가 요청한 어두운 회화형 판타지 UI 방향을 문장으로 지정해 생성했습니다. 사용자 원본을 생성 도구에 첨부한 것으로 기록하지 않습니다. 전사·마법사·숲 배경은 이 시안을 실제 이미지 참조로 사용해 별도로 생성했습니다. 생성 시안은 사용자 승인이나 실제 구현 완료 화면을 의미하지 않습니다.

선택 화면은 상단 제목·분리된 부제·두 직업 탭, 크게 읽히는 인물, 하단 정보·능력치와 시작 버튼을 한 흐름으로 구성합니다. 이어하기 화면은 선택한 인물의 상반신과 네 저장 카드, 고정된 이어하기 버튼을 사용합니다. 석재·숲의 청록색과 숯색, 얇은 청동선·아이보리 글자를 공유하며 과한 금장과 실사 사진풍을 피합니다.

원화에는 글자나 버튼을 굽지 않습니다. 모든 제목·능력치·슬롯 정보·삭제·주 행동은 실제 Godot 컨트롤이며 기존 `GameState` 저장 API를 사용합니다. 그림의 표본 수치는 게임 수치를 바꾸는 근거가 아닙니다. 기존 네 슬롯·백업 복구·손상 안내·삭제 확인·미리보기의 저장 불변·패드 포커스/뒤로 동작을 유지합니다.

세로에서는 인물이 중심이 되고, 가로에서는 인물과 조작 영역을 나란히 배치합니다. 저장 목록은 자기 영역에서만 스크롤하고 주 행동은 남겨둡니다. 얼굴 크롭은 실제 원화를 보고 정하며, 넓고 짧은 영역의 중앙 크롭으로 눈·머리가 잘리지 않게 합니다. 각 화면의 글자와 카드 경계·44CSS px 이상 터치 영역을 실측하고, 세로·가로 실제 브라우저 캡처와 시안을 함께 표시해 별도 리뷰합니다. 시안의 글자 오류나 장식이 실제 UI로 복제되어서는 안 됩니다.

선택 전용 원화·컨트롤 스타일을 사용해 기존 시작/로딩 화면을 함께 바꾸지 않습니다. 2D판은 수정하지 않습니다. 원본 PNG와 배포 WebP의 해시·실측 크기·압축값은 `selection-packing.json`을 따릅니다.
