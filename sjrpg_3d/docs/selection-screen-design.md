# 캐릭터 선택·이어하기 화면 제작 기준

사용자가 두 화면의 레이아웃·재질 기준으로 지정한 원본은
[selection-and-continue-concept.png](../assets/source/entry-redesign/selection-and-continue-concept.png)입니다.
폰 가로·세로의 실제 출력에서 이 원본과 비교합니다. 생성 시안의 고정 숫자·날짜는
게임 수치를 변경하는 근거가 아니며, 실제 슬롯과 캐릭터 값을 표시합니다.
최초 생성 프롬프트와 첨부한 패밀리 원화는 같은 폴더의 `selection-generation.json`에 보존합니다.

## 자산 재사용

인물과 숲은 이미 이 시안을 바탕으로 제작한 `assets/ui/entry/selection-{warrior,mage,forest}.webp`를
재사용합니다. 원본과 배포 이미지의 해시·크기·압축은 `selection-packing.json`을 따릅니다.
이전 `assets/ui/selection/`의 인물·트림과 공용 `woodland_panels`도 비교했으며,
이번 두 화면에는 시안에서 직접 추출한 테두리를 사용합니다. 다른 화면의 자산은 변경하지 않습니다.

사용자는 버튼 등 필요한 부분을 원본에서 잘라 사용하는 것을 허용했습니다.
`tools/assets/ui/extract_selection_concept.py`가 CTA·정보 패널·저장 카드·탭·능력치의
모서리와 테두리를 그대로 추출합니다. 내부는 글자가 없는 원본 표본을 사용해 조립하고,
정확한 원본 좌표와 결과 해시는 `assets/source/entry-redesign/concept-extraction.json`에 남깁니다.
인물·직업명·수치·버튼 이름·슬롯 정보는 실제 Godot 컨트롤입니다.
글자가 들어간 시안 전체를 배경으로 깔아 중복 글자를 만들지 않습니다.

선택 전용 글꼴은 NanumMyeongjo Regular/Bold이며 출처·OFL·해시는
[글꼴 안내](../assets/fonts/README.md)를 따릅니다. HUD와 공용 패널의 글꼴은 유지합니다.

## 화면 구성

새 캐릭터는 상단 브랜드·제목·부제·두 직업 탭, 크게 읽히는 인물, 인물 하단에 겹치는
반투명 청록 정보 패널, 능력치 두 칸, 청동 시작 버튼과 저장 슬롯 변경으로 구성합니다.
인물을 사각 장식 프레임에 가두지 않으며 원본 비율을 유지한 크롭과 가장자리 혼합을 사용합니다.

모험 이어가기는 선택한 인물의 상반신과 네 저장 카드, 고정된 이어가기 버튼을 사용합니다.
초상/빈 슬롯 표시, 번호, 직업·레벨, 위치·시각과 삭제를 카드 안에서 구분합니다.
빈 슬롯은 한 줄 제목으로 표시하고 실제 저장이 있을 때만 두 번째 정보를 보입니다.
본문 목록만 스크롤하며 주 행동과 선택한 슬롯 안내는 아래에 고정합니다.

세로는 원본의 상하 흐름을 유지하고 가로는 인물과 조작 영역을 나란히 배치합니다.
작은 폰에서 본문·카드·얼굴이 겹치지 않도록 이미지와 여백을 조절하며,
최소44 CSS px 터치 영역과 본문12 CSS px를 보존합니다.

## 진입·저장 불변 조건

타이틀의 새 모험은 빈 슬롯의 캐릭터 선택으로, 불러오기는 전체 이어가기 화면으로 연결합니다.
`ClassSelect.entry_mode`의 `new`/`continue`/`auto`가 초기 진입 의도만 정합니다.
네 슬롯·백업 복구·손상 안내·삭제 확인·미리보기의 저장 불변·패드 동작은 유지합니다.
설정 안에서 다른 모험을 불러오는 패널은 기존 `SaveLoadPanel`을 사용합니다.

새 모험에서 바로 열린 선택 화면의 뒤로가기는 타이틀로 돌아옵니다. 목록의 빈 슬롯에서
열린 선택 화면은 목록으로 돌아옵니다. 화면·패드·OS 뒤로가기는 같은 단계를 따르며,
열린 삭제 확인창이 있을 때 배경의 지연된 버튼 신호로 닫거나 다른 슬롯을 변경하지 않습니다.

## 검수

`entry_layout`, `save_layout`, `title_menus`, `entry_loading`, `entry_probe_budget`와
저장·패드 회귀를 검사합니다. 실제 브라우저 하네스는 `tools/check_save_layout.mjs`이며
`SJRPG_ENTRY_VISUAL_ONLY=1`이면 인물·슬롯·삭제의 가로/세로 그림과 측정값을 남깁니다.
`tools/compare_entry_design.py`는 원본·변경 전·후를 비율을 유지해 나란히 표시합니다.
감독자 검토는 최대10회로 제한하며 일회성 결과는 `build/reports/`에 둡니다.
시작/로딩 원화·2D판은 변경하지 않습니다.
