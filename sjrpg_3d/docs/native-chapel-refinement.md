# 예배당

최상위 기준은 사용자가 직접 다시 지정한 [실제 게임 화면](../assets/source/style/approved-game-reference.jpg)입니다. 파생 컨셉을 원본 기준으로 대신하지 않습니다. 원본의 낮게 돌출된 왼쪽 입구, 훨씬 높고 가파른 오른쪽 본당, 뒤쪽 종탑과 두 박공의 비례를 따릅니다.

`NativeChapelPlan`의5.6×약4.80m L자 몸체를 표시와 실제 물리가 공유합니다. 입구 지붕 꼭대기는4.6m, 본당은6.2m, 종탑은7.8m입니다. 본당의 앞면은 전체 깊이의0.30 지점이며 입구와의 앞뒤 간격을 줄였습니다. 왼쪽 입구의3단 계단과0.28m 바닥은 같은 계획을 사용합니다. 본당 앞의 빈 마당을 사각형 건물로 막지 않습니다.

`assets/models/architecture/chapel/albedo.png`의2×2 원화는 입구·본당 정면·측면·석재입니다. 이미지의 문·창·유리·돌 세공은 한 면 전체에 붙이고, 몸체·두 지붕·열린 종탑·창/문 몰딩·부벽·계단은 실제 부피로 만듭니다. 창의 그려진 유리와 세공을 실제 구멍이라고 주장하지 않습니다. 기본 직교120° 카메라는 유지합니다.

`facade.gd`와 `facade.gdshader`는 `asset.json`의 `facadeWarp` 표를 공유합니다. 원형 장식과 창의 둥근 머리를 세로로 늘이지 않도록 정면의 높이 구간별 UV를 조절합니다. 몰딩 위치도 같은 표의 역변환을 사용합니다. 앞·뒤·양쪽 면과 실제 앱 화면에서 그림/입체 몰딩 경계·지붕 연결·계단 진입·주변 상자 공간을 확인합니다.

석재 채움은2.24m 타일이며 실제 그림의 약7단을 기준으로 약0.32m 단 높이를 맞춥니다. 지붕은 기존 슬레이트 배율과 실제 겹침 단을 유지합니다. 생성 원본·정확한 프롬프트·직접 첨부한 사용자 화면 해시는 `assets/source/architecture/chapel/`에 보존합니다.
