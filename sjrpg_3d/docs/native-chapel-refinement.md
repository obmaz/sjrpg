# 네이티브 예배당

`Ortho3DChapel.build(presenter, root, width, depth, height)`가 기존 마을의 실제 배치에서 예배당을 만듭니다. 예배당은 중심 위치를 유지한 채 원래 배치보다25% 커졌으며, 기단 높이0.28m와 세 단의 계단은 `NativeChapelPlan`을 통해 실제 FLOOR와 공유합니다. 카메라는 Y-up·직교120°를 유지합니다.

정면 문짝은 외벽 안쪽에 들어가며 금속 가로대·리벳도 문짝에 붙습니다. 세 겹의 뾰족 아치와 작은 문설주 기둥이 깊이를 만듭니다. 앞뒤 박공에는 실제 원형 개구부, 안쪽 유리와 석재 트레이서리가 있습니다. 양 측면의 란셋 창은 단계별 석재 프레임을 가지며 뒤편에도 종탑을 피한 창이 있습니다. 기둥·석재 테두리·처마가 여러 방향에서 같은 구조로 이어집니다.

벽 채움은 `assets/models/architecture/chapel/asset.json`의 전용 생성형 네 면 원화를 사용합니다. 실제 로컬 좌표에 따라 각 외벽 전체에 한 셀을 배치하고, 문·창의 개구부와 돌출된 테두리는 실제 기하가 유지합니다. 원본·실제 프롬프트·해시는 `assets/source/architecture/chapel/`에 있습니다. 공유 석재 테두리·목재·슬레이트와 스테인드글라스는 기존 재질을 사용합니다.

슬레이트는32.5cm 단 간격으로 경사를 가로질러 이어지고, 기와 겹침과 줄눈은 실제 기하입니다. 종탑·첨탑·아치와 원형 개구부 때문에 일반 주택보다 큰 예산을 사용하되30,000삼각형·8서피스 이내를 유지합니다. 과거 후보의 특정 측정값을 현재 배치의 수치로 사용하지 않습니다.

`ortho_3d_chapel`은 실제 메시의 법선·UV·앞뒤 면 방향, 문 깊이·창·박공 구멍·기단·계단의 실제 광선 접점을 검사합니다. 닫힌 건물의 상세 기하가 보행 가능한 내부를 뜻하지는 않습니다. 채택 전 모바일 가로/세로에서 여러 모서리·그림자·문 접근·NPC 가림과 주변 건물의 재질 밀도를 함께 확인합니다.

외부 모델 제작과 에셋별 커밋 경계는 [에셋 협업](asset-workflow.md)을 따릅니다.
