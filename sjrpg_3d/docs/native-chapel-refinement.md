# 네이티브 예배당 세부 구조

[3D 에셋 제작 기준](../../docs/3d-asset-guide.md)과 기존 사용자 레퍼런스를 따르는 예배당의 제한된 기하 개선입니다. `Ortho3DChapel.build(presenter, root, width, depth, height)` API, 3.5×3m 발자국, Y-up 축, 고정 정투영 카메라, 0.28m 출입구 바닥과 기존 이동 충돌을 유지합니다.

정면 문짝은 외벽에서 28cm 들어가며 금속 가로대·리벳도 문짝에 붙습니다. 세 겹의 뾰족 돌 아치와 작은 문설주 기둥이 깊이를 만듭니다. 앞뒤 박공은 벽 위에 원판을 붙이는 대신 실제 원형 개구부를 내고, 안쪽 유리와 네 잎 석재 트레이서리를 넣습니다. 양 측면의 네 란셋 창은 단계별 석재 프레임을 가지며 뒤편에도 종탑을 피한 작은 창이 있습니다. 앞뒤 모서리 기둥과 얇은 처마·석재 지붕 테두리가 모든 방향에서 같은 재료와 구조로 이어집니다.

슬레이트는 기존 공유 재질을 쓰며 각 경사에 12행의 얕은 물리적 겹침을 둡니다. 새 그림, 가짜 정면 카드, 과한 금색 장식, 건물별 색 보정은 추가하지 않습니다. 기존 생성형 석회암·목재·슬레이트와 기록된 스테인드글라스 추출본을 그대로 사용합니다.

실제 기하는 27,276삼각형, 6개 병합 서피스입니다. 일반 주택보다 큰 예산은 종탑·첨탑, 실제 아치/원형 벽 개구부, 양면 창 장식 때문이며 상한은 30,000삼각형/8서피스입니다. 작은 측면 원형 장식과 선형 원기둥의 중복 분할은 줄이고 큰 박공의 윤곽은 유지했습니다. 종탑 최고점은 약 9.66m입니다. 기존 시각 기단의 윗면이 물리 바닥보다 5cm 높았던 부분을 0.33→0.28m로 맞췄습니다. 물리 바닥이나 경사로 높이는 바꾸지 않았습니다.

[제작·출처 기록](../assets/source/preview3d/chapel/refinement.json)은 기준 커밋과 코드/레퍼런스/재질 해시, 미터 경계, 실제 검수 수치를 보존합니다. `ortho_3d_chapel` 검사는 법선·UV·앞뒤 면 방향과 실제 메시 광선으로 문짝 깊이, 기단 높이, 양 측면/뒷면 창과 앞뒤 박공 구멍을 확인합니다. 닫힌 건물의 상세 기하는 보행 가능한 내부나 전체 지붕 형태의 콜라이더를 뜻하지 않습니다.

헤드리스 기하 검사는 통과했습니다. 모바일 세로·가로 실제 화면에서 재질, 여러 모서리, NPC 가림, 레퍼런스 분위기를 비교하는 검수는 별도로 필요하며 헤드리스 결과만으로 시각적 완성이나 사용자 승인을 선언하지 않습니다.
