# 예배당

최상위 기준은 사용자가 직접 다시 지정한 [실제 게임 화면](../assets/source/style/approved-game-reference.jpg)입니다. `remake/chapel-v2.png`와 `chapel-new.png`는 이 화면의 파생 제작물이며 기준을 대신하지 않습니다.

사용자가 전체 면 이미지 사용을 허용했으므로 창·문·고딕 세공은 생성형 원화로 표현합니다. `assets/models/architecture/chapel/albedo.png`의 네 셀은 왼쪽 입구·오른쪽 본당 정면·측면·빈 석재입니다. 원본 화면만 실제 참조로 첨부한 정확한 프롬프트·원본 해시는 해당 소스 폴더에 있습니다.

`Ortho3DChapel`은 돌출 입구와 오른쪽 본당, 두 지붕, 굵고 열린 종탑, 부벽, 계단을 실제 부피로 만듭니다. 각 면은 건물에 고정되어 다른 방향에서도 보이며 카메라를 따라 회전하지 않습니다. 문과 창의 그려진 세공은 실제 구멍으로 주장하지 않으며 문은 닫혀 있습니다. 기본 직교120° 카메라는 유지합니다.

`NativeChapelPlan`이 확대 배율1.30·왼쪽 입구 중심·3단 계단·L자 몸체 윤곽을 공유합니다. 네이티브 바닥은0.28m이고 본당 앞의 움푹 들어간 마당을 보이지 않는 사각형 건물로 막지 않습니다. 실제 배우 캡슐의 계단 진입과 주변 NPC 동선을 확인합니다.
