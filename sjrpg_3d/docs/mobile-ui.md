# 모바일 UI 배치와 검수

설정·스킬·원정·일지·가방·장비·일시정지와 진입 화면은 실제 글자·조작·스크롤을 기준으로 검수합니다.
기존 생성형 UI의 슬레이트 질감·청동 장식·금색/청동 버튼 외형을 보존합니다. 화면 크기별 레이아웃 개선을 이유로 이 스타일을 단색 테마로 대체하지 않습니다.

## 공용 계약

- `UiMetrics.units_per_display_pixel()`은 웹 CSS px, Android dp를 Godot 논리 좌표로 바꿉니다. Android 창 크기는 물리 픽셀이므로 `screen_get_dpi()/160`을 반영합니다. 접힘 전환 중 크기가 없으면1배로 시작하고 크기 변경 후 다시 맞춥니다.
- `UiKit.GeneratedSkin`은 `woodland_panels`의 기존 원화를 사용합니다. 원본 자르기 좌표, 실제 표시 배율, 글자 안전 여백을 분리합니다. 큰 프레임 모서리는 비율을 유지하고 작은 카드는 전용 카드 원화를 사용합니다. 버튼의 뾰족한 양끝·중앙 문양을 보존하며, 긴 문구는 실제 안쪽 면에 맞춰 높이를 확보합니다.
- `PanelFrame`은 안전 영역 안의 헤더/닫기, 스크롤 본문, 고정 푸터를 분리합니다. 제목·부제와 본문·조작 사이의 가독 간격을 확보합니다. 공통 위젯과 하위 패널은 `display_pixel_scale()` 한 경로를 사용합니다. 검수에서 배율을 바꿀 때도 이 메서드를 재정의해 서로 다른 축의 배치가 덮어쓰지 않게 합니다.
- 본문·상태·수치는 가독 고딕과 최소14표시 단위를 사용합니다. 메뉴 버튼은 최소56표시 단위, 버튼 글자는 최소16표시 단위, 이웃 버튼 사이는12표시 단위를 확보합니다. 버튼을 담는 행·열도 같은 표시 배율을 사용합니다.
- 설정은 항목 이름·현재 값과 실제 오류/저장 결과를 중심으로 표시합니다. 부가 설명은 상시 나열하지 않으며 설치 안내·게임패드 조작·자산 라이선스는 요청했을 때 별도 팝업으로 엽니다.
- 짧은 가로 화면에서는 프레임의 세로 여백과 모서리 표시 크기를 함께 줄여 큰 조작 영역과 최소40표시 단위의 스크롤 본문을 확보합니다.
- 긴 제목·상태·가격·실패 이유는 줄바꿈합니다. 고정 행·열 수보다 실제 최소 크기로 열 수와 세로 배치를 결정합니다.
- 기본 스크롤바는 표시하지 않습니다. `ScrollArrows`가 실제 스크롤 범위와 위치를 읽어 생성형 청동 화살표로 남은 방향만 알립니다. 가장자리 공간을 예약하고 손가락·휠·패드 입력을 유지합니다.
- 버튼 내부 장식도 드래그를 스크롤에 전달합니다. `Range`와 독립 스크롤의 입력 소유권은 유지하며, 스와이프 종료가 선택/삭제/장착/설정 변경으로 실행되지 않아야 합니다.
- 저장 목록이 넘칠 때는 더 볼 내용이 있음을 안내합니다. 네 저장이 모두 들어가는 큰 화면은 남은 높이를 분배하고 카드의 초상·번호·본문을 가운데 정렬합니다.
- 폰트 변경 뒤에는 최소 크기 갱신을 기다려 절대 배치를 정착시킵니다. 같은 값의 폰트/문구를 반복해서 쓰며 무한 재배치를 만들지 않습니다.

## 검수

일반 폰390×844/844×390, 작은 폰320×568/568×320, 외부 화면을 대표하는344×883/883×344,
펼친 비율768×896/896×768과800×800을 확인합니다. 이는 대표 비율 검수이며 특정 Fold 실기기의 측정값을 뜻하지 않습니다.

`panel_layout`, `panel_scroll`, `ui_tone`, `skill_layout`, `bag`, 진입·저장·설정 회귀를 검사합니다.
실제 웹의 `tools/check_mobile_panels.mjs`는 한 번 부팅한 게임에서 실제 입력으로 패널을 열고 글자/조작 크기와 스와이프·끝 내용 접근을 검수합니다. 외곽 사각형뿐 아니라 프레임과 버튼의 실제 콘텐츠 영역 안에 글자가 놓이는지도 확인합니다.
`tools/check_save_layout.mjs`는 실제 저장 행에서 손가락 드래그를 시작해 오발 없이 목록이 움직이는지 검사합니다.
`tools/check_entry_loading.mjs`는 실제 진입의 페인트 장벽과 로딩 표시를 확인합니다.
검수 probe는 명시적 `inspection=1&ui_layout_review=1`에서만 추가하며 위치나 게임 상태를 바꾸지 않습니다.
일회성 화면·진단은 `build/reports/`에 둡니다.
