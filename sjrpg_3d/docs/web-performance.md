## 이동 중 프레임 비용 검사

표시 프레임의 골격 샘플링은 소스 시계에서 계산한 시각에 `AnimationPlayer.seek(time, true)`를 한 번 적용합니다. Godot4.7.2는 이 호출에서 이미 트랙 평가와 포즈 적용을 완료하므로 이어지는 `advance(0)`을 생략합니다. 마법사·상인·미라의 애니메이션 시간·보행 거리·공격 진행률·일시정지·히트스톱은 유지합니다. `native_animation_sampling`은 실제 수입 모델의65개 본 전체를 이전 방식과 비교하고, 테스트 전용 트랙 처리 훅으로 중복 평가 제거를 확인합니다.

배우의 피격 오버레이는 실제 재질 참조가 바뀔 때만 교체합니다. 피격하지 않는 프레임에는 사용하지 않는 오버레이 uniform을 쓰지 않으며, 적의 알베도도 실제 색·알파가 바뀔 때만 갱신합니다. 피격 색상·페이드·인스턴스별 재질 소유권은 유지합니다.

이동 모터는 한 스텝에서 이미 바닥을 확인한 전체 목적지 포즈와 충돌 후 실제 포즈가1µm 이내일 때만 바닥 샘플을 재사용합니다. 충돌로 미끄러지거나 가장자리에서 회복된 포즈는 기존처럼 실제 위치의 바닥을 다시 검사합니다. `native_floor_query_budget`은 실제 마을 물리에서 정상8스텝의 바닥 ray가16회에서8회로 줄어드는지 검사하고, `native_threshold_support`는 문턱 높이와 관통 방지를 별도로 확인합니다.

이 작업의 고정 기준은 `8fb18bf8d67467a8baf75fe91171f47ba8e09169`입니다. 소프트웨어 렌더러의 프레임 간격과 갤럭시 S26의 실제 프레임률은 구분합니다. 텍스처·모델·광원·카메라의 품질을 낮추거나 게임 시뮬레이션 속도를 바꾸지 않습니다.

`.github/workflows/frame-pacing-review.yml`은 위 기준과 현재 소스를 같은 worker에서 차례로 내보냅니다. 두 임시 빌드에 동일한 읽기 전용 관찰기를 주입하고, 360×780 CSS·DPR3·고품질 마법사로 정상 시작 화면과 빈 슬롯을 거쳐 실제 키보드와 터치 이동을 각각 수행합니다. 입력별 최소120개의 `RenderingServer.frame_post_draw` 간격과 실제 이동·카메라 추적·물리 진행을 확인하고 p50/p95/p99·엔진 처리 시간·드로콜·메모리를 아티팩트에 남깁니다. GPU 완료나 실제 화면 표시 시점을 측정한 값은 아니며, 강제 GC·텔레포트·체력 변경·카메라 고정은 사용하지 않습니다. 관찰기는 운영 진입점에 연결하지 않습니다.

## 숨겨진 원본 캔버스의 프레임 비용

네이티브3D에서는 원본2D 캔버스(`field_root`)가 항상 숨겨져 있으므로, 화면에 영향을 주지 않는 프레임별 작업은 실행하지 않습니다. 게임 규칙·충돌·표시 결과는 바뀌지 않습니다.

- `SpatialWorld3D.sync_scope`는 모든 공간 질의의 입구입니다. 성문·상자의 `collision_layer`는 값이 실제로 달라질 때만 물리 서버에 씁니다. 상태 확인은 매 질의마다 유지하므로 닫힌 성문은 다음 질의부터 즉시 막습니다.
- 표시기(`Ortho3DPreview`·`NativeCombatFx3D`·`NativeZoneFx3D`)는 `Effect.in_world`의 그룹 목록을 읽습니다. 나무·바위·풀까지 포함한 `world` 자식 전체를 매 프레임 순회하지 않습니다.
- `WorldOcclusion.update`는 캔버스가 숨겨진 동안 셰이더 전역값만 갱신하고 가림 대상 탐색을 생략합니다. `CanopyShade`는 원본 나무가 숨겨져 있으면 처리를 멈추고 가시성·트리 변경 시 다시 깨어납니다. 숨겨진 시체·소환석·효과는 다시 그리기를 요청하지 않습니다.
- `window.__sjrpg3dProbe` 전체 보고서는 자동화 브라우저(`navigator.webdriver`)나 `?probe=1`·`?benchmark=1`에서만0.5초마다 만듭니다. 일반 플레이에서는 `window.__sjrpg3dReady`만 한 번 게시합니다. 수동으로 콘솔에서 보고서를 보려면 주소에 `?probe=1`을 붙입니다.

`frame_cost` 케이스가 그룹 목록의 순서, 숨겨진 그늘의 대기, 성문 충돌의 즉시 반영을 검사합니다.
