# 새로운 모험

Flutter 3.47.8 · Bonfire 4 기반 핵앤슬래시 게임입니다. `/sjrpg/new/`에 배포하며 기존 버전과 독립적으로 실행됩니다. 지원 브라우저는 Dart WASM·Skwasm으로 실행하며 미지원 브라우저는 JS 호환 빌드를 사용합니다. 준비·검사·빌드·배포 명령은 [저장소 README](../README.md#새-버전-개발)를 따릅니다.

- 주인공 16방향·적 8방향 그림과 연속 360도 조이스틱
- 전사와 마법사, 근접 연타·원소 투사체·분노/마나·직업별 스킬 6종·회피
- 넓은 초원·숲·호수·강·목교·모래벌판과 고정 시작 마을
- 경험치 레벨·스킬 포인트·최대 5등급 투자·주/보조 스킬 두 개 지정·독립 대기시간
- 장비 24종·4등급·독립 옵션·3부위 장착·24칸 가방·비교·판매·물약
- 제1장 십자로의 숲·6개 상자·네 방향의 후속 지역 입구·120마리 처치 후 공격 예고·회피·기절이 적용되는 골렘 보스
- 설정의 전체화면 전환·타격 진동/확인·브라우저별 진동 설정 저장
- 생성 그림 팝업·가방·스킬·여정/지도·상점·설정·일시정지·정화 후 탐험

기존 탈것·전체 장비·사막 원정은 이 버전의 범위에 포함하지 않습니다. 진행 저장은 아직 없습니다. 한글 글꼴 Nanum Gothic은 `assets-fonts/OFL.txt`의 SIL Open Font License를 따릅니다. 그림 원본과 D&D 참고 콘텐츠의 출처는 [콘텐츠 기준](../docs/content-reference.md)에 있습니다.
