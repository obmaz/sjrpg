# 새로운 모험

Flutter 3.47.8 · Bonfire 4 기반 모바일 핵앤슬래시 RPG입니다. `/sjrpg/new/`에 배포하며 Legacy와 독립적으로 실행·저장·빌드합니다.

전사·마법사, 세 탭의 직업별 스킬 트리, 장비·강화·상점·구매형 탈것, 필수 의뢰와 우물 워프, 두 시대의 분기와 총 일곱 지도를 제공합니다. 시작 화면에서 새 모험 또는 저장한 모험 이어하기를 선택합니다. 설정은 전체화면·진동·앱 설치를 지원합니다.

지원 브라우저는 WASM·Skwasm을 사용하며 미지원 브라우저는 JS 호환 빌드로 실행합니다. 실제 게임 안내와 준비·검사·빌드 명령은 [저장소 README](../README.md#새-버전-개발)를 따릅니다. 코드 구조·동작 계약·캐시 소유권은 [개발 참고](../docs/development.md)에 있습니다. 이전 버전은 [Legacy 안내](../docs/legacy-guide.md)를 참고합니다.

한글 글꼴 Nanum Gothic의 SIL Open Font License는 `assets-fonts/OFL.txt`에 보존합니다. 참고 콘텐츠·생성 그림의 출처와 원본은 [콘텐츠 기준](../docs/content-reference.md)에 있습니다.
