# 자연의 수호자

핵앤슬래시 모험 게임을 두 버전으로 제공합니다. 새 버전은 Flutter·Bonfire 4로 다시 만든 독립 게임이며, 기존 JavaScript 게임은 그대로 보존합니다. 두 버전 모두 키보드와 모바일 터치로 플레이합니다.

- **[새로운 모험 · Flutter / Bonfire](https://obmaz.github.io/sjrpg/new/)**: 전사·마법사를 고르고 제1장 ‘십자로의 숲’을 탐험합니다. 직업별 기본 공격·분노/마나·전사 스킬 20종·마법사 18종, 경험치 레벨·스킬 포인트, 장비 24종과 희귀도·옵션·장착·판매, 물약·보물 상자·상점·지역별 보스를 갖췄습니다. 제1장 의뢰를 해결하면 완료 화면 아래에 고정된 **제2장 의뢰 받기**로 사막 유적에 진입합니다. 계속 탐험을 선택해 남은 전리품을 찾을 수도 있습니다. 클리어한 저장을 이어서 열어도 여정 하단의 고정된 다음 의뢰 버튼으로 진행할 수 있습니다. 제2장에서는 야영지 서쪽 기록관이나 동쪽 통신관에게 첫 의뢰를 받습니다. 의뢰인에 따라 고대 왕국 제3-1장 또는 사이버펑크 제3-2장으로 이어지는 네 의뢰가 정해집니다. 각 지역은 같은 크기의 독립 지도입니다. 새 장으로 이동하면 해당 시대의 의뢰 일지를 먼저 보여주며, 읽는 동안 전투는 멈춥니다. 일반 이어하기는 바로 플레이를 재개합니다. 일지는 의뢰인 위치를 안내하고 첫 의뢰는 해당 NPC와 대화해 수락합니다. 후속 의뢰는 같은 줄기의 일지에서 이어 받을 수 있습니다.
- **[기존 모험 · Legacy](https://obmaz.github.io/sjrpg/legacy/)**: 이전 장비·퀘스트·사막 원정·탈것을 유지하는 Canvas 2D·JavaScript 게임입니다.

## 새 버전 개발

Flutter **3.47.8**과 Node.js 24 이상이 필요합니다. 공유 그림은 기존 원본을 유지하며 준비 스크립트로 복사합니다.

```sh
npm ci
npm run prepare:new
cd flutter_game
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run -d chrome
```

두 버전의 빌드는 분리되어 있습니다. Flutter는 WASM으로 빌드하며, Legacy는 동일한 배포본 또는 검증된 캐시를 재사용합니다. 마지막 조립 단계에서 두 경로를 같은 GitHub Pages 배포 파일에 넣습니다.

```sh
cd flutter_game
flutter build web --wasm --release --base-href /sjrpg/new/ --no-web-resources-cdn
cd ..
npm run check
npm run prepare:legacy
npm run build
```

`npm run build`는 준비된 두 산출물을 복사하는 조립 명령입니다. Legacy 소스가 바뀌었거나 기존 배포본을 복원할 수 없을 때만 `prepare:legacy`가 Legacy를 빌드합니다. Legacy만 직접 빌드하려면 `npm run build:legacy`, Flutter만 빌드하려면 `npm run build:new`를 사용합니다. CI는 두 버전의 입력을 각각 캐시하고 독립 작업으로 준비합니다.

새 지도의 가로·세로는 이전의 75%인 34,560×25,920입니다. 이전 저장의 캐릭터·탈것·적·보물 위치도 같은 비율로 옮기며 레벨·장비·의뢰 진행은 유지합니다. 현자·성소·의뢰 지점에 가까이 가면 현재 상태와 다음 행동을 안내합니다. 성소 주변의 적을 정리한 뒤 안내 카드의 정화/조사 버튼을 누르세요. 사막 의뢰의 처치는 수락한 뒤부터 집계됩니다.

탈것은 이동 거리와 피격에 따라 내구도가 줄어듭니다. 20% 이하는 감속하고, 0%에도 저속으로 이동할 수 있어 배에 갇히지 않습니다. 탑승 중이거나 탈것 가까이에서 설정을 열면 골드로 보수할 수 있습니다. 내구도가 0인 탈것은 보수 후 직접 타야 합니다.

결과는 `dist/index.html`(선택 화면), `dist/legacy/`(기존 게임), `dist/new/`(Flutter 게임)입니다. 새 버전은 자산·엔진을 같은 서버에 포함하고 버전별 경로에 보관합니다. 두 게임의 진행은 별개입니다. 새 버전은 이 브라우저에 5초마다 체크포인트를 저장하고 시작 화면의 **모험 이어하기**로 돌아옵니다. 레벨·장비·스킬·골드·상자·이야기·미수집 전리품·보스 체력을 유지합니다. 주변 일반 적의 남은 체력과 지역별 출현 횟수도 유지합니다. 다음 스테이지 이동은 저장에 성공한 뒤 진행하며, 실패하면 현재 의뢰 화면에서 다시 시도할 수 있습니다. 새 모험은 이전 저장을 덮어쓰고, 기존 Legacy는 새로고침하면 초기화됩니다. 새 버전의 키보드 조작은 WASD/방향키 이동, Space/J 연속 공격, N/K·L·O·P 사용 스킬 1~4, 왼쪽 Shift 회피, 1/2 생명·자원 물약입니다. 모바일에서는 조이스틱·공격·스킬·회피·물약을 동시에 사용할 수 있습니다. 분노·마나가 부족한 스킬은 그림을 어둡게 표시하며, 물약이나 회복으로 자원이 채워지면 다시 밝아집니다. 상점·대화·성소·탈것은 조이스틱 위에 주변 행동 버튼으로 표시됩니다. 우물의 의뢰 안내와 타기·워프는 함께 사용할 수 있고, 상자는 공격해 부숩니다. 가까운 주민이 여럿이면 더 가까운 쪽과 대화합니다. 유성·대지 강타는 짧게 누르면 자동 조준하고, 누른 채 끌면 표시된 범위를 향해 손을 놓을 때 시전합니다. 버튼에서 멀리 끌어 붉은 취소 표시가 나오면 자원을 쓰지 않고 취소합니다.

지역 보스는 숲의 파수꾼·사막의 황금 수호자·고대 왕국의 석상왕·미래의 방어 코어로 외형을 구분합니다. 사막 수호자·석상왕·미래 방어 코어도 여덟 방향·두 보행 자세로 움직입니다. 보스 이름은 어두운 판 위에 표시해 밝은 바닥에서도 읽기 쉽습니다. 피격 때 주인공은 짧게 밝아지며, 잠깐의 피해 보호는 발밑 빛으로 표시해 전투 중에도 몸체가 선명하게 보입니다. 전투 HUD는 골드·시간을 간결하게 표시하고 처치 수는 여정과 결과 화면에서 확인합니다. 미니맵은 월드 가장자리에서도 주인공을 중앙에 고정합니다. 출현한 보스는 붉은 표식으로 표시하며 멀리 있으면 미니맵 가장자리에 방향을 보여 줍니다. 큰 지도에서는 보스의 실제 위치와 이름을 확인할 수 있습니다. 미니맵을 누르면 큰 지도가 열리며 두 손가락 확대·드래그·내 위치/전체 지도 버튼을 사용할 수 있습니다. 설정의 **앱 설치**는 지원 브라우저의 설치 창을 열고, 다른 브라우저에서는 홈 화면 추가 방법을 안내합니다. 설치한 앱도 인터넷 연결이 필요합니다.

새 버전 설정의 **전체화면 켜기/끄기**로 화면을 전환할 수 있습니다. 전체화면에 들어가면 화면 크기에 맞추고, 나가면 진입 시 모바일 높이를 복원합니다. **타격 진동**은 적중·피격·스킬마다 다르게 동작하며 설정에서 켜고 끄거나 확인할 수 있습니다. **전투 효과음**은 베기·망치·화염·냉기·번개·함성·피격·전리품을 구분하며, 같은 설정 화면에서 끄거나 확인할 수 있습니다. 소리는 첫 터치나 키 입력 이후 재생하고 일시정지·백그라운드 전환 때 멈춥니다. 설정은 브라우저에 저장됩니다. 진동 설정은 카드 전체를 눌러 바꾸며, 앱 설치 안내의 본문이 길어도 확인 버튼은 아래에 고정됩니다. 전체화면·진동은 지원되는 기기/브라우저에서 사용할 수 있습니다.

지원 브라우저는 Dart WASM과 Skwasm을 사용하며 미지원 브라우저는 JavaScript/CanvasKit 호환 빌드로 실행합니다. GitHub Pages에서는 단일 스레드 Skwasm을 사용합니다. 처음의 버전 선택 화면은 짧은 두 버튼으로 구성해 모바일 세로·가로 화면에서 스크롤 없이 고를 수 있습니다.

전사는 전투 기술·전투 숙련·함성의 3계열 20종, 마법사는 화염·냉기·번개의 3계열 18종 스킬 트리를 사용합니다. 직업의 모든 계열을 한 트리에 함께 표시하며, 분기·합류 연결선과 습득 레벨이 있습니다. 합류 기술은 표시된 선행 기술을 모두 해당 등급까지 익혀야 배울 수 있으며 레벨마다 얻는 포인트로 최대 5등급까지 투자합니다. 노드를 고르면 작은 화면에서도 선택 위치를 맞춰 보여 줍니다. 화면 아래에서 바로 습득·강화하고, 정보 버튼에서 설명·현재/다음 등급의 피해와 주요 능력치·네 전투 슬롯 배치를 확인합니다. 수치는 현재 장비와 레벨을 기준으로 계산하며 미리 보기에는 포인트를 쓰지 않습니다. 새 사용 기술은 빈 슬롯에 자동으로 지정되고 배운 기술끼리 바꾸면 자리를 교환합니다. 조준 기술을 두 손가락으로 조작할 때는 마지막으로 시작한 유효한 조준을 유지하며, 다른 기술 버튼을 놓아도 먼저 발동하지 않습니다. 첫 슬롯은 비울 수 없으며, 첫 기술을 빈 슬롯으로 옮기는 버튼은 비활성화하고 이유를 표시합니다. 재사용 대기시간은 배치를 바꿔도 유지됩니다.

전투 집중은 기본 공격 간격을 줄이고, 전장의 맹세는 생명과 함성 보호 시간을 늘립니다. 고양의 울림은 함성으로 보호받는 동안 **실제 적중**에만 분노를 더 주며 빗맞힌 공격에는 적용되지 않습니다. 온기는 마나 회복을 늘리고 냉기·번개 숙련은 해당 무기와 기술의 피해를 강화합니다. 기존 저장에서 배운 기술과 배치는 그대로 유지되며 새로 배울 기술부터 선행 조건을 적용합니다. 초기화는 확인 창에서 50골드를 사용해 무료 기본 공격·시작 기술 1등급을 제외한 투자 포인트를 돌려줍니다. 현재 보호·격노·소용돌이 효과는 종료되고 대기시간은 유지됩니다. 초기화한 뒤에는 트리의 선행 기술을 다시 배워야 합니다.

새 숲·고대 왕국·미래 모험은 가까운 필수 성소를 미니맵의 금색 테두리·화살표로 안내합니다. 추적하던 성소를 정화하면 현재 위치에서 가장 가까운 남은 성소로 이어집니다. 사막은 NPC에게 첫 의뢰를 받은 뒤 수락한 의뢰만 자동으로 안내하며, 다음 의뢰는 직접 수락합니다. 큰 지도에서 진행 가능한 의뢰 목표를 눌러 추적 대상을 바꾸고 같은 목표를 다시 눌러 끌 수 있습니다. 추적을 끈 상태와 직접 고른 목표는 이어하기·우물 이동에도 유지됩니다. 화살표는 직선 방향 안내이며 캐릭터를 자동 이동시키지 않습니다.

새 버전 스킬 트리는 슬롯·트리·하단 버튼의 안쪽 여백을 맞추고 계열 제목을 고정합니다. 주인공과 몬스터의 보행은 실제 이동 거리에 맞춰 발동하며 방향 전환과 피격 반동을 보간합니다. 주인공은 고주사율 화면에서 조이스틱을 약하게 밀어도 실제 이동에 맞춰 보행합니다. 주인공은 멈추거나 벽에 막히면 기본 자세로 돌아오며, 처음 도보 상태와 탈것에서 내린 뒤의 몸체 크기는 같습니다. 몬스터는 공격을 준비하고 타격한 뒤 자세를 회수하며, 근접 공격을 준비하는 동안 범위를 벗어나면 피할 수 있습니다. 무리가 모이면 발판 간격을 유지하며 돌아서 접근하고, 넉백도 다른 몬스터를 관통하지 않습니다. 근접 명중은 타격 방향의 섬광과 짧은 동작 정지로 구분하고, 한 번의 광역 베기로 카메라 반응이 중첩되지 않습니다. 피격한 적은 짧게 밀려나며 이동 중에도 장애물을 통과하지 않습니다. 적 체력바의 밝은 잔상은 방금 잃은 체력을 보여 주고 곧 실제 남은 체력까지 줄어듭니다.

가방·설정·지도·스킬 상세를 연 상태에서 뒤로가기를 누르면 게임 안의 창부터 닫습니다. 전투 화면에서는 일시정지로 연결하며 브라우저의 이전 사이트로 이동하지 않습니다. 패배 화면에서는 저장을 지우거나 자동으로 재시작하지 않고 게임 안의 선택 화면으로 돌아갑니다. 마지막 살아 있던 체크포인트는 이어하기에 남습니다. 스킬·마법의 재사용 대기시간은 이전보다 30% 짧아졌고 일반·정예·보스 체력은 20% 낮췄습니다. 이어하기에서는 남은 체력 비율을 보존해 한 번만 조정합니다. 분수 마을 동쪽의 보이는 출구는 도보와 탈것으로 통과할 수 있으며 말·오토바이·배는 8방향과 두 동작의 전용 그림을 사용하며 발굽·꼬리·바퀴·노가 가장자리에서 잘리지 않도록 배치합니다. 피해 숫자는 타격별로 유지하면서 겹치지 않게 배치합니다.

호수와 강이 만나는 곳은 하나의 물가로 표시하며 물 안에 가짜 강둑이나 흙길이 겹치지 않습니다. 게임 화면과 지도 모두 같은 물 영역을 쓰고, 실제 다리는 별도로 표시합니다. 확대 지도는 월드 가장자리에서 큰 빈 공간이 나타나지 않도록 이동 범위를 제한합니다. 내 위치·의뢰 목표는 보이는 영역에 맞춰 표시하고, 전체 지도는 가운데에 맞춰 보여 줍니다.

일반 몬스터의 장비 드롭은 20마리당 한 번이며 상점은 원하는 무기를 확실히 얻는 경로입니다. 정예·보스는 직업에 맞는 노란색 희귀 무기를 주고, 희귀 무기에는 적중 둔화·받는 피해 감소·처치 시 회복 중 한 특수 능력이 붙습니다. 능력은 가방 목록에서 바로 확인하며 장착할 때 적용됩니다.

스테이지는 의뢰를 해결하며 진행합니다. 제1장의 필수 성소와 파수꾼을 정화하면 여정 또는 결과 화면의 **제2장 의뢰 받기**로 이동합니다. 네 방향 출구는 사용하지 않습니다. 제2장은 두 분기 모두 공통 사막 유적입니다. 미리 분기를 고르지 않고 첫 의뢰를 준 NPC에 따라 다음 시대가 정해집니다. 기록관은 제3-1장 고대 왕국, 통신관은 제3-2장 사이버펑크로 이어지며 수락 즉시 이동하지 않습니다. 제2장의 과거·미래 의뢰는 각각 시작 의뢰 1개와 후속 3개로, 총 여덟 정의 중 첫 의뢰인에게 받은 줄기의 네 개를 순서대로 수락합니다. 다른 의뢰인의 시간축은 잠깁니다. 이미 받은 의뢰가 있는 저장은 같은 줄기를 유지합니다. 각 의뢰의 처치 목표를 채우고 고유 성소를 조사한 뒤, 지역 처치 목표와 감시자 토벌까지 완수하면 선택한 제3장으로 갑니다. 새 장에 처음 진입할 때 장비·스킬·골드·물약·레벨을 유지하고, 미수집 전리품도 다음 거점으로 옮깁니다. 지역별 처치 수는 새로 집계하며 의뢰 선택과 진행도 저장합니다. 제3-1장과 제3-2장은 각자의 성소 세 곳과 지역 정화·보스 의뢰를 갖춘 현재 이야기의 끝입니다.

각 시대의 거점에는 전용 상점과 회복 샘이 있고 지도에 표시합니다. 가까운 서비스는 거점 아이콘으로 묶고 확대하면 상점·회복 지점을 따로 보여 줍니다. 고대 유적의 열린 아치는 기둥 사이로 통과할 수 있고, 큰 건물 뒤에 주인공이 가려질 때는 건물을 옅게 표시합니다.

상점은 무기·방어구·부적·물약·축복을 바로 고를 수 있습니다. 5레벨부터 룬검·쌍날 도끼·수정 홀 같은 상급 장비가 추가됩니다. 축복 수련은 3레벨마다 한도가 늘고 반복할수록 비용이 증가합니다. 첫 숲 보스는 희귀 무기와 고유 기념 장비인 파수꾼의 심장을 함께 남깁니다.

검의 연속 공격은 베기·역베기·양손 내려치기 자세로 이어지며, 잠시 쉬면 첫 공격부터 시작합니다. 마법사는 준비·발사 자세를 취하고 짧은 공통 시전 간격과 기술별 재사용 대기시간을 가집니다. 기본 마법탄은 손을 뻗는 순간 발사됩니다. 연속 기본 공격 도중 누른 마법은 현재 시전이 끝나면 한 번 실행하며, 구르기·일시정지·스킬 교체로 취소할 수 있습니다. 지역마다 적 무리는 세 차례 출현하며, 남은 적을 모두 처치한 뒤 나타난 비석을 세 번 공격하면 그 지역의 출현이 다시 시작됩니다. 재소환 표식은 숲·사막·고대·미래마다 다른 문양으로 떠 있으며, 남은 적이 없으면 밝아집니다. 이 빛의 표식은 이동을 막지 않습니다. 적의 남은 체력과 지역별 출현 횟수는 이어하기에도 유지됩니다. 큰 지도는 처음에 전체 영역을 맞춰 보여주고 내 위치·의뢰 버튼으로 해당 지점을 확대합니다.

필수 의뢰 지점은 각 지도의 서부·북동부·남부에 분산되어 있습니다. 새 성소 접근로는 호수를 돌아가며 도보와 탈것으로 이동할 수 있습니다. 숲과 초원에는 멧돼지·늑대, 사막에는 바실리스크·전갈, 유적에는 미라·망령, 미래 도시에는 경비병·정찰 드론이 등장합니다. 일반 적 경험치는 8, 정예는 18, 보스는 80이며 이미 얻은 레벨은 유지합니다. 체력 물약은 36마리, 마나 물약은 48마리 처치 간격으로 지급하고 상자 물약은 네 상자마다 하나씩 얻습니다. 전사의 맹렬한 돌진은 6레벨, 집중 강타는 7레벨에 앞선 전투 기술을 배운 뒤 습득할 수 있습니다. 돌진은 장애물에서 멈추고, 집중 강타는 버튼을 길게 눌렀다 놓아 힘을 모으며 취소하면 자원을 쓰지 않습니다.

플레이어의 기본 공격과 공격 스킬 피해는 이전 대비 25% 낮췄습니다. 장비·스킬 미리보기에도 같은 감소율이 적용되며, 저장한 장비와 투자 포인트는 유지합니다. 공격 속도·재사용·대상 수·연출 성장은 유지합니다.

분수와 각 시대의 회복 거점에는 안전 구역 경계가 있습니다. 숲의 낮은 나무 울타리, 사막의 옅은 돌과 밧줄, 고대 왕국의 돌 경계, 미래 도시의 푸른 에너지 울타리로 구분합니다. 출입구로 오갈 수 있으며 적은 안으로 들어오지 못합니다. 안전 구역 안에서는 밖의 적에게도 피해·기절·둔화를 줄 수 없고, 적의 공격과 투사체도 경계를 넘지 못합니다. 전투 기술을 눌러도 자원과 쿨다운을 쓰지 않으며 회피·탑승·상점·의뢰는 이용할 수 있습니다. 미니맵 아래의 안전 구역 표시와 공격 버튼의 방패로 확인하세요.

닫힌 상자는 길을 막는 오브젝트입니다. 가까이서 공격하면 나무 파편과 함께 깨지며 전리품이 나오고, 파괴한 상자는 다시 보상을 주지 않습니다. 마을 안전 구역에서도 기본 공격으로 상자를 부술 수 있습니다. 운석과 폭발의 불꽃·파편은 그림 프레임 사이에도 연속적으로 움직이고, 화면 밖 연출은 전투 판정을 유지하면서 그리기를 생략합니다.

우물이나 거점 분수를 발견하면 옆에 움직이는 포탈이 활성화됩니다. 포탈 또는 근처의 **워프**를 눌러 현재 스테이지와 방문했던 스테이지의 발견한 우물로 이동합니다. 체력·자원·재사용 대기시간을 유지하며, 지역별 의뢰·상자·적과 보스의 남은 체력·출현 횟수도 보존합니다. 탈것에서는 먼저 내려야 합니다. 우물 옆의 의뢰 안내와 타기 버튼은 함께 사용할 수 있고 상자는 가까이서 공격해 부숩니다.

새로 진입하는 사막 거점은 지도 왼쪽 중앙, 고대 왕국은 중앙, 미래 도시는 오른쪽 위에서 시작합니다. 처음 숲의 분수 마을과 기존 저장의 거점 위치는 유지합니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행하고 `http://127.0.0.1:8765`에 접속합니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

실행에는 npm 설치나 별도 빌드가 필요하지 않습니다.
`index.html`, `src/`, `assets/`, `style.css`, `playful-pixels.mp3`가 함께 필요하며 HTTP(S)로 접속해야 합니다.
게임을 다시 시작하려면 페이지를 새로고침합니다.

모바일에서는 진입 시점의 화면 높이를 유지합니다. 회전 후 높이를 맞추려면 새로고침하세요.
터치 기기에는 화면 조이스틱과 조작 버튼이 자동으로 표시됩니다.
공격은 무기마다 다른 찌르기·베기·충격파·마법 효과로 구분합니다. 공격·피격은 효과와 피해 숫자로 표시하고, 아이템·골드 획득과 중요한 안내는 캐릭터 위에 잠깐 뜨는 말풍선으로 표시합니다.
시작 마을은 대표 이미지의 분수·상점·집을 유지합니다. 바깥은 반복되는 방 대신 넓은 초원·깊은 숲·큰 호수·굽은 강과 다리·해안으로 이어지며, 사막은 넓은 사구·자갈 평원·오아시스로 구분됩니다. 지형 윤곽과 수목 배치는 시드마다 달라집니다. 숲·사막 각각 가로 7,680 × 세로 5,760이며 시작 마을은 중앙에 있습니다. 작은 격자는 내부 충돌·길찾기에만 사용합니다. 생성한 바닥 재질과 실제 나무·바위·다리 그림을 공통 지형 데이터로 구성해 보이는 주요 길을 이동할 수 있습니다. 롱소드·수리검을 가지고 시작하며, 전투길과 바깥 지역에서 주변 적 무리가 10초 간격으로 합류합니다. 560px 이상 탐험하면 새 지역에서 즉시 보충을 시도하며 주변 620px 안의 적은 최대 9마리입니다. 멀리 남은 일반 적은 정리하고 보스는 유지합니다. 시작 마을 분수 주변은 안전 구역입니다. 몬스터 종류·레벨은 시작점으로부터의 거리에 따라 달라집니다. 나무와 캐릭터는 발밑 순서로 표시하며 주인공을 가리는 수관은 반투명해집니다. 일반 적 이름·체력바는 교전 중에, 보스는 항상 표시합니다.
모바일 HUD·조작 안내는 12~14px, 팝업 본문은 14~16px로 표시하며 긴 목록은 스크롤해 읽을 수 있습니다.

| I / Esc        | 열린 패널 닫기, 패널이 없으면 인벤토리 열기         |
| 방향키 / Enter | 인벤토리 선택 이동 / 무기 장착                      |
| Delete         | 인벤토리에서 선택한 무기 버리기                     |
| 1 / 2 / 3      | 소비 아이템 사용                                    |
| U              | 탈것에서 내리기                                     |
| C              | 도감 열기·닫기                                      |
| L              | 퀘스트 일지 열기·닫기                               |
| P              | 모험 설정 열기·닫기                                 |

무기 장착은 인벤토리 슬롯 클릭으로도 가능합니다. 슬롯의 버리기 버튼으로 무기를 내려놓을 수 있으며,
남은 사용 횟수도 슬롯에 표시됩니다. 탈것은 가까이 가서 직접 터치하거나 ‘타기’ 버튼을 눌러 탑승합니다. 키보드에서는 E로 탑승합니다.
인벤토리·대화·상점·외관·도감·슬롯머신이 열리면 게임 시간이 멈춥니다.
슬롯머신은 결과 연출이 끝날 때 자동으로 닫히며 중간에 다른 패널을 열 수 없습니다.

일반 지상 몬스터와 지상 보스는 나무·바위·벽·물을 통과하지 못합니다. 비행 몬스터와 위상 이동 능력이 있는 마왕만 지형을 통과합니다. 도보 이동 속도는 초당 245px입니다.

모바일 조이스틱은 연속 360도 각도와 기울기에 따른 이동 속도를 지원합니다. 주인공은 16방향별 두 걸음과 검 휘두르기 자세를, 적·주민·탈것은 기본 8방향별 두 동작 그림을 사용합니다. 왼쪽 조이스틱을 드래그해 이동하고 오른쪽 공격 버튼을 누르고 있으면 연속 공격합니다.
이동과 공격은 두 손가락으로 동시에 할 수 있습니다. 이동 중에는 이동 각도로 공격하고, 멈춘 상태에서 터치 공격을 유지하면 가까운 적을 향해 조준합니다. 검·투사체·수리검·벼락도 같은 연속 각도를 사용합니다. 조작 영역에서는 연속 탭·두 손가락 제스처로 화면이 확대되지 않습니다. 오른쪽의 보조·교체·상호작용 버튼으로 보조무기와 NPC·포탈을 조작하고,
상점·NPC·포탈·탈것은 몸체 가장자리에서 40px 미만까지 다가가, 화면의 대상을 직접 터치하거나 떠오르는 열기 버튼을 누릅니다.
상호작용 버튼은 가까운 대상에 맞춰 상점·대화·이동 등으로 바뀌고, 대상이 없으면 비활성화됩니다. 머리 위에는 작은 반투명 안내만 표시하고, 우하단 버튼을 주 조작으로 사용합니다.
공격 버튼은 검 문양 하나와 원형 공격 대기시간을, 보조 버튼은 선택한 보조무기의 남은 횟수·재사용 대기시간을 표시합니다.
장착 무기는 가방에서 확인합니다. 숫자 아이템 슬롯을 누르면 해당 소비 아이템을 사용합니다. 하단 메뉴에서 가방·도감·일지·설정을 열 수 있습니다.
주요 퀘스트 완료 수와 진행 중인 퀘스트는 일지에서 함께 확인합니다. 상단은 초상 옆 체력·단계 배지·골드·시간과 상태 효과를 표시합니다. 하단 메뉴는 대표 이미지의 청록·황동 그림 버튼을 사용하며 데스크톱에서도 누를 수 있습니다. 빈 소비 아이템 바는 숨기고 아이템을 얻으면 표시합니다.
배는 충분히 넓고 연결된 물과 탑승 가능한 물가가 있을 때만 나타납니다. 말·자전거·오토바이·배는 이동 방향에 맞는 여덟 방향 그림을 사용하고, 내린 뒤에도 마지막 방향을 유지합니다. 탈것을 타면 조작부 위에 내리기 버튼이 표시됩니다. 설정에서 전체화면을 켜고 끌 수 있습니다.
팝업은 생성한 시안의 황동 프레임·청록 카드·양피지 일지로 표시하며, 전체화면 전환이나 주소창 변화 후에도 현재 보이는 화면에 맞춰집니다. 상점 잔액은 상단에 고정됩니다. 제목·닫기 버튼과 하단의
모험 계속하기·다시 도전 버튼은 고정되며, 긴 목록과 설정 본문만 스크롤합니다.
모바일 세로 화면의 팝업은 하단에서 열리며, 가방에는 장착 중인 무기와 보관 칸 수가 표시됩니다.
도감 항목을 누르면 목록 아래의 고정 영역에 상세정보가 표시됩니다. 팝업 버튼은 Tab으로 선택하고 Space·Enter로 실행할 수도 있습니다.

모험 설정에서 타격 진동·배경음악·효과음을 각각 켜고 끌 수 있습니다. 설정을 열면 게임 시간이 멈추며,
선택한 설정은 같은 브라우저에 저장됩니다. 진동과 전체화면은 브라우저·기기에서 지원할 때 동작하고,
지원하지 않는 기능은 설정 화면에서 안내합니다.

무기·몬스터는 D&D SRD 5.1의 이름과 수치를 참고해 실시간 전투용으로 조정했습니다.
대표 화면을 기준으로 생성한 모험가·주민·분수·상점·숲과 사막 소품·주요 몬스터·탈것 그림을 UI와 월드에 사용합니다. [월드 아트 기준](docs/art-direction.md)에서 대표 이미지와 시트 규격을 볼 수 있습니다. 자세한 기준과 저작자 표시는 [콘텐츠·아트 출처](docs/content-reference.md)에 있습니다.

## 게임 진행

- Stage는 누적 처치 수로 계산합니다. 별도의 경험치 레벨업 시스템은 없습니다.
- 처치·보스 퀘스트는 수락 전의 누적 기록도 반영합니다. 골드 목표는 현재 보유 금액을 사용합니다.
- 숲 주요 퀘스트 3개 완료는 숲 완료 안내이며, 게임을 종료하지 않습니다.
- 숲에서 보스 처치 후 1,000골드를 보유하면 중앙 포탈이 생성됩니다.
  `보스 토벌`과 `황금 제국` 퀘스트를 완료하면 사막 여행자도 등장합니다.
- 사막 이동은 편도입니다. 이동 전 달성된 퀘스트는 보상을 받고,
  미완료 숲 전용 퀘스트는 포기해 슬롯을 비웁니다. 지역 공통 퀘스트·완료 기록·보유 장비는 유지합니다.
- 사막에서 `황금 제국`과 `파라오 토벌`을 완료하면 최종 승리합니다.
- 분수 주변에서는 1초마다 최대 3 HP를 회복하고 같은 양의 골드를 소비합니다.
- 이미 보유한 무제한 무기의 드롭은 가치의 20% 골드로 자동 전환됩니다(단검 10골드). 획득 알림에는 전환된 골드만 표시합니다. 사용 횟수가 있는 무기와 직접 버린 무기는 전환하지 않습니다.
- 인벤토리가 가득 찼을 때 새 종류·횟수 제한 무기의 드롭은 발밑에 남습니다. 지상 무기는 120초 뒤 사라집니다.
- 버린 무기도 120초간 바닥에 남고, 게임 시간 1초 동안 다시 줍지 않습니다. 무기를 버려 새 장비를 받을 공간을 만들 수 있습니다.
- 발목 덫은 8초간 대기하며 적 하나에게 피해 18과 1초 속박을 적용하고 사라집니다.
  폭탄은 피해 30을 한 번 주고, 화염병은 즉시 피해 25와 지속 피해를 합쳐 최대 55를 줍니다.
- 독의 단검은 내려찍기 피해에 더해 4초간 초당 독 피해 4를 줍니다. 장판·독의 지속 피해는 피격 경직을 갱신하지 않습니다.
- 최종 승리 등급은 클리어 시간에 따라 5분 이내 S, 7분 이내 A, 9분 이내 B, 그 이후 C입니다.
  실패 등급은 처치·보유 골드·피해량 점수로 계산하며 결과 화면의 골드는 현재 잔액입니다.
- 슬롯머신은 50골드를 소비합니다. 전설의 검 당첨 시 인벤토리가 가득 차면 100골드로 대체합니다.

## 아직 지원하지 않는 기능과 검증 범위

- **세이브·불러오기**: 모험 진행은 메모리에만 있습니다. 새로고침하면 장비·퀘스트·도감 기록도 초기화됩니다. 소리·진동 설정은 유지됩니다.
- **입력·접근성**: 게임패드, Canvas 내용의 스크린리더 설명은 없습니다.
- **추가 설정**: 키 재설정·음량 조절·난이도 설정은 없습니다.
- **멀티플레이·백엔드**: 계정, 서버 저장, 온라인 순위, 협동 플레이는 없습니다.
- **전체 플레이 검증**: 자동 회귀 검사는 있으나 모든 시드·아이템 조합의 밸런스,
  모든 브라우저의 화면·사운드와 실제 플레이를 통한 최종 클리어는 검증하지 않았습니다.
