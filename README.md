# 자연의 수호자

핵앤슬래시 모험 게임을 두 버전으로 제공합니다. 새 버전은 Flutter·Bonfire 4로 다시 만든 독립 게임이며, 기존 JavaScript 게임은 그대로 보존합니다. 두 버전 모두 키보드와 모바일 터치로 플레이합니다.

- **[새로운 모험 · Flutter / Bonfire](https://obmaz.github.io/sjrpg/new/)**: 전사·마법사를 고르고 제1장 ‘십자로의 숲’을 탐험합니다. 직업별 기본 공격·분노/마나·전사 원본 트리 30종과 별도 기술·마법사 원본 트리 30종, 경험치 레벨·스킬 포인트, 장비 34종과 희귀도·옵션·장착·판매, 물약·보물 상자·상점·지역별 보스를 갖췄습니다. 제1장 의뢰를 해결하면 완료 화면 아래에 고정된 **제2장 의뢰 받기**로 사막 유적에 진입합니다. 계속 탐험을 선택해 남은 전리품을 찾을 수도 있습니다. 클리어한 저장을 이어서 열어도 여정 하단의 고정된 다음 의뢰 버튼으로 진행할 수 있습니다. 제2장에서는 야영지 서쪽 기록관이나 동쪽 통신관에게 첫 의뢰를 받습니다. 의뢰인에 따라 고대 왕국 제3-1장 또는 사이버펑크 제3-2장으로 이어지는 네 의뢰가 정해집니다. 제3-1장 고대 왕국은 제4-1장 잊힌 왕릉으로, 제3-2장 네온 도시는 제4-2장 폭풍의 외곽으로 이어집니다. 두 줄기는 제5장 시간의 정원에서 만납니다. 제4·5장은 거점의 의뢰인에게 직접 의뢰를 수락한 뒤 성소 세 곳과 지역 보스를 해결합니다. 제5장은 같은 지도·목표를 사용하며, 과거 줄기는 왕국의 기록관의 ‘뿌리에 남은 약속’, 미래 줄기는 저항군 기술자의 ‘내일을 잇는 정원’으로 의뢰인·이야기가 달라집니다. 각 지역은 같은 크기의 독립 지도입니다. 새 장으로 이동하면 해당 시대의 의뢰 일지를 먼저 보여주며, 읽는 동안 전투는 멈춥니다. 일반 이어하기는 바로 플레이를 재개합니다. 일지는 의뢰인 위치를 안내하고 첫 의뢰는 해당 NPC와 대화해 수락합니다. 후속 의뢰는 같은 줄기의 일지에서 이어 받을 수 있습니다.
- **[기존 모험 · Legacy](https://obmaz.github.io/sjrpg/legacy/)**: 이전 장비·퀘스트·사막 원정·탈것을 유지하는 Canvas 2D·JavaScript 게임입니다.

새 모험의 체력 막대는 받은 피해를 잔상으로 보여 줍니다. 체력이 30% 이하면 붉은 테두리로, 10% 미만이거나 중독 상태이면 게이지와 화면의 붉은 맥박으로 위험을 알립니다. 실제 체력이 줄 때도 짧은 붉은 신호가 나타나며, 기기의 동작 줄이기 설정에서는 위험 신호가 고정됩니다.

광역 기술은 포인트를 한 등급 더 투자할 때마다 대상이 한 명 늘어납니다. 지역 무리 규모는 기존의 약 1.5배이며 몬스터와 의뢰에서 얻는 실제 경험치는 이전 지급량의 2배입니다. 사망 후 다시 일어나면 생명과 분노·마나가 모두 회복되고, 3초 동안 피해와 상태 이상을 받지 않습니다. 일반 이어하기는 이 회복을 제공하지 않습니다. 사망 시 보유 무기 하나가 무작위로 파괴되고 골드를 무작위로 최대 30% 잃습니다. 손실은 사망 시 한 번 확정해 저장하며, 손실 기록을 저장해야 거점에서 재도전할 수 있습니다. 마지막 무기를 잃어도 기본 공격은 유지됩니다.

근접 무기는 이도류·레이피어·카타나·할버드·전쟁 망치·도리깨·글레이브·팔시온을 더해 16종입니다. 종류마다 기본 공격의 궤적·충격 문양을 구분하며 상점과 전리품으로 얻습니다. 기존 장비 그림과 저장은 유지하고 새 무기는 별도 아이콘을 사용합니다.

기본 진행 속도는 1.2배입니다. 이동·공격·적 행동·투사체·쿨타임이 함께 빨라지고, 초당 피해와 대기시간 표시는 실제 시간을 기준으로 계산합니다. 부활 보호는 실제 3초를 유지합니다.

화면은 절제된 금속 프레임과 그림 아이콘, 어두운 청록 버튼으로 구성합니다. 회피는 구르는 투구 전사, 달리기는 갑옷 부츠, 무기 없는 전사의 공격은 갑옷 주먹의 생성형 그림을 같은 원형 스킬 프레임에 표시합니다. 강타는 장착 무기 공격력·숙련도에 비례하는 단일 대상 타격이며, 좁은 무기 궤적과 실제 적중한 적의 짧은 충격 섬광으로 표시합니다. 기술은 넓은 발광·겹치는 고리 대신 칼 궤적·탄환·짧은 적중 파편으로 구분합니다. 소품과 캐릭터 발밑의 얕은 그림자, 건물 뒤에서의 가림 처리가 2.5D 깊이감을 더합니다. 월드 좌표와 충돌은 기존 2D 엔진을 유지합니다.

일곱 스테이지의 필드는 전체 지도 생성형 디자인을 먼저 만들고, 그 구도에서 얻은 넓은 토질·색상 권역과 고해상도 풀·모래·석재·산업 바닥으로 구현합니다. 마을과 우물의 기존 장면은 유지하며, 길과 물은 실제 지형 판정과 같은 경로로 그립니다. 확대지도도 같은 권역 구성을 보여 줍니다. 전체 그림을 거대하게 확대하거나 작은 장면을 반복해서 붙이지 않고, 연결된 지형 위에서 탐험하고 싸우도록 구성합니다.

사막과 다른 지도 안의 모래 지형에서도 길은 모래에 묻힌 옅은 흔적으로 표시합니다. 사막 의뢰터의 포장은 연속된 바닥 띠 대신 반쯤 묻힌 작은 석재 조각으로 남습니다. 두 의뢰 지역 주변에는 부러진 신전 기둥·석주·쓰러진 기둥·무너진 벽이 남아 있으며, 필드에도 같은 시대의 유적이 드문드문 나타납니다. 기둥과 벽의 실제 받침은 이동을 막고 중앙과 의뢰 접근로는 열려 있습니다.

새 모험은 전사·마법사 모두 스킬 포인트 2개로 시작합니다. 기존 저장의 남은 포인트는 유지하며 이어하기로 중복 지급하지 않습니다.

일반 공격은 타이밍 입력 없이 누르거나 길게 눌러 이어서 공격합니다. 마법사의 기본 공격은 화염탄·번개 줄기·얼음살 중 배운 마법을 선택하며, 큰 공격 버튼도 선택한 마법 그림으로 표시하며 같은 마법의 보조 버튼은 중복 표시하지 않습니다. 마나가 부족하면 마법을 사용하지 않고 회복을 기다립니다. 전사의 새 사용 기술 **분신 연격**은 첫 적을 타격한 뒤 기술 버튼을 타이밍에 맞춰 다시 누르면 다음 적으로 순간이동하며 공격합니다. 스킬 등급만큼 서로 다른 적에게 이어지고, 뒤의 타격일수록 강해지며 주변 적에게는 작은 분산 피해를 줍니다. 실패하거나 시간이 지나면 종료됩니다. 타이밍 게이지는 이 기술을 사용하는 동안에만 표시하며, 일반 공격에는 표시하지 않습니다.

## 새 버전 개발

Flutter **3.47.8**과 Node.js 24 이상이 필요합니다. 공유 그림은 기존 원본을 유지하며 준비 스크립트로 복사합니다.

```sh
npm ci
npm run prepare:new
cd flutter_game
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run -d chrome
```

두 버전의 빌드는 분리되어 있습니다. Flutter는 WASM으로 빌드하며, Legacy는 동일한 배포본 또는 검증된 캐시를 재사용합니다. 마지막 조립 단계에서 두 경로를 같은 GitHub Pages 배포 파일에 넣습니다.

```sh
cd flutter_game
flutter build web --wasm --release --base-href /sjrpg/new/ --no-web-resources-cdn
cd ..
npm run check
npm run prepare:legacy
npm run build
```

`npm run build`는 준비된 두 산출물을 복사하는 조립 명령입니다. Legacy 소스가 바뀌었거나 기존 배포본을 복원할 수 없을 때만 `prepare:legacy`가 Legacy를 빌드합니다. Legacy만 직접 빌드하려면 `npm run build:legacy`, Flutter만 빌드하려면 `npm run build:new`를 사용합니다. CI는 두 버전의 입력을 각각 캐시하고 독립 작업으로 준비합니다.

새 지도의 가로·세로는 이전의 75%인 34,560×25,920입니다. 이전 저장의 캐릭터·탈것·적·보물 위치도 같은 비율로 옮기며 레벨·장비·의뢰 진행은 유지합니다. 현자·성소·의뢰 지점에 가까이 가면 작은 의뢰·대화·정화 버튼이 나타납니다. 내용은 버튼을 눌러 확인하며 자동으로 긴 안내를 펼치지 않습니다. 성소 주변의 적을 정리한 뒤 정화 버튼을 누르세요. 사막 의뢰의 처치는 수락한 뒤부터 집계됩니다.

탈것은 무료 배치되지 않습니다. 거점의 **탈것 상인**에게 말 90·자전거 110·오토바이 420·배 180골드로 구매하고, 호출한 뒤 직접 탑승합니다. 기존 무료 배치는 구매 대상으로 전환됩니다. 내구도와 구입 기록은 스테이지를 넘어 유지되며 상인에게 보수할 수 있습니다. 물 위의 고장 난 배는 느린 노 젓기로 물가에 도달할 수 있습니다.

결과는 `dist/index.html`(선택 화면), `dist/legacy/`(기존 게임), `dist/new/`(Flutter 게임)입니다. 새 버전은 자산·엔진을 같은 서버에 포함하고 버전별 경로에 보관합니다. 두 게임의 진행은 별개입니다. 새 버전은 이 브라우저에 5초마다 체크포인트를 저장하고 시작 화면의 **모험 이어하기**로 돌아옵니다. 이어하기 버튼은 항상 표시하며, 저장이 있으면 단계·직업·레벨과 함께 활성화됩니다. 저장이 없거나 읽을 수 없는 경우에는 버튼 아래에 상태를 안내하고 기존 저장을 임의로 지우지 않습니다. 레벨·장비·스킬·골드·상자·이야기·미수집 전리품·보스 체력을 유지합니다. 주변 일반 적의 남은 체력과 지역별 출현 횟수도 유지합니다. 다음 스테이지 이동은 저장에 성공한 뒤 진행하며, 실패하면 현재 의뢰 화면에서 다시 시도할 수 있습니다. 새 모험은 이전 저장을 덮어쓰고, 기존 Legacy는 새로고침하면 초기화됩니다. 새 버전의 키보드 조작은 WASD/방향키 이동, Space/J 연속 공격, N/K·L·O·P 사용 스킬 1~4, 왼쪽 Shift 회피, 1/2 생명·자원 물약입니다. 모바일에서는 조이스틱·공격·스킬·회피·물약을 동시에 사용할 수 있습니다. 분노·마나가 부족한 스킬은 그림을 어둡게 표시하며, 물약이나 회복으로 자원이 채워지면 다시 밝아집니다. 상점·대화·성소·탈것은 조이스틱 위에 주변 행동 버튼으로 표시됩니다. 우물의 의뢰 안내와 타기·워프는 함께 사용할 수 있고, 상자는 공격해 부숩니다. 가까운 주민이 여럿이면 더 가까운 쪽과 대화합니다. 유성·대지 강타는 짧게 누르면 자동 조준하고, 누른 채 끌면 표시된 범위를 향해 손을 놓을 때 시전합니다. 버튼에서 멀리 끌어 붉은 취소 표시가 나오면 자원을 쓰지 않고 취소합니다.

모험 시작·이어하기와 지역 이동을 준비하는 동안 잠시 기다릴 수 있습니다. 새 지역 준비에 실패하면 지금 모험과 저장을 유지하며, 같은 이동 버튼으로 다시 시도할 수 있습니다. 오류가 반복되면 안내의 **새로 열기**로 저장한 모험을 다시 불러오세요.

지역 보스는 숲의 파수꾼·사막의 황금 수호자·고대 왕국의 석상왕·미래의 방어 코어로 외형을 구분합니다. 사막 수호자·석상왕·미래 방어 코어도 여덟 방향·두 보행 자세로 움직입니다. 보스 이름은 어두운 판 위에 표시해 밝은 바닥에서도 읽기 쉽습니다. 피격 때 주인공은 짧게 밝아지며, 잠깐의 피해 보호는 발밑 빛으로 표시해 전투 중에도 몸체가 선명하게 보입니다. 전투 HUD는 체력·분노/마나·물약과 미니맵에 집중하며 골드와 모험 경과 시간은 표시하지 않습니다. 골드는 가방·상점에서, 처치 수는 여정과 결과 화면에서 확인합니다. 미니맵은 월드 가장자리에서도 주인공을 중앙에 고정합니다. 출현한 보스는 붉은 표식으로 표시하며 멀리 있으면 미니맵 가장자리에 방향을 보여 줍니다. 큰 지도에서는 보스의 실제 위치와 이름을 확인할 수 있습니다. 미니맵을 누르면 큰 지도가 열리며 두 손가락 확대·드래그·내 위치/전체 지도 버튼을 사용할 수 있습니다. 설정의 **앱 설치**는 지원 브라우저의 설치 창을 열고, 다른 브라우저에서는 홈 화면 추가 방법을 안내합니다. 설치한 앱도 인터넷 연결이 필요합니다.

뿌리 우물은 세밀한 포장·뿌리·낙엽과 구불길을 함께 설계한 전용 생성형 정원으로 구성합니다. 나머지 필수 의뢰 25곳도 초승달 습지·매몰 회랑·해시계·회로 광장 등 서로 다른 지면 배치와 질감을 사용합니다. 길·수면·이동 판정은 실제 지형을 따릅니다. 숲 마을은 생성형 정원·포장길과 주택을 기존 분수·상점·대장간에 연결하며, 건물의 벽은 이동을 막습니다. 낮은 울타리와 나무로 주변 숲에 이어지며, 출입구와 다리는 열려 있습니다. 공격·회피는 글자 없이 그림 버튼으로 표시하고, 탈것은 이동 거리에 맞춘 연속 동작을 사용합니다. 마을 안에서는 적이 주인공을 인식하지 못하고 필드를 천천히 배회합니다. 숲의 첫 무리는 3마리, 이후 무리는 4~5마리이며 동시에 활동하는 일반 출현 상한은 20마리입니다. 상태창은 금속 초상 프레임과 상단 레벨·직업, 얇은 체력·자원 막대로 구성합니다. 일반 세로·가로 화면에서 사용 스킬 네 개는 공격 버튼 주위에 배치하고 회피·질주는 오른쪽에서 구분합니다. 가로 화면의 가방·설정은 미니맵 옆에 작게 배치하며 스킬·여정은 아래에서 엽니다. 좁고 짧은 화면에서도 44px 터치 영역을 유지합니다.

몬스터는 서로 발 공간을 확보하며 좁은 길에서는 실제 몸체로 줄지어 이동합니다. 앞줄의 적에게 막히면 주변을 돌아 접근하고, 공격 준비 중에는 발을 고정합니다. 추적을 시작할 때 짧게 가속하며 큰 몬스터와 정예·유니크는 더 묵직하게 움직이고 넉백에 덜 밀립니다. 피격 피해는 즉시 적용됩니다.

새 버전의 전사와 마법사는 원본 256px 해상도를 유지한 고해상도 이미지로 표시하며, 기존 128px 출력보다 가로·세로 픽셀 밀도가 2배입니다. 각각 16방향별 8자세로 움직이고, 멈추면 별도의 대기 자세를 사용합니다. 실제 이동 거리에 맞춰 발을 번갈아 딛으며 벽에 막히면 발동작도 멈춥니다. 전사의 세 가지 검 동작과 마법사의 준비·시전도 여덟 자세로 이어지고, 구르기도 같은 캐릭터 모습과 크기를 사용합니다.

일반 이동 속도는 135입니다. 전사는 8레벨부터 달리기를, 마법사는 원본 선행 기술을 익힌 뒤 18레벨부터 순간이동을 배울 수 있습니다. 배우면 회피 옆에 이동 기술 버튼이 생기며 키보드에서는 M으로 사용합니다. 전사는 잠깐 270 속도로 달리고, 마법사는 바라보는 방향의 적을 통과해 멀리 이동합니다. 순간이동은 벽과 적을 넘어가며, 도착할 지형·상자·월드 경계를 검사합니다.

새 버전 설정의 **전체화면 켜기/끄기**로 화면을 전환할 수 있습니다. 세로·가로 전환에 맞춰 플레이 화면이 바뀌며 주소창 변화로 높이가 흔들리지 않습니다. 전체화면에 들어가면 화면 크기에 맞추고, 나가면 현재 방향의 모바일 높이를 복원합니다. **타격 진동**은 적중·피격·스킬마다 다르게 동작하며 설정에서 켜고 끄거나 확인할 수 있습니다. **전투 효과음**은 베기·망치·화염·냉기·번개·함성·피격·전리품을 구분하며, 같은 설정 화면에서 끄거나 확인할 수 있습니다. 소리는 첫 터치나 키 입력 이후 재생하고 일시정지·백그라운드 전환 때 멈춥니다. 설정은 브라우저에 저장됩니다. 진동 설정은 카드 전체를 눌러 바꾸며, 앱 설치 안내의 본문이 길어도 확인 버튼은 아래에 고정됩니다. 전체화면·진동은 지원되는 기기/브라우저에서 사용할 수 있습니다.

지원 브라우저는 Dart WASM과 Skwasm을 사용하며 미지원 브라우저는 JavaScript/CanvasKit 호환 빌드로 실행합니다. GitHub Pages에서는 단일 스레드 Skwasm을 사용합니다. 처음의 버전 선택 화면은 짧은 두 버튼으로 구성해 모바일 세로·가로 화면에서 스크롤 없이 고를 수 있습니다.

새 버전은 생성형 숲 마을 그림과 차분한 석재·청동 UI로 로딩과 직업 선택을 이어 보여 줍니다. 직업 초상 카드와 시작·이어하기 동작을 중심에 둡니다. 갑옷과 검을 든 남성 전사, 천 로브와 마법서를 든 남성 마법사의 그림 카드를 누른 뒤 바로 모험을 시작하며, 저장된 모험의 이어하기는 별도 버튼으로 유지합니다.

전사는 디아블로 2 바바리안의 함성·전투 숙련·전투 기술을 각 10개씩 표시합니다. 기술 이름·선행 관계·1/6/12/18/24/30레벨 단계와 효과를 원본 기준으로 구성하고, 원본 기술은 최대 20등급이며 다음 등급마다 필요한 캐릭터 레벨도 올라갑니다. 세 계열은 탭으로 전환하며 각 계열 안에서만 세로로 스크롤합니다. 별도 기술은 특수 탭에서 배웁니다. 마법사도 디아블로 2 소서리스의 냉기·번개·화염 주문을 각 10개씩, 원본 선행 관계와 6단계 레벨 조건·최대 20등급으로 배웁니다. 분신 연격과 기존 달리기는 원본 트리와 구분합니다. 노드를 고르면 작은 화면에서도 선택 위치를 맞춰 보여 줍니다. 화면 아래에서 바로 습득·강화하고, 정보 버튼에서 설명·현재/다음 등급의 피해와 주요 능력치·네 전투 슬롯 배치를 확인합니다. 수치는 현재 장비와 레벨을 기준으로 계산하며 미리 보기에는 포인트를 쓰지 않습니다. 새 사용 기술은 빈 슬롯에 자동으로 지정되고 배운 기술끼리 바꾸면 자리를 교환합니다. 조준 기술을 두 손가락으로 조작할 때는 마지막으로 시작한 유효한 조준을 유지하며, 다른 기술 버튼을 놓아도 먼저 발동하지 않습니다. 첫 슬롯은 비울 수 없으며, 첫 기술을 빈 슬롯으로 옮기는 버튼은 비활성화하고 이유를 표시합니다. 재사용 대기시간은 배치를 바꿔도 유지됩니다.

기본 공격 간격을 두 배로 늘렸습니다. 시작 무기의 기본 간격은 전사 약 0.83초이며, 마법사의 주문 발사는 원본 시전 프레임과 시전 속도에 따라 달라집니다. 전사의 간격은 기본기 종류·등급·장비에 따라 달라집니다. 한 번의 피해량과 사용 기술의 재사용 대기시간은 유지합니다. 숙련에 따른 피해·속도 증가도 완만해지고 적 공격은 20% 강해집니다. 분노 획득과 마나 회복은 느려지며 레벨업 때 자원을 조금 보충합니다. 물약 두 개 묶음은 치유 80골드, 자원 72골드입니다.

전투 집중은 기본 공격 간격을 줄이고, 전장의 맹세는 등급마다 최대 생명을 8, 함성 보호 중 피해 감소율을 1%p 늘립니다. 기존 전사 기술의 지속 시간은 재사용 대기시간에 맞춰 제한합니다. 마법사의 방어 주문·온기·시전 지연은 소서리스 원본 규칙을 사용합니다. 강화 등급과 재사용 감소도 이 상한에 반영합니다. 고양의 울림은 함성으로 보호받는 동안 **실제 적중**에만 분노를 더 주며 빗맞힌 공격에는 적용되지 않습니다. 온기는 마나 회복을 늘리고, 화염·번개 숙련은 주문 피해를, 냉기 숙련은 냉기 저항 관통을 강화합니다. 이전 21종 마법사 저장은 새 트리로 이전하지 않으므로 새 모험으로 시작합니다. 각 스테이지의 필수 의뢰와 보스를 처음 완료하면 스킬 초기화권을 1장 받습니다. 초기화는 확인 창에서 초기화권 1장으로 무료 기본 공격·시작 기술 1등급을 제외한 투자 포인트를 돌려줍니다. 골드는 사용하지 않으며 같은 스테이지를 다시 방문해도 초기화권을 중복 지급하지 않습니다. 현재 보호·격노·소용돌이 효과는 종료되고 대기시간은 유지됩니다. 초기화한 뒤에는 트리의 선행 기술을 다시 배워야 합니다.

근접 기본 공격은 처음에 1명을 공격하며 연속 베기는 포인트마다 대상이 한 명씩 늘어 최대 5명을 공격합니다. 화염탄·전기 기본 공격도 같은 방식으로 대상이 늘어납니다. 정밀 단일 공격은 한 명을 유지합니다. 광역 기술은 1등급에서 3명으로 시작해 등급마다 한 명씩 늘며, 관련 전문화도 투자한 포인트마다 대상을 한 명씩 더합니다. 전문화가 없는 광역 기술은 최대 7명을 공격합니다. 소용돌이의 세 타격도 한 번 시전한 기술의 대상 상한을 공유합니다. 함께 맞힌 적이 많으면 각 적이 받는 피해가 줄어듭니다. 단일 대상 피해가 100이면 두 명은 각각 80, 세 명은 각각 70입니다. 상한·장애물·안전 구역을 확인한 실제 적 수를 기준으로 하며 상자는 피해 분배 인원에 포함하지 않습니다. 소용돌이는 타격마다, 돌진은 같은 순간 접촉한 적끼리 계산합니다. 이후에 접촉한 적 때문에 앞선 피해를 다시 바꾸지 않습니다. 대상 수는 기술 설명의 등급 비교표에서 확인합니다.

집중 강타를 조준하면 실제 전방 부채꼴 범위를 표시하고, 돌진은 짧은 화살표로 방향을 표시합니다. 길게 누르는 동안 집중 강타의 무기 자세도 조준 방향을 따라갑니다. 적중하면 무기·원소에 맞는 입자가 튀고 잠깐 타격 정지가 적용됩니다. 여러 적을 한 번에 맞혀도 정지 시간이 중첩되지 않습니다.

스킬 창의 ‘기본 공격’ 카드에서 기본기를 고릅니다. 전사는 연속 베기·빠른 속사 베기·무거운 일격을 사용합니다. 마법사는 배운 화염탄·얼음살·번개 줄기를 기본 공격으로 지정하며 주문마다 마나를 사용합니다. 마나가 부족하면 지팡이 근접 타격으로 전환합니다. 네 사용 기술 슬롯은 따로 유지하며, 기본기를 바꿔도 진행 중인 공격 간격과 사용 기술의 대기시간은 유지합니다.

마법사의 피해·마나·시전 지연·시너지·숙련 수치는 [소서리스 원본 데이터와 구현 기준](docs/data/diablo2-sorceress-113.md)을 따릅니다. 불길·화염벽은 지속 피해, 운석은 낙하 후 잔류 불길, 눈보라는 개별 낙하, 얼음 보주는 방사형 파편, 히드라는 세 머리의 화염탄으로 동작합니다. 일부 지연 주문은 원본처럼 시전 지연을 공유합니다. 세 얼음 방어 주문은 서로 교체되며, 마력 보호막·마법부여·뇌우의 남은 시간과 진행 중인 공유 지연은 저장·우물 이동에도 유지됩니다. 사망하면 지속 효과를 해제합니다. 효과와 아이콘은 원본의 형태와 색을 참고해 새로 구현한 것이며 게임 원본 이미지 파일을 사용하지 않습니다.

장비는 무기·방어구·부적 세 부위이며 일반·마법·희귀·고유 등급이 있습니다. 일반 몬스터 29마리마다 장비를 얻습니다. 물약은 첫 숲 상자와 보급 상자에서 치유·자원 물약을 하나씩 얻거나 상점에서 비싸게 구매합니다. 몬스터와 성소는 물약을 주지 않습니다. 상자에는 대체로 장비가 있지만 소량의 골드·보급품만 들어 있거나 적이 매복할 수도 있습니다. 안전 구역에서는 매복이 발생하지 않습니다. 정예·보스는 특수 능력이 붙은 희귀 무기를 보장합니다. 첫 숲 보스는 고유 부적도 줍니다. 가방은 최근 획득한 장비부터 목록에 보여주며 비교 수치와 **장착** 버튼이 바로 보입니다. 분류는 금색 밑줄로 선택을 표시하며, 확대된 글자가 줄바꿈되어도 같은 높이로 맞춰 끝까지 보여 줍니다. 착용 아이콘과 능력치는 함께 모아 목록과 같이 스크롤하고, 신규 탭에서는 이 개요를 생략해 새 전리품을 바로 보여 줍니다. 항목을 누르면 같은 목록 안에서 나머지 옵션·잠금·판매를 펼칩니다. 개요의 공격력은 장비·레벨·숙련을 반영하며, 무기 공격은 해당 장비의 수치입니다. 무기의 초당 피해와 공격 주기는 현재 레벨·숙련·원소 특화·다른 착용 장비까지 반영한 기본 1타 기준입니다. 별도 상세 창을 열고 닫을 필요가 없으며 잠긴 장비도 장착·교체할 수 있습니다. 위쪽 착용 부위를 누르면 그 장비를 목록 맨 앞에서 확인합니다. 새 장비는 가방 배지·신규 탭으로 찾고 확인 상태와 잠금도 저장됩니다. 상점은 가격 버튼 한 번으로 구매·장착하며, 이미 등급·옵션까지 같은 장비를 착용 중이면 빠른 구매 버튼이 비활성화됩니다. 숲은 일반 장비, 사막은 마법 장비, 고대·미래 상점은 더 높은 옵션의 마법 장비를 판매합니다. 제4·5장 상점의 옵션과 가격은 단계에 맞춰 더 높아집니다. 같은 종류의 일반 장비를 이미 가지고 있어도 새 지역의 마법 장비로 바로 바꿀 수 있습니다. 희귀 무기의 특수 능력은 정예·보스에게서 얻습니다. 항목 안의 보관 구매를 선택하면 장착을 바꾸지 않고 가방에 넣습니다. 물약과 축복도 목록에서 바로 구매합니다. 24칸이 가득 차면 장비 구매를 막습니다. 바닥 장비도 가방과 같은 그림으로 표시하며, 마법·희귀·고유 장비에는 은은하게 변하는 빛을 더합니다. 희귀 장비는 노란색입니다. 바닥 전리품은 최대 32개를 최대 150초간 보관합니다. 일반 장비의 같은 종류는 골드로 전환하며 옵션이 있는 장비는 각각 보관합니다.

몬스터는 시작 무리 5마리 이후 간격을 두고 6~8마리씩 합류하며 주변 활성 적은 최대 30마리입니다. 기본 리젠 간격은 10초이고 이동 중에도 최소 8초 간격을 유지합니다. 필수 성소는 **뿌리 우물·달빛 샘·태양 제단**으로, 서로 다른 모습을 보고 찾아가 주변 적을 물리친 뒤 정화를 누릅니다. 각 성소는 40골드를 한 번 줍니다. 성소 3곳 정화와 120마리 처치를 마치면 파수꾼이 등장하며, 토벌 뒤 스테이지를 완료합니다. 필수 성소는 미니맵의 금빛 표시와 여정에서 확인합니다.

말은 달리면서 자신의 기본 공격을 사용할 수 있고 **박차**로 잠시 가속하지만, 적에게 세 번 실제 피격되면 쓰러져 상인에게 회복해야 합니다. 자전거는 작은 차체와 안정성이 장점이며 피격으로 넘어지지 않고 **가속 페달**로 이동 방해를 벗어납니다. 대신 탑승 전투는 할 수 없습니다. 오토바이는 큰 차체·높은 가격·탄약 비용과 사격 반동이 단점이며, 큰 공격 버튼으로 기관포를 발사하고 상인에게 3단계까지 강화·보급합니다. 배는 수면 전용이며 **물살 타기**로 잠시 가속합니다. 탑승 중에는 일반 사용 기술 대신 전용 기술을 표시하며, 우물 워프는 내려서 사용합니다. 지상·수면 이동과 승하차는 전체 몸체와 지형을 검사합니다.

제4-1장 지하 묘역에는 뼈 사냥개가 도약 경로를 예고하고 달려듭니다. 제4-2장 공업 지대의 태엽 거미는 청록 조준선을 충전한 뒤 광탄을 쏩니다. 공통 제5장에서는 수정 갑충이 몸을 낮춰 넓은 전방을 들이받습니다. 세 종류 모두 장애물을 통과하지 않으며 준비 동작을 보고 옆으로 피하거나 기절시켜 끊을 수 있습니다.

독사는 숲·모래땅에서 몸을 낮춰 기어 다니며, 녹색 경로를 예고한 뒤 짧게 달려들어 뭅니다. 옆으로 피하거나 기절시켜 끊을 수 있습니다. 초반 성장 뒤에는 광신도가 지팡이를 충전하고 마지막으로 겨눈 위치에 보라색 투사체를 날립니다. 이동·구르기로 피하거나 기절시켜 끊으세요. 늑대는 직선 경로를 예고한 뒤 마지막으로 겨눈 곳까지 뛰어들며, 나무와 다른 몬스터에 막힙니다. 해골은 부채꼴 범위를 예고하고 방향을 고정해 베므로 옆이나 뒤로 피할 수 있습니다. 두 공격 모두 기절로 끊을 수 있습니다. 사막의 전갈은 녹색 경로를 예고한 뒤 짧게 돌진하고, 고대 왕국의 트롤은 더 긴 준비 후 넓은 범위를 휘두릅니다. 미래에는 부채꼴 베기를 예고하는 검병과 푸른 조준선을 충전하는 사격 경비병이 함께 등장합니다. 사격 경비병은 마지막으로 겨눈 위치에 광탄을 발사합니다. 이 공격들도 옆으로 피하거나 기절로 끊을 수 있으며 장애물을 통과하지 않습니다. 18마리 처치·3레벨 이후에는 일부 무리에 정예 하나가 섞입니다. 금빛 방패 표시는 체력이 높은 철갑형, 보라색 갈매기 표시는 이동이 빠른 신속형입니다. 정예는 미니맵에서도 구분되며 20골드와 특수 능력이 붙은 노란 희귀 무기 하나를 줍니다. 정예도 같은 공격 예고·장애물·기절 규칙을 따릅니다. 운석은 비행 중 불꽃과 충돌·폭발·잔해가 이어지고, 서릿발은 얼음 결정이 자란 뒤 부서집니다. 얼음 갑옷은 결정과 빛이 주위를 돌며, 소용돌이는 캐릭터가 무기를 들고 직접 회전하며 은빛 검 궤적과 흙먼지를 남깁니다. 등급이 높아지면 궤적의 선명도와 소량의 파편으로 차이를 주며, 함성은 시전 위치에서 짧은 압력선으로 퍼집니다. 검 궤적도 시간에 따라 변합니다. 근접 적중 때는 짧은 타격 자세와 적의 섬광·미세한 화면 반응을 주되 이동·공격 간격·쿨다운은 유지합니다. 보스의 큰 공격은 숲의 원형 지면 강타, 사막의 세 지점 분출, 고대 왕국의 넓은 부채꼴 태양 공격, 미래의 교차 광선으로 다릅니다. 사막·고대·미래 보스는 체력이 절반 아래로 내려가면 다음 공격부터 범위·형태를 강화합니다. 바닥의 예고 범위를 벗어나거나 기절로 준비를 끊을 수 있으며 벽 너머에는 피해를 주지 않습니다. 전투를 벗어나 분수 곁에서 쉬면 서서히 회복합니다. 쓰러지면 무기·골드 손실을 저장한 뒤 거점에서 재도전할 수 있습니다.

제1장은 성소 세 곳을 정화하고 몬스터 120마리와 숲의 파수꾼을 토벌합니다. 완료 후 계속 탐험하며 남은 전리품과 31개 상자를 찾을 수 있습니다. 선택 여정 ‘숲의 기억’은 서쪽·북쪽·동쪽 상자의 이야기 3개를 복원하면 스킬 포인트 1개를 줍니다. 기억은 여정에서 펼쳐 읽으며 정화 목표와 별개입니다. 숲의 필수 의뢰를 끝내면 일지에서 제2장 사막 의뢰를 받습니다.

새 모험의 월드는 34,560×25,920입니다. 전사는 빗맞힌 공격으로 분노를 얻지 않으며 실제 적중·피격으로 얻습니다. 첫 정화는 120마리 처치 후 강화된 파수꾼 토벌로 이어집니다. 메뉴는 아이콘과 스킬 포인트 배지로 표시하며 회피는 전용 구르기 그림으로 연출하며 도중에 공격 때문에 방향이 바뀌지 않습니다. 미니맵은 주변 2,100 범위의 길·적·상자를 따라가고, 여정에서는 전체 지도를 봅니다. 외곽에는 태양의 사구·바람꽃 초원과 보물 31개가 있으며, 팝업은 큰 터치 영역의 모바일 패널로 열립니다.

전사 트리는 함성·전투 숙련·전투 기술·특수 탭으로 표시합니다. 각 계열의 원본 기술 10개와 직접 선행을 유지하며, 별도 기술인 분신 연격·질주는 특수 탭에서 배웁니다. 스킬을 누르면 현재·다음 등급의 실제 효과를 보고 투자하거나 네 전투 슬롯에 배치할 수 있습니다. 사막 일지는 진행 중이거나 다음에 수락할 의뢰를 먼저 보여주며, 완료 기록과 잠긴 후속 이야기는 펼쳐 읽을 수 있습니다. 수락 버튼은 설명 위에 배치합니다. 가방·상점·설정·일지·지도는 공통 제목줄과 닫기 버튼을 사용합니다. 각 장의 성소 카드는 실제 월드에 놓인 성소·중계기 그림과 위치, 완료 표시를 보여줍니다. 확대 지도 아래의 필수 의뢰 버튼을 누르면 해당 지점으로 초점을 옮깁니다. 확대·축소해도 위치 표식은 읽을 수 있는 크기를 유지합니다. 큰 지도는 실제 지형과 같은 재질을 쓰며, 월드 경계 밖은 지형으로 표시하지 않습니다. 생성형 UI 그림은 시작할 때 함께 준비해 처음 팝업을 열 때도 바로 표시합니다.

전사 별도 기술은 기존 등급 성장 규칙을 유지합니다. 마법사는 원본 20등급 성장 규칙을 사용합니다. 전사 원본 기술은 서로 다른 비용·범위·지속시간을 사용하며 이중 타격은 숙련하면 자원 소모가 사라집니다. 포효는 일반 적을 도망가게 하고 도발은 원거리 적도 근접하도록 유도합니다. 물약·아이템 발견과 섬뜩한 수호물은 실제 처치한 시체를 한 번만 소비합니다. 전투 지시는 생명·자원 상한을, 전투 명령은 이미 배운 기술의 효과 등급을 잠시 올립니다. 소용돌이·이중 타격·광분·광폭화는 무기를 직접 사용하는 동작으로 구분하고 도약에는 체공·착지 연출을 둡니다.

앱을 잠시 벗어나도 열어 둔 가방·설정 화면은 유지하며 전투는 멈춥니다. 저장 공간 부족이나 브라우저 설정으로 자동 저장에 실패하면 안내를 띄우고 설정에 현재 저장 상태를 표시합니다. 저장이 복구되면 다음 자동 저장에서 다시 안내합니다.

아래 안내는 **기존 버전**의 전체 기능과 로컬 실행 방법입니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행하고 `http://127.0.0.1:8765`에 접속합니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

실행에는 npm 설치나 별도 빌드가 필요하지 않습니다.
`index.html`, `src/`, `assets/`, `style.css`, `playful-pixels.mp3`가 함께 필요하며 HTTP(S)로 접속해야 합니다.
게임을 다시 시작하려면 페이지를 새로고침합니다.

모바일에서는 진입 시점의 화면 높이를 유지합니다. 회전 후 높이를 맞추려면 새로고침하세요.
터치 기기에는 화면 조이스틱과 조작 버튼이 자동으로 표시됩니다.
공격은 무기마다 다른 찌르기·베기·충격파·마법 효과로 구분합니다. 공격·피격은 효과와 피해 숫자로 표시하고, 아이템·골드 획득과 중요한 안내는 캐릭터 위에 잠깐 뜨는 말풍선으로 표시합니다.
시작 마을은 대표 이미지의 분수·상점·집을 유지합니다. 바깥은 반복되는 방 대신 넓은 초원·깊은 숲·큰 호수·굽은 강과 다리·해안으로 이어지며, 사막은 넓은 사구·자갈 평원·오아시스로 구분됩니다. 지형 윤곽과 수목 배치는 시드마다 달라집니다. 숲·사막 각각 가로 7,680 × 세로 5,760이며 시작 마을은 중앙에 있습니다. 작은 격자는 내부 충돌·길찾기에만 사용합니다. 생성한 바닥 재질과 실제 나무·바위·다리 그림을 공통 지형 데이터로 구성해 보이는 주요 길을 이동할 수 있습니다. 롱소드·수리검을 가지고 시작하며, 전투길과 바깥 지역에서 주변 적 무리가 10초 간격으로 합류합니다. 560px 이상 탐험하면 새 지역에서 즉시 보충을 시도하며 주변 620px 안의 적은 최대 9마리입니다. 멀리 남은 일반 적은 정리하고 보스는 유지합니다. 시작 마을 분수 주변은 안전 구역입니다. 몬스터 종류·레벨은 시작점으로부터의 거리에 따라 달라집니다. 나무와 캐릭터는 발밑 순서로 표시하며 주인공을 가리는 수관은 반투명해집니다. 일반 적 이름·체력바는 교전 중에, 보스는 항상 표시합니다.
모바일 HUD·조작 안내는 12~14px, 팝업 본문은 14~16px로 표시하며 긴 목록은 스크롤해 읽을 수 있습니다.

| 키             | 동작                                                |
| -------------- | --------------------------------------------------- |
| WASD / 방향키  | 이동                                                |

| N / K          | 선택한 보조무기 사용                                |

| 방향키 / Enter | 인벤토리 선택 이동 / 무기 장착                      |
| Delete         | 인벤토리에서 선택한 무기 버리기                     |
| 1 / 2 / 3      | 소비 아이템 사용                                    |
| U              | 탈것에서 내리기                                     |
| C              | 도감 열기·닫기                                      |
| L              | 퀘스트 일지 열기·닫기                               |
| P              | 모험 설정 열기·닫기                                 |

무기 장착은 인벤토리 슬롯 클릭으로도 가능합니다. 슬롯의 버리기 버튼으로 무기를 내려놓을 수 있으며,
남은 사용 횟수도 슬롯에 표시됩니다. 탈것은 가까이 가서 직접 터치하거나 ‘타기’ 버튼을 눌러 탑승합니다. 키보드에서는 E로 탑승합니다.
인벤토리·대화·상점·외관·도감·슬롯머신이 열리면 게임 시간이 멈춥니다.
슬롯머신은 결과 연출이 끝날 때 자동으로 닫히며 중간에 다른 패널을 열 수 없습니다.

일반 지상 몬스터와 지상 보스는 나무·바위·벽·물을 통과하지 못합니다. 비행 몬스터와 위상 이동 능력이 있는 마왕만 지형을 통과합니다. 도보 이동 속도는 초당 245px입니다.

모바일 조이스틱은 연속 360도 각도와 기울기에 따른 이동 속도를 지원합니다. 주인공은 16방향별 두 걸음과 검 휘두르기 자세를, 적·주민·탈것은 기본 8방향별 두 동작 그림을 사용합니다. 왼쪽 조이스틱을 드래그해 이동하고 오른쪽 공격 버튼을 누르고 있으면 연속 공격합니다.
이동과 공격은 두 손가락으로 동시에 할 수 있습니다. 이동 중에는 이동 각도로 공격하고, 멈춘 상태에서 터치 공격을 유지하면 가까운 적을 향해 조준합니다. 검·투사체·수리검·벼락도 같은 연속 각도를 사용합니다. 조작 영역에서는 연속 탭·두 손가락 제스처로 화면이 확대되지 않습니다. 오른쪽의 보조·교체·상호작용 버튼으로 보조무기와 NPC·포탈을 조작하고,
상점·NPC·포탈·탈것은 몸체 가장자리에서 40px 미만까지 다가가, 화면의 대상을 직접 터치하거나 떠오르는 열기 버튼을 누릅니다.
상호작용 버튼은 가까운 대상에 맞춰 상점·대화·이동 등으로 바뀌고, 대상이 없으면 비활성화됩니다. 머리 위에는 작은 반투명 안내만 표시하고, 우하단 버튼을 주 조작으로 사용합니다.
공격 버튼은 검 문양 하나와 원형 공격 대기시간을, 보조 버튼은 선택한 보조무기의 남은 횟수·재사용 대기시간을 표시합니다.
장착 무기는 가방에서 확인합니다. 숫자 아이템 슬롯을 누르면 해당 소비 아이템을 사용합니다. 하단 메뉴에서 가방·도감·일지·설정을 열 수 있습니다.
주요 퀘스트 완료 수와 진행 중인 퀘스트는 일지에서 함께 확인합니다. 상단은 초상 옆 체력·단계 배지·골드·시간과 상태 효과를 표시합니다. 하단 메뉴는 대표 이미지의 청록·황동 그림 버튼을 사용하며 데스크톱에서도 누를 수 있습니다. 빈 소비 아이템 바는 숨기고 아이템을 얻으면 표시합니다.
배는 충분히 넓고 연결된 물과 탑승 가능한 물가가 있을 때만 나타납니다. 말·자전거·오토바이·배는 이동 방향에 맞는 여덟 방향 그림을 사용하고, 내린 뒤에도 마지막 방향을 유지합니다. 탈것을 타면 조작부 위에 내리기 버튼이 표시됩니다. 설정에서 전체화면을 켜고 끌 수 있습니다.
팝업은 생성한 시안의 황동 프레임·청록 카드·양피지 일지로 표시하며, 전체화면 전환이나 주소창 변화 후에도 현재 보이는 화면에 맞춰집니다. 상점 잔액은 상단에 고정됩니다. 제목·닫기 버튼과 하단의
모험 계속하기·다시 도전 버튼은 고정되며, 긴 목록과 설정 본문만 스크롤합니다.
모바일 세로 화면의 팝업은 하단에서 열리며, 가방에는 장착 중인 무기와 보관 칸 수가 표시됩니다.
도감 항목을 누르면 목록 아래의 고정 영역에 상세정보가 표시됩니다. 팝업 버튼은 Tab으로 선택하고 Space·Enter로 실행할 수도 있습니다.

모험 설정에서 타격 진동·배경음악·효과음을 각각 켜고 끌 수 있습니다. 설정을 열면 게임 시간이 멈추며,
선택한 설정은 같은 브라우저에 저장됩니다. 진동과 전체화면은 브라우저·기기에서 지원할 때 동작하고,
지원하지 않는 기능은 설정 화면에서 안내합니다.

무기·몬스터는 D&D SRD 5.1의 이름과 수치를 참고해 실시간 전투용으로 조정했습니다.
대표 화면을 기준으로 생성한 모험가·주민·분수·상점·숲과 사막 소품·주요 몬스터·탈것 그림을 UI와 월드에 사용합니다. [월드 아트 기준](docs/art-direction.md)에서 대표 이미지와 시트 규격을 볼 수 있습니다. 자세한 기준과 저작자 표시는 [콘텐츠·아트 출처](docs/content-reference.md)에 있습니다.

## 게임 진행

- Stage는 누적 처치 수로 계산합니다. 별도의 경험치 레벨업 시스템은 없습니다.
- 처치·보스 퀘스트는 수락 전의 누적 기록도 반영합니다. 골드 목표는 현재 보유 금액을 사용합니다.
- 숲 주요 퀘스트 3개 완료는 숲 완료 안내이며, 게임을 종료하지 않습니다.
- 숲에서 보스 처치 후 1,000골드를 보유하면 중앙 포탈이 생성됩니다.
  `보스 토벌`과 `황금 제국` 퀘스트를 완료하면 사막 여행자도 등장합니다.
- 사막 이동은 편도입니다. 이동 전 달성된 퀘스트는 보상을 받고,
  미완료 숲 전용 퀘스트는 포기해 슬롯을 비웁니다. 지역 공통 퀘스트·완료 기록·보유 장비는 유지합니다.
- 사막에서 `황금 제국`과 `파라오 토벌`을 완료하면 최종 승리합니다.
- 분수 주변에서는 1초마다 최대 3 HP를 회복하고 같은 양의 골드를 소비합니다.
- 이미 보유한 무제한 무기의 드롭은 가치의 20% 골드로 자동 전환됩니다(단검 10골드). 획득 알림에는 전환된 골드만 표시합니다. 사용 횟수가 있는 무기와 직접 버린 무기는 전환하지 않습니다.
- 인벤토리가 가득 찼을 때 새 종류·횟수 제한 무기의 드롭은 발밑에 남습니다. 지상 무기는 120초 뒤 사라집니다.
- 버린 무기도 120초간 바닥에 남고, 게임 시간 1초 동안 다시 줍지 않습니다. 무기를 버려 새 장비를 받을 공간을 만들 수 있습니다.
- 발목 덫은 8초간 대기하며 적 하나에게 피해 18과 1초 속박을 적용하고 사라집니다.
  폭탄은 피해 30을 한 번 주고, 화염병은 즉시 피해 25와 지속 피해를 합쳐 최대 55를 줍니다.
- 독의 단검은 내려찍기 피해에 더해 4초간 초당 독 피해 4를 줍니다. 장판·독의 지속 피해는 피격 경직을 갱신하지 않습니다.
- 최종 승리 등급은 클리어 시간에 따라 5분 이내 S, 7분 이내 A, 9분 이내 B, 그 이후 C입니다.
  실패 등급은 처치·보유 골드·피해량 점수로 계산하며 결과 화면의 골드는 현재 잔액입니다.
- 슬롯머신은 50골드를 소비합니다. 전설의 검 당첨 시 인벤토리가 가득 차면 100골드로 대체합니다.

## 아직 지원하지 않는 기능과 검증 범위

- **세이브·불러오기**: 모험 진행은 메모리에만 있습니다. 새로고침하면 장비·퀘스트·도감 기록도 초기화됩니다. 소리·진동 설정은 유지됩니다.
- **입력·접근성**: 게임패드, Canvas 내용의 스크린리더 설명은 없습니다.
- **추가 설정**: 키 재설정·음량 조절·난이도 설정은 없습니다.
- **멀티플레이·백엔드**: 계정, 서버 저장, 온라인 순위, 협동 플레이는 없습니다.
- **전체 플레이 검증**: 자동 회귀 검사는 있으나 모든 시드·아이템 조합의 밸런스,
  모든 브라우저의 화면·사운드와 실제 플레이를 통한 최종 클리어는 검증하지 않았습니다.

## 개발 안내

후속 개발 지침은 [AGENTS.md](AGENTS.md), 구조·아키텍처·검증·배포 절차는
[개발 참고](docs/development.md)에 기록합니다.

적은 각 장의 시작 거점에서 멀어질수록, 다음 장으로 갈수록 체력과 공격력이 증가합니다. 생성 때의 강함을 고정하므로 쫓아오는 도중 거리에 따라 갑자기 강해지지 않습니다. 이어하기·우물 이동에서도 적의 남은 체력과 강함을 유지합니다.

숲의 시작 마을 동쪽에는 새 대장간 마당이 있습니다. 가까이 가서 **대장간**을 누르면 한 화면에서 무기를 고르고 현재·다음 공격력, 강화 비용과 성공 확률을 확인할 수 있습니다. 강화 횟수에는 제한이 없지만 **실패하면 선택한 무기가 소멸**합니다. 현재 무기 레벨이 내 레벨보다 낮으면 성공률 90%, 같으면 70%, 1·2·3레벨 높으면 각각 60·50·40%, 4레벨 이상 높으면 30%입니다. 무기는 강화에 성공할 때마다 1레벨과 공격력 2가 오릅니다. 새 전리품의 무기 레벨은 획득 시 내 레벨보다 최대 2 높고, 상점 무기는 내 레벨에 맞춰집니다. 기존에 보유한 무기의 공격력은 유지됩니다. 무기를 모두 잃어도 맨손이나 기초 마법으로 싸우며 상점에서 무기를 다시 구할 수 있습니다.

무기 카드의 무기 공격은 장비 수치이고 실제 한 타와 초당 피해는 직업·기본기·등급·공격 속도·현재 격노와 감속을 반영합니다. 초당 피해는 일반 기본 공격 한 타 기준이며 분신 연격 등 사용 기술의 피해는 별도입니다. 근접 무기는 사거리 105~190과 공격 각도를, 마법 무기는 사거리 440~600을 구분합니다. 함께 맞는 적이 늘면 한 명당 피해가 감소해 두 명에게 각각 80%, 세 명에게 각각 70%를 적용합니다.

마을·거점은 숲·사막·고대·미래·지하 묘역·공업 지대·시간의 정원별 전체 장면을 생성형 이미지로 제작했습니다. 같은 고정 시점·물체 크기·빛 방향을 쓰고, 각 그림의 건물·울타리·분수에 실제 충돌과 NPC·우물 위치를 맞춥니다. 마을과 필드는 지역에 맞게 밝게 유지하며 던전만 어둡게 표현합니다. 미니맵은 사진이 겹치지 않는 평면 지도에서 건물·우물·출입구를 보여 주고, 전체 지도는 상세한 마을 그림을 사용합니다. 하단 메뉴는 그림 아이콘을 살린 청동 테두리 버튼이며, 일반 피해·치명타와 희귀 전리품은 구분해 표시합니다. 설정의 조작법 안내는 제거했습니다.

전사는 투구와 강철 갑옷을 착용한 남성 모습이며 이동·공격·구르기의 16방향 프레임과 초상화를 함께 사용합니다. 화면에서 18% 크게 보이지만 충돌 몸체와 공격 사거리는 유지합니다. 기본 공격용 투척 도끼와 투창은 상점·전리품에서 얻으며, 투척 숙련이 실제 피해·치명타·초당 피해에 적용됩니다. 투척은 장비별 사거리·속도의 비행체로 한 명을 맞히고 장애물에서 멈춥니다. 원형 전투 버튼에는 사각 테두리 없이 기술 삽화를 표시합니다.

마을 보호 구역은 성벽의 실제 모양을 따릅니다. 성벽 안에서는 서로 공격할 수 없고, 밖의 필드는 이전의 큰 원형 범위로 보호하지 않습니다. 체력·자원 게이지는 얇게 표시하며 위기·중독 경고는 유지합니다.

전투 기술은 생성형으로 만든 화염 베기·얼음 파열·번개 타격의 4단계 그림을 실제 무기 궤적·파편과 함께 사용합니다. 그림의 단계를 부드럽게 이어 표시하며 주인공의 몸통은 가리지 않습니다. 달리기 버튼도 다른 기술과 같은 원형 틀 안에 갑옷 부츠 그림으로 표시합니다. 피해 숫자는 천 단위 쉼표·금빛 숫자·짙은 외곽선을 사용하고, 치명타는 더 큰 주황 금빛 숫자와 `CRITICAL!`로 구분합니다. 주인공 피격은 붉은색이며 골드·회복 표시는 기존 색으로 구분합니다.
