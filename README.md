# 자연의 수호자 (Godot 4)

Flutter·Bonfire로 만든 [sjrpg](https://github.com/obmaz/sjrpg)를 **Godot 4.7.2**로 옮기는 프로젝트입니다.
웹(HTML5/WebAssembly)으로 빌드해 GitHub Pages에 배포합니다.

[게임 플레이](https://obmaz.github.io/sjrpg2/)

게임의 **설정 → 이 기기에 설치**에서 브라우저 설치 창을 열 수 있습니다. 설치 창을 지원하지 않는 브라우저에서는 홈 화면 추가 방법을 안내합니다. iPhone/iPad는 Safari의 공유 → 홈 화면에 추가를 사용합니다. 설치한 뒤에도 인터넷 연결이 필요하며, 진행은 해당 브라우저·앱의 로컬 저장 공간을 사용합니다.

스타일·투영·재질의 고정 기준은 [아트 기준](docs/art-direction.md), 새 원화 생성 지시는 [공통 프롬프트](docs/art-prompts.md)에 보관합니다. 첨부받은 최종 게임 레퍼런스가 최상위이며, 같은 패밀리 원화를 함께 참조하고 실제 투영과 게임 화면을 검수합니다.

## Godot판 개발 방향

원본의 세계관·전사와 마법사·120° 쿼터뷰를 바탕으로 새롭게 만드는 액션 RPG입니다.
수치와 규칙의 완전한 재현보다 조작감·가독성·자연스러운 진행을 우선합니다.
먼저 숲 1장을 완성하며, 저장과 재도전 → 전투·성장 → 의뢰·보스 → 탐험(폭포·지도·안식처 이동)
→ 선택형 바람 동굴 → 모바일·웹 마감 순서로 진행합니다. 강화와 사망의 부담을 줄이고 자유로운 스킬 실험을 지향합니다.
후속 지역과 탈것은 숲 1장을 마친 뒤 확장합니다.

## 현재 이식된 범위

- 타이틀 → 직업 선택(전사/마법사) → **제1장 숲 마을**과 주변 필드
- **시작 화면**: 로딩부터 모험 시작까지 같은 숲 배경·제목·구도를 유지하고, 준비가 끝나면 실제 다운로드 진행 표시만 금빛 시작 버튼으로 교체. 모바일 [수호자 선택](docs/newselection-design.md)은 첨부 레퍼런스에 맞춘 어두운 숲·금빛 문장, 전사·마법사 탭, 큰 초상화와 능력치 카드, 하단 시작·이어하기 버튼으로 구성하며 회전 시 재배치. 직업 미리보기는 저장을 바꾸지 않고, 새 모험은 읽을 수 없는 파일·중단된 임시 저장을 포함해 기존 저장이 있으면 확인 후 시작
- **2.5D 쿼터뷰 120°**: 원본 `IsometricGround`와 같은 ±30° 지면 축 (`scripts/iso.gd`)
  - 원본 실측 데이터를 바탕으로 Godot판 건물·성문·분수·워프·나무를 배치. 새 건물은 밝은 석재·목재·슬레이트 지붕의 절제된 디테일로 교체하고 원화와 충돌 좌표에 같은 투영 보정을 적용 (`scripts/iso_sprite.gd`, `scripts/village.gd`)
  - [통합 생성형 디자인](docs/gate-design.md)의 쌍탑 성문 네 개와, 성문 날개벽의 실제 픽셀을 추출한 성벽(`gate-cohesive-*.png`·`wall-from-gate.png`). 십자 포장길과 밝은 광장, 상인·대장장이·탈것 상인·촌장·보급원 미라
  - **120° 기준 점검**: 건물·예배당·성문·성벽·다리·분수·워프·상자·석축 등 16종의 실제 픽셀 모서리 137개를 상·중·하단에서 측정. 지면 두 축 ±30°, 수직 90°와의 오차 및 평행선 간 차이를 각각 2.5° 이내로 검사. 성문·성벽은 실제 띠장·캡 높이와 경계 알파도 비교. 예배당은 계단으로만 오르고 절벽·건물은 막힘 ([측정·재생성 방법](docs/chapel-regeneration.md)).
  - 마을은 안전 구역(몬스터 진입·생성 없음), 성문 밖 흙길과 숲에서 몬스터 등장
  - **동문 밖 강과 돌다리**: 새 돌다리 원화의 상판·난간·기둥을 실측해 동문 앞마당과 북쪽 길을 연결. 물은 흐르는 텍스처 두 겹과 바위 둑으로 그리고, 다리 상판만 걸을 수 있으며 난간 앞면과 모서리 기둥은 캐릭터 위에 그려짐
  - 광장 분수는 이전보다 약 1.7배 크게 배치하고 석조 기단의 충돌도 함께 확대. 물줄기·수면의 흐름과 게이트 내부 소용돌이가 움직이며, 석재 모서리는 고정. 일시정지와 동작 줄이기에서는 애니메이션도 정지
  - 성벽 양 방향은 같은 성문 픽셀을 대칭 배치해 재질·돌 크기·띠장·흉벽 형태를 유지. 실제 앞면 접점과 프로필 높이를 맞추며, 필터링 틈을 막는 작은 그리기 겹침은 충돌과 분리
  - 나무는 수관 윗면과 짧게 가려진 줄기·뿌리의 앞뒤 관계가 보이는 원화 4종으로 통일. 정면형·고정 지면 그림자가 섞인 이전 18개 ID를 새 원화로 연결하며 기존 위치·크기·통행 범위는 유지
  - [숲 레퍼런스](docs/forest-reference.md)를 기준으로 차분한 이끼 잔디·회색 포장석·흙길과 흰꽃·따뜻한 색의 야생화·고사리를 배치. 문·상자·주민·워프·계단을 비우며 예배당 앞 화단은 높은 마당 위에 표시
- 원본 스프라이트 아틀라스(16방향 영웅 달리기·공격, 8방향 몬스터 걷기·공격)와 JSON 경계 데이터를 그대로 사용 (`scripts/actor_atlas.gd`)
- [몬스터 원화 640프레임 검수](docs/monster-animation.md): 5종 모두 높은 쿼터뷰와 앞뒤 가림을 확인. 생물 원화만으로 정확한 카메라 고도를 수치 인증하지 않으며, 발치 등록과 8방향을 유지. 공격 후 복귀 모션은 빠르게 마친 뒤 기존 회복 대기를 유지해 되감김과 늘어지는 자세를 줄임
- **스킬 트리**: 전사 33종(함성·전투 숙련·전투 기술·기본/특수), 마법사 31종(냉기·번개·화염)
  - 원본 카탈로그의 이름·설명·습득 레벨·소모·재사용·선행 조건·트리 배치·아이콘을 그대로 사용 (`assets/data/skills.json`)
  - 스킬 포인트 2개로 시작, 레벨업마다 1개(5의 배수 레벨은 2개), 원본 계열 기술은 최대 20등급
  - 주 슬롯 1개 + 보조 슬롯 4개 + 구르기, 새로 배운 기술은 빈 보조 슬롯에 자동 장착
  - 마법은 개별 재사용 대기시간을 적용하고 주·보조 버튼에 남은 초와 줄어드는 원형 가림막을 표시. 대기·공격 중 반복 입력에는 중복 팝업을 띄우지 않음. 원본에서 마나만 쓰던 주문은 조작 구분을 위해 1–5초를 적용하며 기존 양수 쿨타임은 유지. 지팡이 기본 근접 공격과 패시브는 제외
  - 초기화 시 투자한 포인트 환급
  - 전투 수치(피해 배율·등급당 성장 등)는 이식판에서 단순화해 조정 (`scripts/skill_defs.gd`)
- 고블린·늑대·멧돼지·해골 전사. 거리별 지역 레벨 1·3·5·7, 마을 주변은 적 체력·공격력·밀도를 낮춰 첫 탐험을 쉽게 구성. 성장해도 기존 지역 적은 함께 강해지지 않음
- **적의 시체**: 고블린·늑대·멧돼지·해골 전사·골렘은 처치한 자리에 종류별 쓰러진 원화를 남깁니다. 활성 맵에서 30초간 유지되고 마지막 3초 동안 옅어져 사라집니다. 최대 32개까지 유지하며, 시체 활용 스킬로 소비하면 즉시 제거합니다.
- 경험치·레벨업·물약 드롭, 초상화 왼쪽 위 메달에 현재 레벨 표시. 레벨업·이어하기에 맞춰 갱신하며 사망 시 장비·골드·경험치를 유지한 채 안식처 부활(3초 보호)
- 진행 저장(`user://`, 웹에서는 IndexedDB): 5초 간격·주요 변경 시 저장, 직전 정상 저장 백업·손상 시 복원, 실패 안내와 눌러서 재시도. 중단된 보호 의뢰는 다시 시작할 수 있으며, 새 모험은 직업 선택 후 확인할 때 저장을 덮어씀
- PC는 **좌클릭 주 공격, 우클릭 목적지 이동, WASD/방향키 이동, 1–4 보조 스킬**을 사용합니다. 좌클릭은 큰 주 슬롯·J/스페이스와 같은 기술이며 누르고 있으면 준비될 때 반복합니다. 우클릭 이동은 벽·건물에 막히면 멈추며 WASD나 터치 이동으로 취소합니다. Shift/L 구르기, Q 물약, T 스킬 트리, Esc 메뉴와 모바일 멀티터치(가상 조이스틱 + 버튼)도 지원합니다.
- 가로/세로 화면 모두 지원
- 캐릭터를 가까이 읽을 수 있도록 기본 카메라를 조정하고 두 직업 원화 높이를 74→84로 확대. 충돌·이동·전투 사거리는 유지
- **앱 전환·화면 이탈**: 입력을 해제하고 진행을 저장한 뒤 자동 일시정지. 돌아오면 직접 계속하기를 눌러 재개하며, 보호·동굴 제한 시간과 지연 공격·부활도 함께 멈춤. 열어 둔 메뉴는 유지.
- **가방(장비)**: 원본 장비 34종(`assets/data/gear.json`), 부위 3(무기·방어구·부적) · 등급 4 · 옵션 · 무기 레벨, 보관함 24칸, 탭(전체·신규·무기·방어구·부적·잠금), 장착·잠금·판매, 현재 장비와 비교. 시작 장비는 원본과 같음(전사: 수호자의 검, 마법사: 불씨 완드, 둘 다 여행자의 옷). 공격력·생명·자원은 장비를 합산해 계산(`GameState.attack_power`)
- **상자**: 마을 상자 5개를 공격 기술로 부수면 원본 규칙대로 장비 7 · 보급 1 · 골드 1 · 매복 1 비율로 보상
- **상점**: 상인(왼쪽 위 집) 곁에서 "상점" 버튼 → 무기·방어구·부적·물약 구매와 축복(무기 강화·생명 축복 수련: 한 번에 공격 +5/생명 +20, 레벨 3마다 상한 +1) (원본 가격·레벨 해금)
- **대장간**: 대장장이 곁에서 무기 강화(원본 비용·성공 확률, 실패 시 비용만 소비하고 무기·강화 단계 유지, 잠금 무기 제외)
- **지형·높낮이**: 랜드마크 4곳(고목의 쉼터·숲의 석조 정원·바람 언덕·계곡 폭포)을 필드에 배치. 언덕·정원은 새 원화와 계단·석축 실측값을 사용. 폭포의 물은 통과할 수 없고 마른 길 위 상자에서 희귀 장비를 얻음. 윗면은 계단(입구)으로만 오를 수 있고 절벽·구조물은 막히며, 윗면의 캐릭터는 원화 위에 그려짐
- **바람 동굴**: 로웬 근처의 동굴 입구에서 선택 탐험. 5분 제한·전투 구역 5개·두 갈림길·적 22마리, 적 레벨은 입장 시 내 레벨+2로 고정. 전부 처치 후 마지막 귀환문에서 완료하면 추가 골드. 동굴 처치는 숲 의뢰와 별개이며 일시정지 중 시간 정지. 사망·퇴장·시간 종료·재접속 시 입구 밖으로 돌아오고 획득 보상 유지.
  - [생성형 완성 디자인](docs/cave-design.md)을 기준으로 회색 석재 바닥·층이 보이는 암벽·낮은 앞쪽 돌턱·통로 아치·철제 등불과 숲 입구 원화를 사용. 넓은 전투 공간을 유지하고 등불은 탐험 중 은은하게 움직이며 일시정지·동작 줄이기를 따름.
  - 대기 중인 적은 각 방 안에서 배회해 선택하지 않은 갈림길에 숨어들지 않음. 전투 중에는 방 밖으로도 추적.
- **확대 지도·안식처**: 미니맵 또는 M으로 전체 지도와 의뢰·시설·발견한 안식처를 확인. 숲 마을·고목의 쉼터·동굴 입구를 직접 방문하면 해금되며, 안식처 곁에서 주변 적과 진행 중인 보호·보스 도전이 없을 때 무료 이동·회복. 사망·이어하기는 마지막 안식처에서 시작. F는 근처 대상 상호작용.
- **워프게이트**: 숲 마을·고목의 쉼터·동굴 입구의 게이트 곁에서 F 또는 워프게이트 버튼 → 발견한 목적지를 선택해 무료 이동·회복. 직접 방문한 목적지만 활성화되며 현재 위치는 선택 불가. 전투·보스 도전·보호 의뢰·사망·동굴 내부에서는 이동하지 못하고, 목적지의 안전한 게이트 앞으로 도착.
- **첫 여정 안내**: 새 모험은 마을의 미라에게서 시작하도록 안내. 이미 수락한 의뢰·완료 보고·진행 중인 보호 의뢰를 우선 표시하며, 대화와 안식처 이동 버튼은 더 가까운 대상을 선택.
- **제1장 퀘스트**: 수녀 엘린(석조 정원 봉인 정화, 근처 적 18마리) · 보급원 미라→약초사 노아(고목의 쉼터 배달) · 조사관 로웬(동굴, 90초 동안 30마리 습격 방어, 실패 시 재도전), 보상 골드·경험치, 퀘스트 일지(하단 두루마리)와 "지금 할 일" 표시
- **숲의 파수꾼**: 의뢰 3개를 완료하면 서쪽 숲 공터에서 직접 도전(슬램 예고 타원과 실제 판정 일치, 사망·이탈 후 재도전 가능), 최초 처치 시 파수꾼의 심장(고유 부적)과 제1장 클리어 화면. 가방이 가득 차면 보상을 보관했다가 빈칸이 생기면 지급
- **숲의 기억**: 서쪽·북쪽·동쪽 길의 상자 3개에서 이야기를 모으면 스킬 포인트 +1(마지막 상자와 함께 즉시 저장, 이전 저장의 누락 보상도 복구)
- **자유로운 성장**: 스킬 초기화는 무료이며 투자 포인트를 돌려받습니다. 강화 실패 시 장비가 사라지거나 강화 단계가 내려가지 않습니다.
- **보호 전투의 도발**: 전사의 도발은 조사관을 노리는 적도 자신에게 끌어옵니다. 효과가 끝나면 가까운 대상을 다시 노립니다.
- **무기 능력과 무기 성능**: 희귀·고유 장비의 능력 5종(서리의 낙인·수호의 맹세·생명의 수확·연격의 격정·연격의 수호), 무기별 사거리·타격 호·공격 간격 반영
- **설정**: 절약 화질(배경·캐릭터의 렌더링 해상도를 낮추고 HUD·메뉴는 선명하게 유지, 기본 꺼짐), 전체화면, 동작 줄이기(HUD 장식 회전·맥박과 분수·게이트의 움직임을 고정), 타격 진동, 전투 효과음(원본 SoundProfile 합성), 지금 저장, 타이틀, 새 모험(확인 후 저장 삭제). 설정은 기기에 저장
- **모바일 레이아웃**: 가방·스킬·설정이 한 틀(`PanelFrame`)을 공유. 화면 전체를 쓰고 안전 영역을 피하며, 글자 약 20px+·터치 영역 64px+, 탭은 가로 스크롤, 본문은 세로 스크롤
- **스킬 화면 조작**: 큰 스킬 그림·64px 이상 터치 영역, 단계별 스크롤과 상세창 분리. 스크롤 드래그와 선택 터치를 구분해 실수로 선택하지 않음.
- **팝업 디자인**: 어두운 가죽 질감·얇은 청동 이중 프레임·크림색 본문, 입체감 있는 어두운 금속 버튼과 원형 닫기 버튼으로 HUD와 통일. 제목·부제·본문 사이 여백을 두고 긴 내용은 본문만 스크롤. 대화·확인창은 실제 내용 높이에 맞춘 중앙 창, 가방·스킬·설정은 넓은 화면을 사용하며 회전 시 다시 배치. 긴 행동 버튼은 좁은 화면에서 세로로 배치.
- **레퍼런스 스타일 HUD**: 사용자 최종 레퍼런스 비율의 작은 초상화·가느다란 체력/자원/경험치 바, 얇은 청동 원형 미니맵과 지역명. 주 슬롯과 보조 4개를 청백색 테두리의 부채꼴로 배치하고 오른쪽에 구르기, 위에 붉은/보라 물약, 왼쪽에 반투명 룬 조이스틱, 아래에 작은 가방·스킬·일지·설정 버튼 배치. 빈 슬롯은 각인된 소켓으로 표시하며 모든 공격은 그림 아이콘을 사용
- **캐릭터 가림 완화**: 건물·성벽·나무·랜드마크가 주인공을 가리면 몸 주변의 작은 영역만 반투명 처리. 높은 마당 위에서는 기존 깊이 정렬 유지.
- 걷기·구르기·밀려남은 이동 경로를 나눠 검사해 프레임이 늦어져도 얇은 절벽을 건너뛰지 않음
- 투사체는 실제 이동 구간의 명중 순서를 검사해 느린 프레임에서도 적을 건너뛰지 않음. 관통은 적마다 한 번만, 비관통은 가장 먼저 닿은 적에 명중하며 수명 이후로 이동·타격하지 않음
- 사망·부활은 예약 공격·구르기·유지 입력을 취소하고, 시전 중 사라진 연쇄 번개 대상은 기존 사거리 안에서 다시 찾음. 일시적 기술 등급 강화는 새 모험·이어하기에 남지 않음
- **보상 피드백**: 상자 골드·희귀 장비·처치 경험치·레벨업을 서로 다른 짧은 빛 효과로 확인. 동시에 발생한 알림은 청동 명판에 순서대로 표시하며 중복·오래된 알림은 정리.
- **타격 피드백**: 실제 명중에 물리·화염·번개·냉기 원화 이펙트, 40–65ms 접촉 자세 유지·짧은 감쇠 반동·작은 카메라 충격·강한 타격의 낮은 타격음 적용. 접촉 자세는 그림에만 적용하며 공격·이동·AI 시간은 유지. 체력 손실 잔상·회복·물약 소비·재사용 완료·자원 부족을 HUD로 확인. 동작 줄이기에서는 카메라·반동·확장 동작을 억제하며 피해·공격 간격은 유지.
- **생성형 UI·이펙트**: [같은 원화 패밀리](docs/presentation-design.md)의 은빛 스킬 링·청동 미니맵/팝업 장식, 속성별 접촉→확산→잔광 4프레임을 사용. 베기·시전·발사·명중·오브·광역 빛에 반영하며 쿨타임 숫자·터치 크기·전투 수치는 유지
- **마법 표현**: 성공한 원소 마법의 준비 동작에 손끝 원화 빛과 작은 청백·금빛 섬광 표시. 투사체는 생성형 핵과 가는 꼬리를 사용하며 피해·속도·판정은 유지. 실패한 시전에는 준비광을 표시하지 않으며 일시정지·동작 줄이기를 반영. 준비음과 실제 발사 순간의 빛·발사음을 동기화하고 구르기·사망으로 취소한 주문의 발사음은 재생하지 않음. 구르기 시작 잔상으로 동작을 구분하고, 지속 원소 피해도 같은 속성의 피격 원화·플래시를 사용. 느린 프레임에서도 첫 피격 플래시를 보존하고 짧게 감쇠
- **헤더 가독성**: 초상화·게이지 묶음은 기존 소형 배치보다 10% 키우고, 원형 초상화와 막대의 접점을 매끈하게 연결. 아바타·게이지와 미니맵은 안전 영역 위쪽의 같은 높이에 배치. 레벨 메달은 초상화 왼쪽 위 테두리에 겹쳐 또렷하게 표시. 체력·자원·경험치의 채움은 초상화 밖의 가시 구간을 기준으로 표시. 작은 채움과 거의 가득 찬 채움도 경계 안에 유지하며 긴 숫자·화면 회전·안전 여백을 반영. 미니맵 마커는 원형 테두리 안에 표시.
- **조작 가독성**: 물약을 포함한 터치 영역 64px 이상, 안전 여백 반영, 활성 강화 효과와 남은 시간 표시.
- 조이스틱·빈 슬롯은 배경이 비치는 낮은 명암으로 표시하고 근접 상호작용은 작은 명판으로 정리. 표시를 줄여도 원래 터치 영역·쿨타임 숫자는 유지
- 바닥은 생성형 석재·잔디·흙길 원화를 균일한 밝기로 표시. 실제 나무·건물·광원과 연결되지 않는 반복 그림자와 고정 햇빛 얼룩은 사용하지 않음

원본의 나머지 여섯 지역(제2장 사막 이후), 탈것은 아직 구현 전입니다.
무기 능력과 무기별 사거리·공격 간격은 구현되어 있습니다. 무기 숙련은 가장 높은 한 가지가 기본 무기에 적용됩니다.

## 개발 하네스

작업 규칙은 [AGENTS.md](AGENTS.md), 구조·디버그·테스트는 [docs/development.md](docs/development.md)에 있습니다.

```sh
tools/check.sh            # 임포트 + 전체 테스트
tools/check.sh --export   # + 웹 빌드
tools/serve.sh            # build/web 로컬 서빙
node tools/screenshot.mjs --scene bag --device phone
```

## 로컬 실행·빌드

1. [Godot 4.7.2](https://github.com/godotengine/godot/releases/tag/4.7.2-stable)와 같은 버전의 export templates를 설치합니다. 버전 기준은 `.godot-version`이며 Linux x86_64에서는 `tools/setup_godot.sh`가 둘을 설치합니다.
2. 에디터에서 `project.godot`을 열고 F5로 실행합니다.
3. 웹 빌드:

   ```sh
   tools/export_web.sh
   tools/serve.sh
   ```

   `index.html?zoom=0.4`로 카메라를 넓게, `&at=field`·`&at=bridge`·`&at=gate0..3`로 시작 위치를 바꿔 볼 수 있습니다 (디버그용).

   웹 빌드는 스레드를 끈 단일 스레드 템플릿(`variant/thread_support=false`)을 사용합니다.
   GitHub Pages는 COOP/COEP 헤더를 보낼 수 없기 때문입니다.

## 배포

`.github/workflows/web.yml`이 모든 푸시에서 웹 빌드를 만들고, `main` 브랜치에 푸시되면 GitHub Pages에 배포합니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다.
