# 자연의 수호자

모바일 터치와 키보드를 지원하는 핵앤슬래시 RPG입니다. 두 게임은 독립적으로 실행·저장·빌드합니다.

- [새로운 모험 · Flutter / Bonfire](https://obmaz.github.io/sjrpg/new/): 전사·마법사와 의뢰를 따라 진행하는 새 게임입니다.
- [기존 모험 · Legacy](https://obmaz.github.io/sjrpg/legacy/): 기존 Canvas 2D·JavaScript 게임입니다. [조작·진행 안내](docs/legacy-guide.md)를 참고합니다.
- [버전 선택](https://obmaz.github.io/sjrpg/): 두 버전의 진입 화면입니다.

## 새로운 모험

전사와 마법사는 스킬 포인트 2개로 시작합니다. 전사는 함성·전투 숙련·전투 기술, 마법사는 냉기·번개·화염의 세 탭에서 기술을 배웁니다. 원본 계열 기술은 최대 20등급이며, 기본 공격·별도 기술의 한도는 각 설명을 따릅니다. 네 사용 기술과 기본 공격을 지정하고, 성장에 따라 질주·순간이동을 배웁니다.

일반 공격은 누르거나 길게 눌러 이어서 공격합니다. 마법사의 기본 공격은 배운 화염탄·번개 줄기·얼음살 중 선택하며 마나가 필요합니다. 전사의 분신 연격은 기술 버튼을 타이밍에 맞춰 다시 눌러 다음 적으로 공격을 잇습니다. 강타는 장착 무기에 비례하는 단일 타격입니다. 광역 기술은 등급별 대상 제한을 가지며, 실제 명중 대상이 늘면 한 명당 피해는 줄어듭니다. 피해·공격 주기·초당 피해·소모량은 가방과 기술 설명에서 확인합니다.

제1장 숲의 세 성소와 처치 의뢰·파수꾼을 해결하면 제2장 사막으로 진행합니다. 제2장의 첫 의뢰인에 따라 고대 또는 미래 줄기가 정해지고, 각 줄기의 제3·4장을 거쳐 공통 제5장으로 이어집니다. 총 일곱 지도에서 지역별 의뢰·적·보스를 만납니다. 지도는 미니맵을 눌러 확대하며, 발견한 우물은 방문한 스테이지 전체의 우물과 연결됩니다.

마을 주변에서는 새 무리 수와 일반 적 기본 체력을 절반으로 줄입니다(홀수 무리 수 올림). 먼 곳과 다음 장의 적은 더 강하며 정예·고유 적은 추가 능력을 사용합니다. 일반 적은 처치 시 10% 확률로 혈흔 없는 종별 시체를 남깁니다. 물약 발견·아이템 발견·섬뜩한 호신부는 가까운 시체를 한 번 소비합니다. 시체는 최대 32개·시뮬레이션 180초까지 유지됩니다. 레벨업 요구 경험치는 이전의 절반이며, 레벨업 시 금빛 고리와 빛이 나타납니다.

장비는 가방에서 바로 비교·장착·잠금·판매합니다. 상점에서 장비·물약을 사고, 대장간에서 성공 확률과 비용을 확인해 무기를 강화합니다. 강화 실패 시 무기가 소멸하며 강화 횟수 제한은 없습니다. 새 무기 전리품은 내 레벨보다 최대 2레벨 높습니다. 일반 중복 장비는 골드로 바뀌고, 희귀·고유 장비는 특수 능력을 가집니다.

탈것은 상인에게 구매합니다. 말은 탑승 공격이 가능하지만 세 번 피격되면 쓰러지고, 자전거는 넘어지지 않는 대신 탑승 전투를 할 수 없습니다. 오토바이는 탄약을 쓰는 기관포와 강화 기능이 있고, 배는 수면에서만 움직입니다. 탑승은 가까이 가서 직접 선택합니다.

사망 시 무기 하나와 골드 최대 30%를 무작위로 잃습니다. 다시 일어나면 체력·분노/마나를 회복하고 실제 3초간 보호받습니다. 스테이지 완료마다 스킬 초기화 티켓을 받으며 골드로 초기화하지 않습니다.

체력이 30% 이하면 위험 테두리를, 10% 미만이거나 중독 상태이면 게이지와 화면의 붉은 맥박을 표시합니다. 동작 줄이기 설정을 존중합니다. 시간·골드 칩은 전투 HUD에서 숨기며 골드는 가방·상점에서 확인합니다. 설정에서 전체화면·진동·앱 설치를 조절합니다.

모험은 5초 간격과 주요 변경 시 브라우저에 저장됩니다. 원본 황혼 풍경의 타이틀에서 **이어하기**로 복원합니다. **시작**은 직업 선택으로 이어지며, 기존 저장이 있으면 덮어쓰기 확인을 표시합니다. 취소하거나 직업 선택에서 타이틀로 돌아오면 저장을 유지합니다. 저장이 없거나 읽을 수 없으면 이어하기를 비활성화하고 이유를 표시합니다. 새 모험을 실제로 시작하면 기존 저장을 덮어씁니다. 저장 불가 시 게임 안에서 오류와 재시도를 안내합니다. 기본 진행 속도는 1.2배이며 표시 시간·DPS는 실제 시간을 기준으로 합니다. 30FPS의 프레임 예산을 목표로 최적화하지만 실제 성능은 기기·브라우저에 따라 달라집니다.

## 새 버전 개발

Flutter **3.47.8**, Node.js **24 이상**을 사용합니다.

```sh
npm ci
npm run prepare:new
cd flutter_game
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

Dart 코드는 `flutter_game/`에서 다음 명령으로 포맷을 검사합니다.

```sh
dart format --output=none --set-exit-if-changed lib test
```

저장소 루트의 `npm run check`는 JavaScript·스크립트·문서 포맷·Node 회귀 테스트를 검사합니다.

## WASM 빌드·배포

```sh
npm run prepare:new
npm run prepare:legacy
npm run build:new
npm run build
```

`build:new`는 Flutter만 WASM 릴리스로 빌드합니다. `prepare:legacy`는 소스가 같은 Legacy 캐시나 배포본을 재사용하며, Legacy 소스가 바뀐 경우에만 별도로 빌드합니다. `build`는 준비된 두 결과를 `dist/`에 조립합니다.

지원 브라우저는 Dart WASM·Skwasm을 사용하며 미지원 브라우저는 함께 생성된 JS 호환 빌드를 사용합니다. GitHub Pages에서는 단일 스레드 Skwasm으로 실행합니다. GitHub Actions의 **Check and deploy**가 버전별 검사·캐시·Pages 배포를 수행합니다. 배포 완료는 해당 커밋의 성공과 공개 페이지에서 확인합니다.
