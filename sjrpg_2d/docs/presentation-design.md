# HUD 금속과 원소 타격 원화

최상위 스타일은 [사용자 원본](../assets/source/style/approved-game-reference.jpg)과 [아트 기준](art-direction.md)입니다.
화면 배치·작은 초상화·실제 스킬 아이콘·터치 영역은 [UI 기준](ui-reference.md)을 유지합니다.

## 생성 원본과 패킹

`assets/source/hud-trim.png`에서 청백색 은빛 스킬 링, 어두운 청동 빈 슬롯 링, 작은 청동 모서리 장식을 사용합니다.
미니맵은 같은 패밀리에서 더 얇게 생성한 `assets/source/map-rim.png`를 사용해 기존 지도의 표시 영역을 비웁니다.
중앙 구멍과 외부는 실제 투명 알파이며, 미니맵·아이콘을 가리는 단색판을 넣지 않습니다.
`PresentationArt.draw_ui()`는 실제 금속의 바깥 치수를 지정 반경에 맞추므로 투명 패킹 여백 때문에 링이 작아지지 않습니다.
미니맵 테두리는 반경 64px 기준 바깥 66.5px에 맞추고 전체 그리기 범위를 안전 영역 안에서 검사합니다.
기존 지도 내용의 반경 62px와 마커의 내부 여유, 팝업 모서리의 8–34px 장식 공간을 유지합니다.

`assets/source/combat-frames.png`는 4×4 원화입니다. 행은 물리·화염·번개·냉기, 열은 접촉·최고조·분산·잔광입니다.
같은 셀 크기와 중심으로 패킹하고 인접 그림을 교차 페이드해 한 장의 그림을 커지게만 하던 표현을 바꿉니다.
발광 전용 원화는 **순수 검은 바탕 + ADD 재질**을 사용합니다. 검정은 빛 기여가 0이므로 장면을 가리지 않습니다.
일반 알파 모드로 표시하면 검은 사각형이 나타나므로 모든 사용 경로의 ADD 재질을 검사합니다.
UI 금속과 일반 물체에는 이 방식을 사용하지 않고 실제 투명 알파를 유지합니다.

반투명 회색 매트가 남았던 제작 중간본은 `assets/source/style/`에 참조용으로만 보관합니다.
채택한 원본·사용자 참조·실제 배포 텍스처·생성 기록의 SHA-256은 `assets/data/presentation_art.json`에 고정합니다.
실제 생성 문구와 참조 파일 순서는 [presentation_generation.json](../tools/extract/presentation_generation.json)에 있습니다.
`tools/prepare_presentation_art.py`는 원화를 자르고 크기·여백을 맞추며 새 금속이나 이펙트를 그리지 않습니다.

```sh
python3 tools/prepare_presentation_art.py
tools/check.sh --only=presentation_art,juice,hud_layout,minimap_border,panel_layout,ui_input --export
```

## 실제 동작과 표현

- 스킬·빈 슬롯·미니맵 링과 팝업 모서리에 같은 생성형 금속 패밀리를 사용합니다. 실제 아이콘·재사용 초·누름 반응과 메뉴 기능은 유지합니다.
- 성공한 시전의 작은 손끝 빛, 실제 발사 순간, 투사체 핵·꼬리, 확정 명중, 베기·오브·광역 빛에 원화를 사용합니다.
- 명중 수명 0.22/0.28초, 피해·공격 시간·사거리·판정·관통 규칙은 유지합니다. 시간은 기존 Effect의 age/life에서만 읽고 새 타이머나 공격 판정을 만들지 않습니다.
- 동작 줄이기는 최고조 한 장을 고정한 뒤 기존 수명으로 흐리게 합니다. 시전·명중이 취소되면 새 장식은 추가하지 않고, 일시정지와 장식 64개 한도를 따릅니다.
- 얇은 범위선과 실제 위험 예고는 가독성을 위해 유지합니다. 광역 빛은 낮은 불투명도로 바닥과 적의 실루엣을 비우고 화면 전체 섬광을 넣지 않습니다.
- 투척 무기는 일반 재질·기존 그림을 유지하며 검은 발광 시트를 사용하지 않습니다.

## 검수

`presentation_art`는 출처 해시·비어 있는 링 중앙·지도 경계 64방향의 투명 여유·검은 셀 여백·잔광이 최고조보다 약한지 확인합니다.
`juice`는 실제 피해로 생긴 원화의 시간 진행·일시정지·동작 줄이기·수명 종료·추가 피해 없음과 ADD 재질을 확인합니다.
기존 HUD·팝업·입력 검사는 작아진 화면과 회전에서도 배치·터치·숫자가 유지되는지 확인합니다.
실제 브라우저에서 전사·마법사, 가로·세로, 밝은 포장길·숲과 메뉴, 기본·절약 화질의 과도한 밝기·사각형 매트·잘린 링·가려진 숫자를 함께 검수합니다.
